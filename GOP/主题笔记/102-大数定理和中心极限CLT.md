- **老师的PPT思路**：
	- 把 “**观测到的具体数据**” 和 “**理论上的随机变量**” 划清了界限，我们永远看不到“**上帝视角**”的总体分布，我们只有手里的 “**有限样本**”，我们所有的工作都只能是 “**估计（Schätzung)**"
	- 给 “**估计**” 吃定心丸——**弱大数定律（WLLN）**：只要数据量大，“**均值**” 是靠谱的：只要样本量 n 足够大，样本的 **算术平均值** $\bar{X}_{n}$​ 就 一定（**依概率**）无限接近总体的 **真实期望** $\mu$
	- 把 “**单个点**” 扩展到 “**整体分布**”：光知道均值收敛还不够，万一 **整体分布形态** 变了怎么办？
		- **经验分布函数（ECDF)**  也会无限靠近 **真实的分布函数** $F(x)$
		- 只要 **样本足够大**，**经验分布** 就是 **真实分布** 的完美替身
	- 大数定律 只告诉你 “**均值会靠近**”，但 中心极限定理告诉你 “**靠近时的概率分布形状**”
		- 无论原始数据长什么样（离散、连续、偏态），**只要期望和方差有限**，当 n 足够大时，**样本均值 $\bar{X}$ ，总和 $S_n$​ 的分布** 都 **近似服从** 正态分布
		- $S_n\overset{a}{\sim}\mathcal{N}(n\mu,n\sigma^2)$
		- $\bar{X}_n \overset{a}{\sim} \mathcal{N}\left(\mu = \mu_X,\ \sigma^2 = \frac{\sigma_X^2}{n}\right)$ -- 基于 **“正态分布的线性变换”** $X \sim \mathcal{N}(\mu,\sigma^2),Y=aX + b \Rightarrow Y \sim \mathcal{N}(a\mu + b, a^2\sigma^2)$，因为$X_{n} = \frac{1}{n} \cdot S_{n}$ ，所以 **均值分布** 可以直接从 **和分布** 直接变换写出
		- **正态分布标准化**：对于随机变量 X，具有均值 $\mu$ 和 方差 $\sigma^2$，$\frac{X-\mu}{\sigma}\xrightarrow{d}N(0,1)$，注意，是**依分布收敛**

- **大数定理（GGZ）**：(Schwaches Gesetz der großen Zahlen) -- **研究的是观察到的数据的平均值随着观测数据增大，趋近于数据真实分布的均值（期望）**
	- ”**弱**“ 大数定理（**WLLN**）：对于来自某个 iid 的随机变量 $X_{i}$，算术平均值 $\bar{X}_{n}$ = $\frac{1}{n}\Sigma_{i=1}^nX_{i}$，该分布的期望为 - $E(X_i) = \mu_X$，方差为 - $Var(X_i)=\sigma^2$，则有：
		- **注意1：** $X$ - 是一个随机变量，$X_{1} + X_{2}$ - 也是个随机变量，$\Sigma X_{i}$ - 也是个随机变量，因此，$\bar{X}_{n}$ - 也是个随机变量
		- **注意2**：随机变量满足 弱大数 **定理的前提是 随机变量 X 需要具有期望**，例如：**柯西分布没有期望**，因此无论 n 多大，均值都不会收敛
		- **均值的期望** $E(\bar{X}_{n}) = \mu_{X}$，**均值的方差** $Var(\bar{X}_{n}) = \frac{1}{n}\sigma_{X}^2$（**方差随着样本数量增大而减少**）
		- 并且有 ： $P(|\bar{X}_{n} - \mu_{X}| \geq \epsilon) \xrightarrow{n \to \infty} 0, \forall \epsilon > 0$ -- **随着取得的数越多，抽取到的数的算术均值越趋近于随机变量的期望**
		- 即：$\bar{X}_n \xrightarrow{P} \mu_X$  -- **算术平均值依概率收敛到随机变量的期望**
			- **回顾依照概率收敛定义**：如果对任意 $\varepsilon>0$，$P(|X_n-X|>\varepsilon)\to0,\quad n\to\infty$，则称 $X_n$ 依概率收敛到 $X$，记作 $X_n\xrightarrow{P}X.$
			- **容易混淆**：依照概率收敛到的 X 可以是一个随机变量，**也可以是一个随机变量的退化值（一个常数）**

- **经验分布的点态收敛**（**Punktweise Konvergenz der empirischen Verteilung**）
	- **定理**：**经验分布函数** "**逐点收敛**" 到数据生成分布的 **真实分布函数**
	- **经验分布函数（ECDF）**：对于观测数据 $x_{1},\dots,x_{n}$ 经验分布函数定义为：$\hat{F}_{n}(t) = \frac{1}{n}\Sigma_{i=1}^n I( x_{i} \leq t)$  -- t = 5, 就是数一下有多少观测数据小于等于5，例如 20 个里面有5个，得到分布值 = 25%
		- 我们获得了一堆数据，但是不知道真实分布 $F(t)$，就用数据样本算出来的 $\hat{F}_{n}(t)$ 当作 $F(t)$ 的替身，这叫做 ”**估计**“ 
		- 当数据足够多的时候，ECDF 分布曲线会无线贴近真实的分布函数
		- 经验分布函数 X 轴是 t **就是你在 X 轴上设定的一个“门槛值”/“标尺位置”，用来问一个问题：数据里有多少比例落在了这个位置的左边（含这个位置）？**
	![[34ca7123-f655-4463-8042-1f05cf4b9ace.png|946]]
	- 令随机变量 $Y = I(X_{i} \leq x)$ ，根据弱大数定理（WLLN），有：$\frac{1}{n}\Sigma_{i=1}^n Yi = \frac{1}{n}\Sigma_{i=1}^n I(X_{i} \leq x)  \xrightarrow{P} E(Y_{i}) = 1 \cdot P(X_{i} \leq x) + 0 \cdot P(X_{i} > x)$
		- 所以：$\frac{1}{n}\Sigma_{i=1}^n I(X_{i} \leq x)  \xrightarrow{P} P(X_{i} \leq x) = F_{X}(x)$
		- **提示**：指示函数 $I(X_{i} < x)$ 也是个随机变量 !!!
		- **观察，上面式子左侧就是 ECDF 经验分布函数，因此，经验分布函数 依概率 收敛到 真实分布函数(CDF)**
		- 因为上面推导过程，针对任意 $x$ 都成立，所以，经验分布函数 **逐点收敛** 到 真实分布函数(CDF)
- **Glivenko-Cantelli 定理（重要！！）**：
	- **前提**：对于 i.i.d 的随机变量 $X_i, i = 1,2,\dots,n$ 其分布函数为：$F_{X}(x)$，经验分布函数为：$F_n(x) = \frac{1}{n} \sum_{i=1}^n \mathbf{I}(X_i \leq x)$
	- **结论**:  满足 $P\left( \sup_{x \in \mathbb{R}} \left| F_n(x) - F_X(x) \right| < \epsilon \right) \xrightarrow[n \to \infty]{} 1 \quad \forall \epsilon > 0$   **-- 小于无限小的数的概率为1，也就是 $F_n(x)$ 和 $F_{X}(x)$ 之间差距无限小！**
	- **只要样本足够多，经验分布 和 真实分布 之间的“最大差距”，一定会变得要多小有多小** !!!
	- **定理用途**：我们永远无法知道真实分布 F（比如全国人的身高分布），只能拿到有限样本 Fn​。**定理的作用**：它向你**打包票**（概率为1）：只要样本量 n 够大，你的经验分布 Fn​ 就是真实分布 F 的**完美替身**
	- **只要样本量够大，数据一定能反映真相。它是所有“大数据分析”和“统计推断”能够成立的最后底气。**

- **中心极限定理**（Der zentrale Grenzwertsatz）：来自具有**有限期望和有限方差**的 n 个独立同分布随机变量的算术平均值，经过正确标准化后，当 n 增大时，**分布收敛到标准正态分布**
	- **随机变量标准化**：每一个具有有限期望值 $\mu_{X} = E(X)$ 和 有限方差 $\sigma_{X}^2=Var(X)$ 的随机变量 X，都可以通过变换使得 期望 = 0，方差 = 1：$\tilde{X} = \frac{X - \mu_X}{\sigma_X}$
		- $E(\tilde{X}) = \frac{1}{\sigma_X} \bigl(E(X) - \mu_X\bigr) = 0$
		- $\text{Var}(\tilde{X}) = \frac{1}{\sigma_X^2} \, \text{Var}(X) = 1$
	- **独立同分布随机变量之和的标准化**：考虑独立同分布随机变量 $X_{1},\dots,X_{n}$，具有相同的有限期望 $\mu_{X} = E(X)$， 和有限方差 $\sigma_{X}^2 = Var(X_{i})$
		- 构造新随机变量 $Y_{n} = X_{1} + \dots + X_{n}$，有：$E(Y_{n}) = n \cdot \mu_{X}$， $Var(Y_{n})=n \cdot \sigma_{X}^2$
		- 对 $Y_{n}$ 进行标准化，$Z_n=\frac{Y_n-n\mu_X}{\sqrt n\,\sigma_X}$，有：$E(Z_{n}) = 0, Var(Z_{n}) = 1$
	- **中心极限定理**（ZGWS）：由 i.i.d 随机变量（**存在期望和有限方差**）X 构成的**标准化和** $Z_{n}$ 的分布函数 $F_{n}(z)$ ，当 $n \to \infty$ 时，在 每一个点 $x \in \mathbb{R}$ 处收敛于标准正态分布 $N(0,1)$ 
		- **和分布**：令 $S_n=X_1+\dots+X_n$，则 $S_n\overset{a}{\sim}N(n\mu,n\sigma^2)$；等价地，$\frac{S_n-n\mu}{\sqrt n\,\sigma}\xrightarrow{d}N(0,1)$
		- **均值分布**：$\bar{X}_n \overset{a}{\sim} \mathcal{N}\left(\mu = \mu_X,\ \sigma^2 = \frac{\sigma_X^2}{n}\right)$
		- **书写注意**：
			- $S_n$ 是 n 个 i.i.d. 随机变量的和（也是随机变量），其 $E(S_n)=n\mu$、$Var(S_n)=n\sigma^2$；一般只在大样本下**近似正态**，若 $X_i$ 本身正态则有限样本下精确正态；
			- 对 $S_n$ 进行标准化后，其分布函数逐点收敛于 $N(0,1)$ 的分布函数，这里收敛到的分布一定是一个具体分布，不能出现 n 这种，因为收敛是 $n \to \infty$
		- **适用场景**：只要 期望 和 方差 都存在，ZGWS 定理 同样适用于 **离散的随机变量**

- **大数定律（GGZ）**提供关于**算术平均值依概率收敛到总体期望**的渐近结论；$E(\bar X_n)=\mu$ 和 $Var(\bar X_n)=\sigma^2/n$ 则是在相应矩存在时的有限样本公式。
    
- **中心极限定理（ZGWS）** 提供了关于 **算术平均值的完整（渐近）分布** 的结论。 **---- 根据上面，均值服从正态分布 可以 直接推导出 和服从正态分布!!**
    
- **中心极限定理**既适用于**连续型**随机变量 $X_{i}$​，也适用于**离散型**随机变量 $X_{i}$​。
    
- **应用**：许多（近似）独立同分布随机变量之和/平均值的分布，可以通过**正态分布模型**很好地近似。

- 例子1（离散）：设 $X_{i} \sim B(p)$ 服从**伯努利**分布，i = 1,2,...,n，所以有：$Y_{n} = \Sigma X_i ~ B(n,p)$ 即 $X_{i}$ 之和服从二项分布。
	- **根据中心极限定理**：$\frac{Y_n-np}{\sqrt{np(1-p)}}\xrightarrow{d}N(0,1)$
	- **等价于**：$Y_n\overset{a}{\sim}N(\mu=np,\sigma^2=np(1-p))$

- 例子2（连续）：设 $X_{i} \sim N(0,1)$, i = 1,2,...,n, 所以有 $Y_{n} = \Sigma X_{i}^2 \sim \mathcal{X}^2(d = n)$  -- 注意，这个场景下，卡方分布的自由度为 n
	- **注意1**：$X_{i}^2$ - 这个也是个随机变量，因此，$Y_{n} = \Sigma X_{i}^2$  必然可以套用中心极限定理（求和表达式）
	- **注意2**：根据卡方分布的定义，$Y_{n} = \Sigma X_{i}^2$ **正好就是自由度为 n 的卡方分布，期望 = n，方差 = 2n**
	- **根据中心极限定理**：$\frac{Y_{n} - n}{\sqrt{ 2n}} \xrightarrow{d} N(0,1)$ 
	- **等价于**：$Y_{n} \overset{a}{\sim} \mathcal{N}(\mu = n, \sigma^2=2n)$ 
	- **附加发现**：在 n 足够大的时候（要满足中心极限），自由度 = n 的卡方分布 近似等于 $N(n,2n)$ 这个正态分布
