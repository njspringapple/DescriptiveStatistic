
- **二分类特征** Y 和 至少一个**有序尺度特征** X
	- 例如：
		- X - 生物标志物（血液中的物质浓度等）或**诊断评分（diagnostischer Score）**  Y - **患病 vs. 健康**（krank vs. gesund）
		- X - 客户特征（例如该客户迄今为止带来的销售额） Y - 购买决策 是/否
---		
- **敏感性与特异性**（Sensitivität und Spezifität）
	- 设 $Y \in \{0,1\}$ 是**二分类特征**dichotom（目标变量Zielgröße），$X$ - **有序尺度**mindestens ordinalskaliert（影响变量Einflussgröße）
	- **目标**：仅基于 $X_{i}$ 和 门限 $c$ 进行 **预测/诊断**：$$\hat{y}_{i} = 1 \Leftrightarrow x_{i} \geq c -- \text{有序数据 x 取值超过门限 c 情况下，分类为 1}$$
		- **换成人话**：血压高于 **140 mmHg**（毫米汞柱），就是 **高血压**
		- **探索问题**：如何选择这个 门限 使得 X 可以用来评估Y（如何选择 **每日学习时长门限**，使得 每日学习时长（X）可以用来评估是不是可以 **通过考试**（Y）)
		- **问题**：这个门限如何选择并且评估？**将预测值（根据自己设置的门限来预测）和 最终真实结果 排列组合比对，得到4个结果！**
			- **预测成功**：
				- 真阳性（**TPR** - True Positive Ratio）-- 敏感性 Sensitivität -- **确诊患者中有多大比例被正确识别出来了？**
				- 真阴性（**TNR** - True Negative Ratio) -- 特异性 True Negative Rate -- **“健康者中被正确诊断的比例是多少？”**
			- **预测失败**：
				- 假阳性（**FPR** - False Positive Ratio）     -- **误诊**  -- **“健康者中被误诊为患病的比例是多少？”**
				- 假阴性（**FNR** - False Negative Ratio）  -- **漏报** -- **患病者中没有检测出来的比例多少？**
			- 调整 "**门限**" 会影响以上指标，我们判定方法和门限是否有效，就是要看以上几个指标是否合适，**最理想肯定是某个门限下完美区分阴性和阳性**： TPR = TNR = 1，FPR = FNR = 0
				- 但是！实际上不可能存在完美的门限！在选择的判别方法下，**一定有一些 误诊 或者 漏报**
				- **门限调高** ==> 划入阳性的数据变少 ==> TPR真阳性也变少，FPR假阳性也会变少             ---- **这里自己好好想一下不用背**！
				- **门限降低** ==> 划入阴性的数据变少 ==> TNR真阴性会变少，FNR假阴性也会变少
		- **其它指标**：--- **关注的预测准确性！！！**
		
			- **阳性预测值（ppV，Positive Predictive Value)**： ppV = TP / （TP + FP）  -- **报警器响了，真的是坏人吗？**
			- **阴性预测值（npV，Negative Predictive Value)**：npV = TN /  (TN + FN)   -- **在被诊断为“健康”的人中，有多少人确实是健康的?**
				
		- **口诀**：
			- **看到阳性**：
				- 有多少比例“患者”被挑出来了（看水平方向比例） - **TPR 敏感度**
				- 有多少比例是“真患者”（看垂直方向比例）- ppV
			- **看到阴性**：
				- 有多少比例“健康”被挑出来了（看水平方向比例）- **TNR 特异度**
				- 有多少比例是“真健康”（看垂直方向比例）- npV

- **混淆矩阵（Konfusionsmatrix）**
	- **真阳率 TPR** ： TP /（TP + FN） = 真阳 / （真阳 + 假阴）===>  实际阳性里面 **有多少比例阳性能找出来**
	- **假阳率 FPR** ：FP / （FP + TN） = 假阳 / （假阳 + 真阴）===>  实际阴性里面 **有多少比例误诊了**

|                       | 真实值 $y_i=0$           | 真实值 $y_i=1$           | 合计     |
| --------------------- | --------------------- | --------------------- | ------ |
| **预测值 $\hat{y}_i=0$** | **“真阴性”** (正确阴性) - TN | **“假阴性”** (漏报) - FN   | 阴性预测总数 |
| **预测值 $\hat{y}_i=1$** | **“假阳性”** (误报) - FP   | **“真阳性”** (正确阳性) - TP | 阳性预测总数 |

- **ROC 曲线**（真假阳性曲线）--- **(假阳性FPR，真阳性TPR)**
	- X 轴 - **假阳性FPR** = 1 - **真阴性TNR**
	- Y 轴 - **真阳性TPR**
	- **符号注意**：TPR(c) , FPR(c) 带参数的函数表达式代表是：**在选定的 门限-c 下的各个指标数值**
	- 针对所有可能的门限 $c \in [x_{(1)},x_{(n)}]$，连接点：$( FPR(c), TPR(c) )$ -- 它展示了在所有可能的阈值 $c$ 下预测的可靠性

- **曲线的量化评估指标 - AUC：** （Maß zur Bewertung der Kurve）
	- AUC 对应于 ROC **曲线下的面积** （Das 𝐴𝑈𝐶 entspricht der Fläche unter der ROC-Kurve）
	- **公式**：$\mathrm{AUC} := \frac{N_C + N_E / 2}{N}$
		- 假如有10个人，做某种检查，得到分数，10个人里面有疾病的是7个人，健康有3个人
		- 首先，根据**真实分类**，把数据分**两类**，例如：患者 和 健康
		- $N_{C}$ ：逐个比对两类数据的分数，看**真正应该被挑选出来的数据的分数** 和 **真正不应该被挑出来的数据的分数**，**数出大于的数量**
		- $N_E$ ：逐个比对两类数据的分数，看有多少是 **相等的**
		- $N$：根据真实数据标签，把两类的数量相乘：7 x 3 = 21
	- **解读数据**：AUC = 1 说明 **评分值X** 可以完美区分**二分类指标Y**；如果X和Y相互独立，AUC = 0.5 
		- **基于 X 的简单阈值规则，能在多大程度上预测 Y**！！！ --- **用这个 X（模型分数）来做分类，到底好不好使？**
		- **如果 X 指标可以较好的分类，这时候再选取合适的门限**
