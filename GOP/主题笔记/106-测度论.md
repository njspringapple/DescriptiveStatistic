		- **σ-代数的性质**：

	- **“度量” 工具** - 测度与概率：有了 **可测的空间** (Ω,F)，在这个空间放上一个 “**刻度尺**” - **测度**（μ）
		- **测度**：一个把集合映射成数字（长度、面积、个数）的函数。核心要求是 **“可数可加性”**（总长度 = 各段不重叠长度之和）

-  **概率空间**：
	- **结果(Ergebnisse/outcome)**：$\omega$   -- 不一定是一个数，**有可能是个集合**，例如 {1,2} ，具体看 $\Omega$ 定义
	- **结果空间**：$\Omega = \{\omega_{1}, \dots , \omega_{n}\}$
	- **事件(Ereignisse)**：**结果的集合** 称为 **事件（event）**，每个事件都是结果空间的（真或非真）子集，例如：$A = \{1\}$ 是投掷骰子结果为 1，$B = \{2,4,6\}$ 是投掷骰子得到偶数的事件
		- **基本事件**：对于结果 ωᵢ ∈ Ω，单元素集 {ωᵢ} ⊂ Ω 称为**基本事件**
		- **事件集合**：花体大写字幕表示，**集合的集合**
	- **集合运算：**
		- **基础运算**：相等，交，并，子，不相交，补，差
		- **德摩根**：TODO
		- **基数**：|A|，如果 A和B 是有限集合，|AxB| = |A||B|
		- **笛卡尔**：A x B := {(a,b) | a ∈ A, b ∈ B}
		- **可数集合**：有限或者无限的结果空间 ==> 离散型随机变量
		- **不可数集合**：连续型随机变量
		- **集合系（Mengensysteme）**：是以集合为元素的集合
		- **幂集**：$\mathcal{P}(\Omega)$ = {A | A ⊆ Ω} 是 **所有子集的集合**
		- **康托尔定理**：任意集合 A 的基数小于其幂集 P(A) 的基数： |Ω| = 6 < |P(Ω)| = 64
	- **σ-代数（σ-Algebra）**：集合系 $\mathcal{F} \subset \mathcal{P}(\Omega)$ 称为 Ω 上的 σ-代数：    **--- 下面概念是一个引用一个的顺序，必考题！！** 
		- **定义：**
			- $\Omega \in \mathcal{F}$
			- $A \in \mathcal{F} \Rightarrow \bar{A} \in \mathcal{F}$ （**补封闭**）
			- 若 $A_i \in \mathcal{F} (i \in \mathbb{N})$，则 $\cup_i^{\infty} A_i \in \mathcal{F}$   （**可数并封闭**）
		- **最小σ-代数(die kleinste σ-Algebra)**：$\{\emptyset, \Omega\}$
		- **最大σ-代数(die größte σ-Algebra)：**$\mathcal{P}(\Omega)$ - **幂集**
		- **生成σ-代数(die erzeugte σ-Algebra)：** 如果 $A \subset \Omega$，则 $\sigma(A) = \{\emptyset, A, \bar{A}, \Omega\}$ 是：**由 A 生成的 σ-代数，是包含 A 的最小 σ-代数**
		- **生成元(Erzeuger)**：$\mathcal{E} \subseteq \mathcal{P}(\Omega)$ 是一个**集合系**，包含 $\mathcal{E}$ 的 $\sigma$-代数的 **交集** $\sigma(\mathcal{E})$，称为：由 $\mathcal{E}$ 生成的 $\sigma$-代数
			- 包含 $\mathcal{E}$ 的 $\sigma$-代数 **有很多**，这些 $\sigma$-代数 的 **交集** 就是 **最小$\sigma$-代数**：$\Omega=\{1,2,3,4\},\mathcal{E}=\{\{1,2\}\}$，包含 $\mathcal{E}$ 的 $\sigma$-代数 有至少：$A_{1}=\{\emptyset,\{1,2\},\{3,4\},\Omega\}$，$A_{2} = \mathcal{P}$
			- 如果 $\sigma(\mathcal{E}) = \mathcal{A}$，则称 $\mathcal{E}$ 是 $\mathcal{A}$ 的 **生成元** 
			- 举例：$\Omega=\{1,2,3,4\},\mathcal{E}=\{\{1,2\}\}$，为了计算 $\sigma$-代数：
				- **补封闭**：$\{1,2\}^c = \{3,4\}$
				- **同时包含**：$\{\emptyset, \Omega\}$
				- $\sigma(\mathcal{E}) = \{\emptyset, \Omega, \{1,2\}, \{3,4\}\}$
		- **Borel σ-Algebra**：设 $\Omega = \mathbb{R}$，令 $\mathcal{O} = \{\,]a,b[\, \mid a,b \in \mathbb{R},\; a < b\}$ 为开区间系。则 $\mathcal{B}(\mathbb{R}) := \sigma(\mathcal{O})$ 称为 $\mathbb{R}$ 上的 **博雷尔 $\sigma$-代数**，其元素称为 **博雷尔集**
			- **公理要求**：$\emptyset, \mathbb{R} \in \mathcal{B}$
			- **单点集合**：$\{c\} \in \mathcal{B}$
			- **所有区间（闭、半开）**：都属于 $\mathcal{B}$
			- **举例**：求开区间 (1,3) 的 **Borel σ-Algebra**
				- **开区间**：(1,3) 自身就在 Borel集合内
				- **补集**：$\mathbb{R} \ (1,3) = (-\infty,1] \cup [3,+\infty)$ 
				- **可数并**：对 (1,3) 以及 $(1,3)^c$ 并交补
				- **最小的Borel**：$\emptyset, \mathbb{R}, (1,3), (1,3)^c = (-\infty,1] \cup [3,+\infty)$
	- **测度**：
		- **可测性(**Messbarkeit)：** 若 $A \in \mathcal{F}$，则称 $A$ 关于 $\mathcal{F}$ **可测**  ---  $\sigma$ - 代数里面一个元素 $A$（也是个集合）
		- **可测空间(messbarer Raum / Messraum)：** $(\Omega, \mathcal{F})$ 称为 **可测空间**
		- **测度(measure)**：设 $(\Omega, \mathcal{F})$ 为可测空间。函数 $\mu: \mathcal{F} \to [0, +\infty]$ 称为 $\mathcal{F}$ 上的 **测度**  **---- 测度性质可能会考！！！！！！**
			- **空集零测性（Null des leeren Menge / Leermengeneigenschaft）**：$\mu(\varnothing) = 0$
			- **归一化（Normierung）**：若 $\mu(\Omega) = 1$，则称 $\mu$ 为归一化测度
			- **非负性（Nichtnegativität）**：$\mu(A) \ge 0$，对所有 $A \in \mathcal{F}$
			- $\sigma$-**可加性（Additivität）**：对任意两两不交的集合序列 $(A_n)$，有 ：$\mu\left(\bigcup_{n=1}^{\infty} A_n\right) = \sum_{n=1}^{\infty} \mu(A_n)$
			- **有限性（Endlichkeit）**：
				- 若存在 $A_n$ 使 $\bigcup A_n = \Omega$ 且 $\mu(A_n) < \infty$，则称 $\mu$ 为 **$\sigma$-有限**（σ-endlich）
				- 若 $\mu(\Omega) < \infty$，则称 $\mu$ 为有限
			- **差公式**：若 $A \subset B, \mu(A) < \infty$ 则 $\mu(B \text{\\} A) = \mu(B) - \mu(A)$
		- **测度空间**：$(\Omega, \mathcal{F}, \mu)$ -- **可测空间上叠加一个“测度”**
		- **计数测度**: $$\mu_Z(A) = 
\begin{cases}
|A|, & A \text{ 有限} \\
+\infty, & \text{其他}
\end{cases}$$
			
			- **定理3.6**：若 Ω 可数，则计数测度是 σ-有限的。
			- **定理3.7**：限制在可数集 A 上的计数测度 μZ∣A(B)=∣A∩B∣μZ​∣A​(B)=∣A∩B∣ 是 σ-有限的 ？？？
			
		- **勒贝格测度**：勒贝格测度 λ 在 **开区间**  $]a,b[$ 上定义为 $λ(]a,b[) = b−a$
			- **平移不变性**：$λ(A+c)=λ(A)$
			- σ-有限
			- **高维**：$\lambda(]a_1, b_1[ \times \cdots \times ]a_n, b_n[) = \prod_{i=1}^n (b_i - a_i)$
		- **指示函数**：$$\mathbf{1}_A(\omega) = 
\begin{cases}
1, & \text{若 } \omega \in A, \\
0, & \text{否则}.
\end{cases}$$

			- **补**：$\mathbf{1}_{\bar{A}} = 1 - \mathbf{1}_A$
			- **并**：$\mathbf{1}_{A \cap B} = \mathbf{1}_A \mathbf{1}_B$
			- **交**：若 $A \cap B = \varnothing$，则 $\mathbf{1}_{A \cup B} = \mathbf{1}_A + \mathbf{1}_B$
			- **差**：若 $A \subset B$，则 $\mathbf{1}_{B \setminus A} = \mathbf{1}_B - \mathbf{1}_A$
		- **狄拉克测度（Dirac-Maß）**：$\delta_\omega(A) = \mathbf{1}_A(\omega)$
			- 指示函数是看作 “**关于$\omega$**” 的 **函数**，是现有集合 A ，再带入不同的 $\omega$ 得到 0 或者 1。狄拉克测度是先固定点 $\omega$，给不同集合得到 0 或者 1。**测度函数的输入都是集合！！**。
	- **概率测度（Wahrscheinlichkeitsmaß）**：若 $P: \mathcal{F} \to [0,1]$ 是测度且 $P(\Omega) = 1$，则称 $P$ 为 **概率测度**
		- **概率空间**：$(\Omega, \mathcal{F}, P)$  -- $P$ 是测度函数（映射）
		- **例1**：拉普拉斯概率（离散均匀分布）：$P(\{\omega\}) = \frac{1}{|\Omega|}$
		- **例2**：连续均匀分布 $\Omega = (a,b), P((c,d))) = \frac{d-c}{b-a}$，在高维度空间：$P(A) = \frac{\lambda(A)}{\lambda(\Omega)}$  -- **用计数测度来表达概率**
		- **几乎必然（Fast sicher）**:
			- **零测集**：测度为零的集合
			- **μ-几乎处处）**：性质除零集外处处成立         **P-几乎必然）**：概率意义下几乎必然 ??
		- **条件概率**：$P(A|B) = \frac{P(A \cap B)}{P(B)}$      -- **条件概率 * 边缘概率 = 联合概率**      $P(\cdot | B)$ - **是条件概率测度** 
	- **随机变量**：
		- **像与原像（Bild und Urbild）:**  
			- $f: \Omega_1 \to \Omega_2$，将每一个 $\omega_1$ 映射到 $\omega_2$
			- **像**：$f(A) = \{f(\omega) | \omega \in A\}$ -- 例如 f(”红色“) = 1， f("黑色“) = 0,  A = {红色，黑色} 的 ”**像**“ 就是：{1,0}，把事件集合映射成数值集合
			- **原像**：$f^{-1}(B) = \{\omega \in \Omega_1 | f(\omega) \in B\}$ -- 例如 $f^{-1}(1) = \text{红色}$，$f^{-1}(0) = \text{黑色}$，B = {1,0} 的"**原相**” 就是：{红色，黑色}，把数值集合映射成事件集合 ，**原像保持集合运算（并、交、补）封闭！**
			- **重要性质**：若 $\mathcal{F}$ 是 $\sigma$ - 代数，则 $f^{-1}(\mathcal{F})$ 也是 $\sigma$ - 代数
		- **可测映射（Meßbare Abbildungen）：** 
			- **定义**：如果 $f^{-1}({\mathcal{F_2}}) \subseteq \mathcal{F_1}$，则称映射/函数 $f$ 是 $\mathcal{F_1} - \mathcal{F_2}$ 可测的，也就是说这个 $f$ 是可测映射
			- **定理**：**定理4.7**：若 F2=σ(E)F2​=σ(E)，则 f 可测当且仅当 f−1(E)⊆F1f−1(E)⊆F1​。 ？？？？
		- **随机变量（Zufallsvariablen）：** 设 $(\Omega_1, \mathcal{F}_1, P)$ 为 **概率空间**，$(\Omega_2, \mathcal{F}_2)$ 为 **可测空间**，若 $X: \Omega_1 \to \Omega_2$ 是 $\mathcal{F}_1$-$\mathcal{F}_2$ 可测的，则称 $X$ 为随机变量
			- 若 $\Omega_2 = \mathbb{R}$，则称 $X$ 为 ”**实值随机变量**“
			- 若 $\Omega_2 = \mathbb{R}^n$，则称 $X$ 为 $n$ **维随机变量**（或 **随机向量**）
		- **像测度（Bildmaß）与分布：**
			- **像测度**：$\mu_f(B) = \mu(f^{-1}(B))$ 称为 $\mu$ 在 $f$ 下的像测度 --- 注意，就是测度右下角带个可测映射函数 $f$，**测度在原像下的结果  = 像测度在像下的测度** ，$P_X$  就是**像测度**
			- **随机变量的分布(不是分布函数，就是概率)**：$P_X(A) = P(X^{-1}(A))$   ===>  **$P_X(\{1\}) = P(X^{-1}(\{1\})) = P(\{\text{红色}\})$**
			- **几种等价书写方式**：$P_X(A)$，$P(X^{-1}(A))$，$P(X \in A)$，$P_X(\{c\}) = P(X = c)$，$P(\{\omega \in \Omega \mid X(\omega) \in A\})$     ---- 核心是理解 $P_X$ 是像测度，就是**通过随机变量映射后**的集合里面的元素作为参数，映射称为一个**实数**，这个实数也就是概率，这里就是概率的**形式化定义**
				- X 是随机变量，是一个映射，理论上不可能出现 $X \in A$ 这个写法，但是这是一个**简要写法**，意思是通过随机变量 X 映射，所有相成员**映射成一个集合** $A$，也就是 $A$ 是**像空间上的一个子集**！
		- **复合函数**：$(g \circ f)(x) = g(f(x))$   --- **可测函数的复合仍可测**
			- 若 X 是随机变量，g 可测，则 g(X) **也是随机变量**  -- **例如**：X 是随机变量，$X^2$ 也是随机变量
		- **独立随机变量**：
			- **交集**：若 $P(A \cap B) = P(A)P(B)$，则称 ：**事件** $A$ 与 $B$ 相互独立
			- **条件概率**：若 $P(B) > 0$，则 $A \text{ 与 } B \text{ 独立} \iff P(A \mid B) = P(A)$
			- **事件的补**：$A \text{ 与 } B \text{ 独立} \iff A \text{ 与 } \bar{B} \text{ 独立}$
