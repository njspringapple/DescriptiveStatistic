### 概率收敛题

- **写定义**: ,小抄上概率收敛定义写上:  "**Definition der Konvergenz in Wahrscheinlichkeit**　$X_{n}\xrightarrow{P}X \Leftrightarrow P(|X_{n}-X|>\varepsilon)\to0，\forall\varepsilon>0$"

- **转换为求概率**
	1. 根据上面定义写: "$\forall \epsilon > 0$, P(|$X_n - 要证明的收敛的目标,例如 0$|)", 例如, 要证明  $X_n \xrightarrow{P} 0$, **改写为** $\forall \epsilon > 0, P(|X_n - 0| > \epsilon) = P(|X_n| > \epsilon) = ...$
	2. 将 $X_n$ **代入题目给的条件**, 例如: 已知条件是 $P\left(X_n = \frac{1}{n}\right) = P\left(X_n = -\frac{1}{n}\right) = \frac{1}{2}, \quad \forall n \in \mathbb{N}.$ ,  **则转换为** $P(1/n > \epsilon)$

- **加极限后否定不等式**: 
	- 根据题意, 要让证明成立, 即上一步这个概率 在 $n \to \infty$ 情况下, = 0, 也就是 概率表达式中的不等式 **不成立**!!!
	- 例如, 上面例子中就是要证明 $\forall \epsilon > 0, lim_{n \to \infty}(1/n) < \epsilon$
	- 然后可以写: $Sei \quad 1/N = \epsilon \Rightarrow N = 1/\epsilon$, 所以, $n > 1/\epsilon, lim_{n\to \infty}(1/n) < \epsilon$, 因此 $P(|X_n - 0| > \epsilon) \to 0$

- **变体**1
	- 如果是要求收敛到什么值,例如 收敛到 c, 求这个 c
	- 等价于 $lim_{n \to \infty}X_n = c$ , **即求 $X_n$ 的极限值**!!!!!

- **变体2**
	- 如果题目条件没有给 $X_n$ , 但是给了 分布函数 $F_n$
	- 将 $P(|X_n| > \epsilon)$  改为 $1 - P(|X_n| <= \epsilon) = 1 - F_{c}(c + \epsilon) + F_{c}(c - \epsilon)$ 

- **变体3**:
	- 题目告诉你概率收敛到 **常数c**, **等同于告诉你** $lim_{n \to \infty}X_n$ = c
	- 遇到随机变量均值带极限, 并且**有限期望** 和 **独立同分布**, **等同于告诉你** $lim_{n \to \infty}\bar{X_n}  = E(X)$


### 分布收敛题

- **常数 c 的分布函数：**
	- $F_{c}(x) = 0, x < c$
	- $F_{c}(x) = 1, x \geq c$

- **写定义**: $X_{n}\xrightarrow{D}X \Leftrightarrow F_{n}(x)\to F(x)$，只查 $F$ 的连续点

- **写分布**: 根据题目给的信息,写出 $X_n$  和 $X$ 的分布函数区间($F_n$ 和 $F$), 某个区间的值有可能是: **(1) 某个具体的值,例如 0, 1  (2) 一个函数, 例如 2x - 1, (3) 一个抽象的概率, 例如 P(X = 某个值)**

- **检查连续点**:
	- **离散分布**: 因为离散分布,**在跳跃点不连续**, 那就直接检查 **在分布函数定义的所有区间内的点** (连续点), $lim_{n \to \infty}F_n(x) = F(x)$, 例如:
		- 下面是支撑集 {0,1} 上的分布函数, 离散分布, **不检查跳跃点** x = 0, x = 1, 就检查 x < 0, x >= 1, 0 < x < 1 三个区间两个分布值一样, 就说明分布收敛
		- 在某个区间内验证分布值一样,可以用这个区间内的一个点,例如 x = 1/2, $F_n(1/2) = P(X_n=0)$,  $F(1/2) = P(X = 1/2)$   如果依照分布收敛,所以 $P(X_n=1/2) = P(X = 1/2)$
		- $$F_n(x)=
\begin{cases}
0, & x<0,\\[4pt]
P(X_n=0), & 0\le x<1,\\[4pt]
1, & x\ge 1.
\end{cases}$$ $$F(x)=
\begin{cases}
0, & x<0,\\[4pt]
P(X=0), & 0<x\le 1,\\[4pt]
1, & x>1.
\end{cases}$$
	
	- **连续分布**: F 处处连续, 所有点都是连续点, 因此要**检查包含分界点在内的 $F_n$ 的所有点和区间**, 证明 $lim_{n \to \infty} F_n(x) = F(x)$
	
	- **混合分布**: F  既有连续部分又有跳跃点, 只需要**检查所有非跳跃点**，即 F 的连续点 的 $lim_{n \to \infty} F_n(x) = F(x)$.

	- **所谓跳跃点就是:  左极限 != 右极限 != 函数值!!!**

### 几乎必然收敛

- **写定义**: **fast sichere Konvergenz**　$X_n \xrightarrow{a.s.} X\iff P\{\omega \in \Omega: \lim_{n \to \infty} X_n(\omega) = X(\omega)\} = 1$              

- **求极限**
	- 把 $X_n$ 定义代入后, 问题**转换为求极限等于右边**
	- 例如: $X_n : \Omega \to \mathbb{R}, \quad \omega \mapsto n \cdot \mathbf{1}_{(0, \frac{1}{n})}(\omega)$   证明几乎必然收敛为 0
	- **代入** $X_n$,     问题转换为 $lim_{n \to \infty} n \cdot \mathbf{1}_{(0, 1/n)}(\omega) = 0$
	- 因为固定 $\omega$ 和 $n$ ,  $n \cdot \mathbf{1}_{(0, 1/n)}(\omega)$ 可能为 1 也可能为 0, 但是当 n 逐渐变大后, $lim_{n \to \infty} n \cdot \mathbf{1}_{(0, 1/n)}(\omega) = 0$

- 举例: $X_i$ 的方差 $\sigma^2$, 期望 = 0, $Y_i = X_i^2$, 证明 $\bar{Y}$ 几乎必然收敛于一个有限期望

	- 根据几乎必然收敛定义, 要证明, 那就是等价于求解: $lim_{n \to \infty} \bar{Y}$
	- 根据 WLLN, 均值收敛于 E(Y)
	- 求解 E(Y),  $E(Y) = E(X^2) = Var(X) - E(X^2) = \sigma^2 - 0 = \sigma^2$
	- 所以, $lim_{n \to \infty} \bar{Y} = \sigma^2$
	- 所以,  $X_n \xrightarrow{a.s.} \sigma^2$

### Slutsky

- **定理**: 设 $X_n \xrightarrow{D} X,\quad A_n \xrightarrow{P} a,\quad B_n \xrightarrow{P} b$，则 $A_n + B_n X_n \xrightarrow{D} a + bX$
	- 即多个 **随机变量序列**  的线性组合也 **依分布收敛**

	- 举例: $X_1, X_2, ...$, $X_n$ 依分布收敛到 $X$, 其中, $X \sim ~ N(0,1)$, 且 $Y_n$ 依照概率收敛到 2
	- $Z_n = X_n + Y_n$ 根据 Slutsky 定理, **分布收敛到 $X + 2$**,  即 $Z_n \xrightarrow{D} N(2,1)$
