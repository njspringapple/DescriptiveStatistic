#### 2  原子集合，集合总数计算

设
$$
\Omega=\{a,b,c,d,e,f,g,h\},
$$
$$
A=\{a,b,c,d\},
$$
$$
B=\{c,d,e,f\},
$$
$$

$$

1. 确定由 A 和 B 产生的互**不相交的非空基本块**。

	- 通过集合 A 和 B 在全集上做交集与补集运算，得到的**原子集合（atomic sets）**（也叫基本块）
	- **对于 n 个集合，最多产生 2^n 个基本块**
	- 都属于，属于一个不属于另外一个（双边），都不属于
	- 交 - {c,d}   A\B = {a,b}  B\A = {e,f}   \Omega \ （A ∪B） = {g,h}

2. F 包含多少个集合？请说明理由，不必写出所有集合。

	- |F| = 2^4 = 16   (指数就是**基本块数量**)

3. 完整给出 F。

omega，空，{a,b,c,d}，{c,d,e,f}，{e,f,g,h}, {a,b,g,h}, {g,h} {a,b,c,d,e,f}, {a,b}, {c,d,e,f,g,h} {e,f} {a,b,c,d,g,h}, {c,d}, {a,b,e,f,g,h}, {a,b,e,f} {c,d,g,h}

4. 求最小的集合 C ∈ F，使得 {a,c,g} ⊆ C。
 {a,b,c,d,g,h}
**推理过程**：

- 先找出 a,c,g 各自所在的原子；
a \in {a,b}     c \in {c,d}    g \in {g,h} ==> 并集合 {a,b,c,d,g,h}
C =K1∪K2∪K4={a,b,c,d,g,h}.    K1 K2 K 3 是第一小问里面的原子集合
    
- 说明因为不能拆原子，所以必须把整个原子拿进来；
    
- 于是最小的集合就是这几个原子的并。

这一部分有意放在统计 II 主体之后。它只复习那些直接为测度论做准备的基本工具。

**概念帮助：学习前提**

- 元素 / 子集：$x\in A$ 表示 x 是 A 的一个元素。B 是 A 的子集表示 B 的每个元素也在 A 中。特别地，x 和 $\{x\}$ 是不同的对象。
- 集族：$\Omega$ 上的集族 M 是 $\Omega$ 的一些子集组成的集合，即 $M\subseteq\mathcal{P}(\Omega)$。因此它的元素本身也是集合。
- 结果 / 事件：在统计语境中，$\omega\in\Omega$ 称为结果，$\Omega$ 称为结果空间。σ-代数 F 中的可测集 A 称为事件；F 是事件空间。结果 ω 本身也可以是集合。
- 关系 / 等价关系：X 上的关系 R 是 $X\times X$ 的子集。若它自反、对称且传递，则称为等价关系。
- 部分和：对于项 $a_i$ 组成的级数，$S_n=a_1+\cdots+a_n$。若部分和收敛，其极限就是无穷级数的和。
- 阶梯函数：阶梯函数在有限多个区间上分别取常值。它的黎曼积分是区间长度乘函数高度之和。

**概念帮助：模型与分布**

a) 每个连续分布函数都有勒贝格密度。

b) 若 X 有勒贝格密度 $f_X$，则对每个 x 都有 $P(X=x)=f_X(x)$。

c) 两个只在有限多个点处不同的密度总是描述不同的分布。

d) 若 $F_X$ 在 x 处连续，则 $P(X=x)=0$。

e) 两个互不相交且各自有正概率的事件是独立的。

f) 若 X 和 Y 独立，则对所有 Borel 集 A 和 B，$\{X\in A\}$ 与 $\{Y\in B\}$ 独立。

> 特别注意一个说法是逐点、几乎处处还是在概率层面表述的。
