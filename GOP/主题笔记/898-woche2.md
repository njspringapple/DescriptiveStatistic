实验的结果记录为所得到的最大点数：

$$M = \max\{X_1, \ldots, X_n\}.$$
(a) 随机变量 $X_1, ..., X_n$ 服从什么分布？请给出支撑集、概率质量函数、期望和方差。
- X~ U({1,2,...,K})
- P(X = k ) = 1/K
- E(X) = (K+1)/2
- Var(X)=(K^2-1)/12
(b) 证明 M 的分布函数由下式给出：

$$
F_M(x) =
\begin{cases}
0, & x < 1, \\[4pt]
\left( \dfrac{\lfloor x \rfloor}{K} \right)^n, & 1 \le x < K, \\[4pt]
1, & x \ge K
\end{cases}
$$

请特别解释，为什么在 1 ≤ x < K 时会出现向下取整函数 ⌊x⌋。
- P(M <= x) = P(max{X_1,...,X_n} <= x) = P(X_1 <= x)...P(X_n <= x)
- 对于投掷一次筛子，X ~ U{1,2,...,K}
- P(X = k) = f_X(x) = 1/K
- P(X_i <= x) = x/K
- 所以 P(M <= x) = (x/K)^n
- 所以 F_M(x) = 
	- x < 1, 0
	- 1 <= x < K,  (下取整（x）/K)^n
	- x >= K, 1
- 因为是离散均匀分布 x，不可能出现 x 和 下取整（x) 中间的数，例如 x = 2.7， 不存在这个点数，所以下取整为 2
(c) 由 M 的分布函数推导出概率质量函数 P(M = m)，其中 m ∈ {1, ..., K}
- P(M = m) = F(m) - F(m-1) = (m/K)^n - ((m-1)/K)^n = (m^n - (m-1)^n)/K^n
(d) 考虑 K = 4 且 n = 3 的情形。计算期望 E[M] 和方差 Var(M)。

- K = 4, n = 3
- P(M = m) = (m^3 - (m-1)^3)/64
- F_M(m) = m^3/64
