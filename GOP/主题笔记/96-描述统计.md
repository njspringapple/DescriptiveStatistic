- **图形语法（Grammar of Graphics）**：统计图形通过几何对象的 **美学属性** 来表示数据集中某些特征的 **表现/取值**
	- **数据（变量/特征）**  **Daten (Variablen/Merkmale)**
	- **几何对象** **geometrische Objekte（Geom）**
		- **Points** 散点图 / **Lines** 折线图 / **Bars** 柱状图 / **Boxplots** 箱线图 / **Histogram** 直方图 /**Areas** 面积图
	- **美学属性** **ästhetische Eigenschaften (Ästhetiken)**
		- **位置**：position / **颜色**：colour / **填充色**：fill / **大小**：size （针对点/线）/ **形状**：shape （点的不同符号，例如 ★，●，▲等）/ **线形**：linetype（例如 直线，虚线）
	- **标度水平 Scales**：**名义标度 Nominalskala / 顺序标度 Ordinalskala（有序，可比较大小） / 区间标度 Intervallskala（间距有意义，可计算性） / 比率标度 Verhältnisskala/绝对尺度（Absolutskala）**
	- **标度（Scales）**、**坐标系（Koordinatensysteme）**、**分面（Facets）**  **数据转换**（**Datentransformationen**）**统计量(Statistiken)** **主题（Theme）** 等
	- **图形的感知**（Wahrnehmungvon Grafiken）：人们对以下几种图形类型的**正确解读程度**存在显著差异：
		- **位置 > 长度（Abstände & Längen） > 角度(Steigung & Winke) > 面积(Flächen) > 体积（Volumen） > 色相（饱和度 - 明度 Farbton-Farbsättigung-Farbhelligkeit） ...**
		- 由于**位置**和**间距**的感知效果最好，因此应当用它们来编码最重要的特征
	- **图形设计的黄金法则(Goldene Regeln für Grafikgestaltung)**
		- **理解图形需要 Verständnis von Grafiken erfordert **:
			- **检测Detektion** ：识别哪些 **几何元素** 和 **美学属性** 代表哪些数值
			- **综合Synthese**：对检测到的内容进行 **分组** 并将其 **关联** 起来
			- **评估Evaluation**：评估这些内容的 **相对大小** 和 **重要性**
		- **全部三个阶段都通过有意识的选择来支持**  alle drei Phasen unterstützt durch bewusste Wahl
			- **选择合适的审美属性与几何形式** geeigneter Ästhetiken & Geometrien (s.o.: Abstände > Farbe, etc.)
			- **选择合适的坐标轴、网格线和宽高比** geeigneter Achsen, Gitterlinien und Seitenverhältnisse
			- **对定性特征的不同表现进行内容上恰当的排序/排列顺序** inhaltlich adäquater Sortierung/Reihenfolge der Ausprägungen qualitativer Merkmale
			- **相应的标注与突出显示** entsprechender Annotationen & Hervorhebungen 
		- **明确沟通意图**：我主要想传达哪些信息？附加传达哪些？应引导注意力投向哪些比较？Kommunikationsabsicht klarmachen: Welche Informationen will ich primär vermitteln? Welche zusätzlich? Auf welche Vergleiche soll Aufmerksamkeit gelenkt werden?
		- **最大化可读性**：准确性与速度/难度同样重要  Lesbarkeit maximieren– sowohl Genauigkeit als auch Geschwindigkeit/Schwierigkeit sind wichtig
- **颜色感知（Farbwahrnehmung）**：
	- **需兼顾视觉缺陷**（**色弱/色盲**） Sehschwächen mitbedenken
	-  为图形选择颜色时，**应考虑感知一致性** Farben für Grafiken so wählen dass Wahrnehmungseinheitlichkeit berücksichtigt wird
		- **同样的颜色 = 同样的类别**
		- **同样的亮度 = 同样的数值**
		- **视觉上的“突出” = 信息上的“重要”**
	- **在相同饱和度下，绿色/黄色调 比其他颜色感知更强烈** Grün-/Gelbtöne werden bei gleicher Sättigung intensiver wahrgenommen als andere Farben
	-  **色彩空间**：
		- HCL - 色相-彩度-亮度 **hue-chroma-luminance**
		- HSV -色相-饱和度-明度  **hue**-**saturation**-**value**   
	- **颜色选择方法**：
		- **名义尺度**：在 **饱和度** 与 **明度** 恒定（针对人类感知进行校正）的情况下**变化色相**
		- **序列型**：**色相** 和 **饱和度** 恒定，仅变化 **明度**
		- **低明度** 编码的值具有最高的 **显著性** Höchste Prägnanz für Werte die mit niedriger Helligkeit kodiert werden.
		- **发散型颜色标度** 将 **两条各自色相恒定** 的序列型标度组合在一起 **“中性”中间值**：标度的 **上下两端** 具有 **最高的显著性** Divergierende **Farbskalen**

	- **图形选择方法**：
		- **钉形图 / 柱形图 / 条形图(Lines/Bars)**
			- **有序 / 名义特征
			- **取值较少的度量特征**（如少量离散数值）-- 如果 度量特征多，竖着的柱子（Bar）太多看不清
		- **堆叠图（Stack）**
			- **有序 / 名义特征**
			- **取值较少的度量数据** - -- 如果 度量特征多，竖着的柱子（Bar）太多看不清
			- **特别适合：** 通过并列堆叠来 **比较不同组别** 的分布（**即条件频数**） -- **注意：** 需区分展示的是 **相对频数（占比）** 还是 **绝对频数（数量）**
		- **饼图 / 扇形图（Pie）**
			- **有序 / 名义特征**
			- **缺点：** **人眼对面积的判断不如对长度敏感**  **Das menschliche Auge kann Flächen weniger genau beurteilen als Längen**
		- **点图（一维散点图）（Point）**
			- 展示 **"单个einzeln"** 观测值的分布
			- 可选地通过 y 轴引入 **分组变量 Gruppierungsvariable，展示不同组别的取值分布（多根横线对应Y值，横向散点）
			- **特点：** **保留原始数据细节，适合探索性分析** **Beibehaltung der Details der Rohdaten, geeignet für explorative Analysen**
		- **直方图（Histogram）**
			- **至少为区间尺度 Intervallskala**
			- **连续度量数据 stetige metrische Daten** 的 **分组频数 Klassenhäufigkeit 分布，直方图的条形之间通常 **无间隙(ohne Lücken)**
			- 用于展示数据的 **分布形态 Verteilungsform（如 偏态 Schiefe、峰值 Wölbung** 等）

- **直方图**：
	- 适用于 至少为 **区间尺度（Intervallskala）** 的 **频数分布(Häufigkeitsverteilung)** 的图形类型
	- 通过 **面积(Fläche)** 来表示 **相对频数(relative Häufigkeit)**（面积守恒原则）
	- 因为直方图的 **各组的组距 Klassenbreite）可能不一样**，只有用“**面积**”才能公平地表示 **相对频数**，才能进行**比较**
	- **步骤**：
		- **划分组距 Klassenbreite**（若数据尚未分组），得到 $b_{j}$
		- 确定各组 **绝对频数** $n_j$​ 和 **相对频数** $f_j = \frac{n_j}{n}$​
		- 确定直方图的高度：$H_{j} = \frac{f_{j}}{b_{j}}$，其中，$b_{j}$ 为 第 j 组的 **组距（组宽)**
	- **面积 = 相对频数** ：$S = b_{j} \cdot \frac{f_{j}}{b_{j}} = f_{j}$ 
	- **密度Dichte**：密度函数在任意区间下的面积应大致等于这些区间内的相对频数，$\int_a^b f(x)\,dx \approx \frac{1}{n} \left| \{ x_i : a < x_i \le b \} \right|$，连续分布的密度函数和直方图多匹配，**取决于组距选择，组距越小越接近**
	- **优点**：
		- **图形形态直观可见，如多峰性和偏态性**
		- **组距较小或者数据较大，逼近密度函数**
	- **缺陷**：
		- **不同的组距，图形不一样**
		- **即使组距相同，但是组段边界不一样，图形也不一样：**
			- 10 个学生成绩：52, 58, 61, 63, 67, 72, 74, 78, 81, 86
			- 场景一：从 50 开始，组距 10，【50，60】、【60，70】，【70，80】，【80，90】
			- 场景二：从 45 开始，组距 10，【45，55】、【55，65】，【65，75】，【75，85】，【85，95】  
			- 这两个场景出来的直方图不一样
		
- **核密度估计器 KDE-Diagramm/Kerndichtediagramm：
	- **用途**：
		- 直方图有个死穴：**分组一变，图形就变**
		- **用有限的数据样本，去“猜”出背后那个看不见的真实分布形状**
		- **数据密集的地方，密度曲线就高；数据稀疏的地方，密度曲线就低**
	- **密度函数** $$\hat{f}(x) = \frac{\frac{1}{n}|{x_{i}:x_{i} \in [x-h,x+h]}|}{2h} = \frac{1}{n}\Sigma_{i=1}^n \frac{1}{h}  k(\frac{x-x_{i}}{h}) = \frac{1}{nh}\Sigma_{i=1}^n k(\frac{x-x_{i}}{h})$$
		- **平滑参数** - h
		- **数据总数** - n
		- 对于一个固定的 x，有多少个 **观测值** $x_i$​ 落在这个区间里
		- **核函数 k** ：
			- **核函数要求**：$\int_{-\infty}^{+\infty}k(u)du = 1$
			- **高斯核函数**：。。。
			- Epanechnikov-Kern ： 。。。
			- **不同的核函数！！！！！** 。。。。
			- **矩形核** - $k(u) = \frac{1}{2}, -1 \leq u \leq 1, k(u) = 0, u 为其他值$
			- 看核密度函数，在每一个观察点 $x_{i}$ 点，都通过 **核函数** 构造一个 “**小鼓包**”，最后的核密度函数是 **所有的核函数叠加的结果**。
		- **和直方图差异**：
			- **直方图**：把数据划分成若干个**固定组段（区间）**，数每个组段里有多少个观测值，**阶梯状**（矩形条，条与条之间无间隙），关键参数：**组距（Klassenbreite）** 和 **组段边界（Klassengrenzen）**
			- **核密度图**：以每个数据点为中心放置一个“核函数（小鼓包）”，再把这些鼓包**叠加**起来，**光滑的连续曲线**，关键参数：**带宽（Bandbreite hh）**，核密度估计**尤其在数据量较大**和（准）连续特征时 **优于直方图**
			- 直方图不考虑观测值在组段内的具体位置，只统计组段边界内的观测值个数
			- 在位置 x 处的核密度估计则考虑了邻近点与 x 的距离，并采用随距离递减的加权方式
		- **不同带宽影响**：
			- **h 过小** ： 锯齿状，多峰，不稳，把随机噪声页当成真实结构
			- **h 最优**：  光滑 且保留主峰
			- **h 过大**： 过于扁平，细节全部丢失
