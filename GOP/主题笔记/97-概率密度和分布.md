- **概率 $P(A)$** 表示事件 $A$ 发生的可能性。
	  - $P(A) = 1$ → $A$ 必然发生
	  - $P(A) = 0$ → $A$ 必然不发生
	  - $P(A) = p \in (0,1)$ → $A$ 以概率 $p$ 发生
- **随机：**
	- **结果（结果）$\omega$**：随机试验的一个可能结果。
	- **随机总体（样本空间）$\Omega$**：所有可能结果 $\omega$ 的集合。又称基本空间、结果空间。
	- **事件 $A$**：$\Omega$ 的**任意子集** $A \subseteq \Omega$。
	- **基本事件 $\{\omega\}$**：只含一个结果 $\omega$ 的子集。每次试验恰有一个基本事件发生。
- **拉普拉斯古典概率**：设 $\Omega = \{\omega_1, \omega_2, \dots, \omega_n\}$ 为有限样本空间， $|A|$ 表示 $A$ 中元素的个数，事件 $A \subseteq \Omega$ 的拉普拉斯概率为：$P(A) = \frac{|A|}{|\Omega|} = \frac{|A|}{n},$
	- 每个基本事件 $\{\omega_i\}$ 的概率为 $1/n$。
	- $P(\Omega) = 1$。
	- 映射 $P: \mathcal{P}(\Omega) \to [0,1]$ 称为 $\Omega$ 上的 **离散均匀分布**（$\mathcal{P}(\Omega)$ 是幂集，勿与概率 $P$ 混淆）。
	- 并集 $A \cup B$ 表示“$A$ 或 $B$ 或两者都发生”；交集 $A \cap B$ 表示“$A$ 和 $B$ 同时发生”
- **组合数**：
	- 无放回、无序：$\displaystyle \binom{n}{k} = \frac{n!}{(n-k)!\,k!}$
- **柯尔莫哥洛夫公理（概率公理化）**
	- **基本定义**
		- **不相交事件**：$A \cap B = \varnothing$（不能同时发生）。
		- **对立事件/补事件**：$\bar{A} = \Omega \setminus A$（$A$ 不发生）。$A$ 与 $\bar{A}$ 不相交。
	- **柯尔莫哥洛夫公理**：设 $\Omega$ 为任意（可数）样本空间，$P$ 为定义在幂集 $\mathcal{P}(\Omega)$ 上的函数，若满足：
		- **A1（非负性）**：$P(A) \ge 0$，$\forall A \subseteq \Omega$
		- **A2（归一性）**：$P(\Omega) = 1$
		- **A3（可加性）**：若 $A \cap B = \varnothing$，则 $P(A \cup B) = P(A) + P(B)$
		则称 $P$ 为 $\Omega$ 上的**概率分布**。
	- **性质**
		- 有限可加性：对两两不相交的 $A_1,\dots,A_n$，$P(\bigcup_i A_i) = \sum_i P(A_i)$
		- 单调性：若 $A \subseteq B$，则 $P(A) \le P(B)$
		- 补事件：$P(\bar{A}) = 1 - P(A)$
		- **一般加法公式（两个集合的 ”容斥定理“ ）**：$P(A \cup B) = P(A) + P(B) - P(A \cap B)$
- **条件概率(bedingte Wahrscheinlichkeit)**：对事件 $A, B$，且 $P(B)>0$，则**给定 $B$ 下 $A$ 的条件概率**为：$P(A|B) = \frac{P(A\cap B)}{P(B)}.$
	- $P(B|B)=1$，$P(\bar{B}|B)=0$，$P(A|B)\ge 0$
	- 固定条件 $B$ 后，条件概率 $P(\cdot|B)$ 也是样本空间 $B$ 上的概率分布，满足所有概率公理。
	- **多次条件化** 等价于 **对交集条件化**：$P((A|B)|C) = P(A | B\cap C)$
	- **乘法法则（链式法则)**：若 $P(A_1\cap\cdots\cap A_n)>0$，则  $P(A_1,A_2) = P(A_1)\cdot P(A_2|A_1)$  ，通用形式：$P(A_1\cap\cdots\cap A_n) = P(A_1)\cdot P(A_2|A_1)\cdot P(A_3|A_1\cap A_2)\cdots P(A_n|A_1\cap\cdots\cap A_{n-1}).$
	- **全概率公式**：$P(A) = P(A|B)P(B) + P(A|\bar{B})P(\bar{B})$。若 $\{B_1,\dots,B_n\}$ 构成 $\Omega$ 的一个**分割**（两两不相交且并集为 $\Omega$，且 $P(B_i)>0$），**则对任意事件** $A$：$P(A) = \sum_{i=1}^n P(A|B_i)\,P(B_i).$
- **随机独立性(stochastische Unabhängigkeit)**：
	- **两个事件的独立性**：一个事件发生不改变另一个事件发生的概率。$A$ 与 $B$ 独立 $\iff$ $P(A\cap B) = P(A)\cdot P(B)$，记为 $A \perp B$。  
		- 独立性与补事件相互继承：$A\perp B \iff \bar{A}\perp B \iff A\perp \bar{B} \iff \bar{A}\perp \bar{B}$。
		- **例：连续掷两次公平骰子**  ：$A$=“第一次出6”，$B$=“第二次出6”。若独立，则 $P(A\cap B)=1/36$。  
	- **多个事件的独立性**：事件 $A_1,\dots,A_n$ 独立，若对任意子集 $I$（指标集）有  $P\left(\bigcap_{i\in I} A_i\right) = \prod_{i\in I} P(A_i).$
		- **两两独立不能推出整体独立！！**
	- **条件独立性**：给定 $C$（$P(C)>0$），$A$ 与 $B$ 条件独立 $\iff$  $P(A\cap B|C) = P(A|C)\cdot P(B|C)$，记为 $(A\perp B)|C$。
		- **注意**：条件独立 $\not\Rightarrow$ 无条件独立；无条件独立 $\not\Rightarrow$ 条件独立。
- **贝叶斯定理(Satz von Bayes)**：$P(A|B)P(B) = P(A\cap B) = P(B|A)P(A)$  $\Rightarrow P(B|A) = \frac{P(A|B)P(B)}{P(A)} = \frac{P(A|B)P(B)}{P(A|B)P(B) + P(A|\bar B)P(\bar B)}.$
	- **标准形式**：更一般地，对**分割** $B_1,\dots,B_n$：$P(B_i|A) = \frac{P(A|B_i)P(B_i)}{\sum_{j=1}^n P(A|B_j)P(B_j)}.$
	- **术语解释**
		- **先验概率 $P(B_i)$**：**在看到数据 A 前对假设 $B_i$ 的信念**。
		- **似然 $P(A|B_i)$**：在假设 $B_i$ 下观测到数据 $A$ 的可能性。
		- **后验概率 $P(B_i|A)$**：观测到数据 **A** 后对假设 **$B_i$** 更新后的信念。
		- 贝叶斯定理提供了**更新规则**：数据如何改变假设的 plausibility。
	- **举例**：--- 补充一个例子
	- **优势和优势比**：
		- **优势(Odds)**：**某个事件自身** 发生与不发生的概率之比。它是一个**绝对值**，描述的是“该事件本身有多大概率发生”。
			- **公式**：$\displaystyle \gamma(A) = \frac{P(A)}{1-P(A)} \in [0,\infty]$
			- **概率与 odds 互转**：$P(A) = \dfrac{\gamma}{1+\gamma}$
		- **优势比(Odds Ratio)**：**两个不同条件下**（或两个不同群体）的 Odds 之比。它是一个**比值**，描述的是“**这个条件对事件概率的影响有多大**”。
		- **贝叶斯定理的 odds 形式（带条件的优势比）**： -- 用贝叶斯公式简单推导 $\frac{P(B|A)}{P(\bar B|A)} = \frac{P(B)}{P(\bar B)} \cdot \frac{P(A|B)}{P(A|\bar B)}$
	- **举例**：$K$ = “患病”，$T$ = “检测阳性”，已知：灵敏度 $P(T|K)=0.8$，特异度 $P(\bar{T}|\bar{K})=0.99$，患病率 $P(K)=0.001$
		- 求：阳性预测值(ppV) $P(K|T)$ 和 阴性预测值(npV) $P(\bar{K}|\bar{T})$
		- **方法1**：
			- **贝叶斯公式**：$P(K|T) = \frac{P(T|K) \cdot P(K)}{P(T)}$
			- **全概率公式**：$P(T) = P(T|K)P(K) + P(T|\bar{K})P(\bar{K}) = 0.8 \times 0.001 + (1-0.99) \times (1-0.001) = 0.01079$
			- 所以，$P(K|T) = \frac{0.8 \times 0.001}{0.011} = 0.073$
		- **方法2**：**列联表方式，把混淆矩阵画出来最重要！！**
			- **灵敏度** = TP / (TP + FN) = 0.8 , 所以，假设有100个实际患者，回填列联表（**混淆矩阵**）
			- **患病率** = P(K) = 0.001, 所以，得到总人数是 100 x 1000 = 100,000, 未患病 = 100,000 - 100 = 99,900
			- **特异度** = TN / (TN + FP)，所以 TN = 99,900 x 0.99 = 98901，所以 FP = 99,900 - 98,901 = 999
			- **阳性预测值** = ppV = TP / (TP + FP) = 80 / (80 + 999) = 0.074
			- **阴性预测值** = npV = TN / (TN + FN) = 98901 / （98901 + 20 ） = 0.999
		- **先验和后验**：
			- **先验**：所谓先验就是我们还没有进行测试的时候的”**心里认为的信念**“，例如这里患病的”**先验概率**" - $P(K)$
			- **后验**：在进行了若干测试后，“**心理认为的概率**” 会发生变化，例如这里的患病的“**后验概率**” - $P(K|T)$ ，即在 T 条件下的时候患病概率
			- **先验赔率**：知道了“**先验概率**”，自然可以知道“**先验赔率**” - $\gamma(K) = \frac{P(K)}{1-P(K)}$
			- **后验赔率**：知道了“**后验概率**”，自然可以知道”**后验赔率**“ - $\gamma(K|T) = \frac{P(K|T)}{1 - P(K|T)}$  --  假如算出结果 1/13， **解释为：约每13个阳性结果中仅1人真患病（在检测出这个条件下患者1，健康12）**
			- **似然比**：**后验赔率 / 先验赔率** = $\frac{P(T|K)}{P(T|\bar{K})}$  = $\frac{P(检测阳性|病人)}{P(检测阳性|健康人)}$， **很明显，应该分子越大越好，分母越小越好，这样说明方法越有效果!!**
				- **下面计算带入贝叶斯标准公式展开化简**
				- 根据灵敏度和特异度定义，**似然比 LR = $灵敏度 / (1-特异度) = 灵敏度 / (1-假阳率)$**
				- 不难看出，这就是 ROC 曲线上点的斜率，**LR 越大**，说明阳性结果的“**证据越强**” （似然比**越偏离 1**（ROC中间对角线），数据对假设的判别力越强）
			$$\begin{aligned}
\frac{P(K|T)}{P(\bar{K}|T)} \cdot \frac{P(\bar{K})}{P(K)}
= \frac{\frac{P(T|K) P(K)}{P(T)}}{\frac{P(T|\bar{K}) P(\bar{K})}{P(T)}} \cdot \frac{P(\bar{K})}{P(K)}
= \frac{P(T|K) P(K)}{P(T|\bar{K}) P(\bar{K})} \cdot \frac{P(\bar{K})}{P(K)}
= \frac{P(T|K)}{P(T|\bar{K})}
\end{aligned}$$

- **绝对频数与相对频数**：设观测值为 $x_1, \dots, x_n$（ **n 个原始数据** ），不同的取值记为 $a_1, \dots, a_k$ （ **k个不重复的值** ）
	- **绝对频数**：$h(a_j) = h_j$ -- $h(\cdot)$ 函数是获取不同取值的数在原始数据中的“**数量**”
	- **相对频数**：$f(a_j) = f_j = \frac{h_j}{n}$ -- $f(\cdot)$ 函数是不同取值的数在原始数据中的“**比例**”
	- **绝对频数分布**：$h_1, \dots, h_k$
	- **相对频数分布**：$f_1, \dots, f_k$

- **支集**（Träger）：
  $T_X = \{ x \in \mathbb{R} : P(X = x) > 0 \}$

- **随机变量**：随机变量 $X$ 是一个映射：$X: \Omega \to T_X \subseteq \mathbb{R}$，它将每个基本事件 $\omega \in \Omega$ 映射到一个实数 $X(\omega)$
---
- **离散型随机变量(diskrete Zufallsvariable)**：
	- **定义：若 $T_X$ 是有限集或可数无限集，则称 $X$ 为 离散型随机变量。
	- **概率质量函数**（Probability Mass Function, PMF）：$f_X(x_i) := P(X = x_i) = P(\{\omega \in \Omega : X(\omega) = x_i\})$
		- 性质：
			- $f_X(x) \geq 0$
			- $\sum_{x \in T_X} f_X(x) = 1$
			- 若 $x \notin T_X$，则 $f_X(x) = 0$
	- **分布函数 Verteilungsfunktion（离散型）**：$F_X(x) := P(X \leq x) = \sum_{i: x_i \leq x} f_X(x_i)$
		- 性质
			- $F(x)$ 是**单调递增的 “阶梯函数” **
			- 在 $x_i \in T_X$ 处有跳跃，跳跃高度为 $f_X(x_i)$
			- $\lim_{x \to -\infty} F(x) = 0, \quad \lim_{x \to \infty} F(x) = 1$
---
- **连续型随机变量(stetige Zufallsvariable)**：
	- **密度函数（Probability Density Function, PDF）**：函数 $f_X(x)$ 称为 $X$ 的**概率密度函数**。
		- 性质：
			- $f_X(x) \geq 0$
			- $\int_{-\infty}^{+\infty} f_X(x) \, dx = 1$
	- **分布函数 Verteilungsfunktion（连续型）**：若存在非负函数 $f_X(x) \geq 0$，$F_X(x) = P(X \leq x) = \int_{-\infty}^{x} f_X(u) \, du$
	- **性质（连续型）：**
		- $F(x)$ 是**连续**且**单调递增**的
		- $\lim_{x \to -\infty} F(x) = 0, \quad \lim_{x \to \infty} F(x) = 1$
		- 在 $f$ 连续的点上：$F'(x) = f(x)$  -- **分布函数导数是密度！**
	- **点概率(Punktwahrscheinlichkeit)**：对于任意 $x \in \mathbb{R}$：$P(X = x) = 0$ ！！！！！！**因为**：$\int_x^x f(u) \, du = 0$
	- **区间概率(Intervallwahrscheinlichkeit)**：$P(a \leq X \leq b) = \int_a^b f(x) \, dx = F(b) - F(a)$
	- **尾概率(Randwahrscheinlichkeit)**：$P(X > a) = 1 - F(a)$

-  **条件频率（die bedingte Häufigkeit）**
	- 从联合频数 $h_{ij}$（或 $f_{ij}$）**直接判断关联较困难**。
	- 因此考察**条件频率**，**即固定一个特征取值时另一个特征的分布**。
	- **规则**：条件频率 = 单元格频数 / 对应的行（或列）合计。
		- 给定 $X = a_i$ 时 $Y$ 的条件分布（$Y|X=a_i$）：$f_{Y|X}(b_1|a_i) = \frac{h_{i1}}{h_{i\cdot}},\ \dots,\ f_{Y|X}(b_m|a_i) = \frac{h_{im}}{h_{i\cdot}}.$
		- 给定 $Y = b_j$ 时 $X$ 的条件分布（$X|Y=b_j$）：$f_{X|Y}(a_1|b_j) = \frac{h_{1j}}{h_{\cdot j}},\ \dots,\ f_{X|Y}(a_k|b_j) = \frac{h_{kj}}{h_{\cdot j}}.$

- **离散相关性分析**：**优势比**（Odds）
	- $2\times2$ 列联表，假设 **$X$ 定义两个子人群**，$Y$ 是 **二值目标变量**
	- **条件优势（odds）**：在子人群 $X=a_i$ 中，$Y=1$ 与 $Y=2$ 的频数之比：  $\gamma(Y|X=a_i) = \frac{h_{i1}}{h_{i2}}.$

| $X \backslash Y$ | 1             | 2             | 合计           | Odds                                                                                                        |
| ---------------- | ------------- | ------------- | ------------ | ----------------------------------------------------------------------------------------------------------- |
| 1                | $h_{11}$      | $h_{12}$      | $h_{1\cdot}$ | $Odds_{X=1} = \gamma(Y_{1},Y_{2} \| X_{1}) = \frac{h_{11}}{h_{12}}$                                         |
| 2                | $h_{21}$      | $h_{22}$      | $h_{2\cdot}$ | $Odds_{X=2} = \gamma(Y_{1},Y_{2} \| X_{2}) = \frac{h_{21}}{h_{22}}$                                         |
| **合计**           | $h_{\cdot 1}$ | $h_{\cdot 2}$ | $n$          | $OR = \frac{Odds_{X=1}}{Odds_{X=2}} = \gamma(Y_{1},Y_{2}\|X_{1},X_{2}) = \frac{h_{11}h_{22}}{h_{12}h_{21}}$ |
- **优势比**（**Odds Ratio, OR**）两个子人群的优势比：$OR = \gamma(Y=1,Y=2|X=1, X=2) = \frac{\gamma(Y=1,Y=2|X=1)}{\gamma(Y=1,Y=2|X=2)} = \frac{h_{11}/h_{12}}{h_{21}/h_{22}} = \frac{h_{11}h_{22}}{h_{21}h_{12}}.$，**也称为 交叉乘积比**
	- **书写注意**：$\gamma(Y=1,Y=2|X=1, X=2)$  意思是 **在 X = 1 和 X = 2 两个条件下，计算 Y = 1，Y = 2 这两个数据的优势后，再做除法，进行对比**
	- **解释**：
		- $\gamma = 1$：两个子人群的优势相同（无关联）
		- $\gamma > 1$：子人群 $X=1$ 中 $Y=1$ 的优势更大
		- $\gamma < 1$：子人群 $X=1$ 中 $Y=1$ 的优势更小
	- **对称性**：优势比对称于行列交换，即 $\gamma(Y=1,Y=2|X=1,X=2) = \gamma(X=1,X=2|Y=1,Y=2)$ 等，即：$OR_{X|Y} = OR_{Y|X}$

- **独立性与列联**
	- **经验独立性**：若 $X$ 和 $Y$ “**经验独立**”，则 $Y$ 的分布不受 $X$ 影响，即所有条件分布相同，**这等价于所有局部优势比均为 1**
		- **证明**：$$\text{经验独立} 
\iff P(Y=b_j\mid X=a_i)=P(Y=b_j)\ \forall i,j
\iff \frac{P(Y=b_{j_1}\mid X=a_{i_1})\big/ P(Y=b_{j_2}\mid X=a_{i_1})}{P(Y=b_{j_1}\mid X=a_{i_2})\big/ P(Y=b_{j_2}\mid X=a_{i_2})}=1\\
$$
- **期望频数（die erwartete Häufigkeit）**：在列联表里面找一个“格子”，看这个格子的 行 和 列 的总数，即 $h_{i\cdot} \, h_{\cdot j}$  ，所有数据总数为 $n$，根据公式计算期望频数：$\tilde{h}_{ij} = \frac{h_{i\cdot} \, h_{\cdot j}}{n}$
	- 例如：无学历，短期失业这个格子数字：86，无学历总人数 123，短期失业总人数 324，采样总人数 447，所以期望频数 = (123 x 324) / 447 = 89.15
	- 89.15 和 86 **非常接近**，说明：**一个失业者的教育水平，和他属于哪种失业类型（短期/中期/长期）毫无关系**

-  **$\chi^2$ 系数（卡方系数）** -- 超过 2 x 2 的列联表计算卡方统计量太复杂，不可能让手算，重点知道利用 **卡方统计量** 计算 **列联系数和矫正列联系数**
	- **算法步骤**：
		1. 计算每个格子的 “**期望频数**” - $\tilde{h}_{ij}$
		2. 计算每个格子对整体**卡方统计量的贡献** -  $\frac{(h_{ij} - \tilde{h}_{ij})^2}{\tilde{h}_{ij}}$
		3. **卡方统计量** = **每个格子的卡方统计量求和**
		4. **查卡方分布表** ($\alpha  = 0.05$) 是 3.84
		5. 比较卡方统计量和3.84，**如果远远大于3.84，说明 X 和 Y 有显著关联**
		6. **计算列联系数** ：$K = \sqrt{\frac{\chi^2}{n + \chi^2}}$，计算出来结果取值范围：$K \in [0,\sqrt{ \frac{M-1}{M} }]$，**因此，需要矫正，归一化**
		7. **计算矫正列联系数**：$M = min\{行数,列数\}$ ，$K^* = \frac{K}{\sqrt{(M-1)/M}}$，取值范围 $K^* \in [0,1]$， **0 - 关联极弱，1 - 关联极强**
	- **2 x 2 列联表的简化计算**：
		1. $\chi^2 = \frac{n(ad - bc)^2}{(a+b)(a+c)(b+d)(c+d)}.$

|                  | **阳性/患病 (Y=1)** | **阴性/健康 (Y=2)** | 合计  |
| ---------------- | --------------- | --------------- | --- |
| **暴露/处理 (X=1)**  | **a**           | **b**           | a+b |
| **非暴露/对照 (X=2)** | **c**           | **d**           | c+d |
| 合计               | a+c             | b+d             | n   |

- **马赛克图（Mosaic Plot）** ： 列联表可以用马赛克图形式展示
	- **行方向（通常垂直方向）**：按行变量分层，每一行的**高度**与该行的**总数成正比**
	- **列方向（通常水平方向）**：在每一行内**再按列变量细分**，**宽度**与该列在该**行中的比例成正比**
	- **矩形面积 = 该格子的相对频数**，也就是 $f_{ij}​ = \frac{h_{ij}}{n}$
	- X,Y 两个变量分类对比后，通过 方块颜色或者方块内再水平风格假如第三个变量，**例如 X = 船舱等级， Y = 生存与否，颜色 = 年龄**
