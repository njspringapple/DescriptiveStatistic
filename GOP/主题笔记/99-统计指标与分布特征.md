### 位置相关指标

- **众数（Modus）** ：出现频率最高的数值，**不必唯一**，适用于 **所有尺度**，随机变量的众数：$f(x_{mod}) \geq f(x), \forall x \in T_{x}$，众数是 X 的 **密度函数/概率质量** 函数的 **全局最大值点**
- **中位数（Median）**：
	- 书写形式：$\tilde{x}_{med}$，适用于 **有序尺度**，对**极端值**稳健(robust gegenüber extremen Werten)
	- 有 $n$ 个数，从小到大排序为 $x_{(1)},\dots,x_{(n)}$
	- $n$ 是偶数，$\tilde{x}_{med} = x_{(k)}, k = \frac{n+1}{2}$
	- $n$ 是奇数，$\tilde{x}_{med} = \frac{1}{2}[x_{(k)} + x_{(k+1)}], k = \frac{n}{2}$
	- 形式化定义：$\tilde{x}_{med} = argmin_{x}\Sigma_{i=1}^n|x_{i}-x|$  -- **中位数是和所有数之差的绝对值之和最小的数**
- **均值**：算术平均数(arithmetisches Mittel)，广为人知，受极端值影响很大，适用于**区间尺度**（**有顺序，且差值有意义**）数据，$\bar{x} = \frac{1}{n}\Sigma_{i}^n x_{i}$
	- **加权均值**：$\frac{1}{\Sigma_{i=1}^n w_{j}}\Sigma_{i=1}^n w_{i}x_{i}$，**注意！每个数乘以权重后的求和结果 除以 权重之和**
	- **分组均值（Gewichteter Mittelwert）**：
	- **几何均值（Das geometrische Mittel）**：
		- **一般形式** - $\bar{x}_{G} = (x_{1} \cdot x_{2} \cdot \cdot \cdot x_{n})^{\frac{1}{n}}$           **对数形式** - $\exp(\frac{\log x_{1} + \log x_{2} + \dots + \log x_{n}}{n})$    
		- 仅适用于正数、且**至少为区间尺度**的特征，**变化率的平均值，例如平均利率**，几何平均数是适用于那些取值应被解释为**乘法因子**的特征的正确均值
	- **调和平均数（Das harmonische Mittel）**：**倒数的平均值 的 倒数**  $\bar{X_{H}} = (\frac{1}{n}\Sigma_{i=1}^n \frac{1}{x_{i}})^{-1}$，应用于**尺度比率/比值** 的平均值，例如求平均速度，平均收益率
		- **举例**：先用30km/h 开车 100km，再用 100km/h 开车 100km，算术平均数 (30+100)/2 = 65km/h 平均速度显然错，调和平均数算出来是 46.2km/h，这个是对的
	- **截尾均值（Getrimmtes Mittel）：** 为减弱均值 $\bar{x}$ 对异常值的敏感性，定义：$\frac{1}{n-2r}\Sigma_{i=r+1}^{n-r}x_{(i)}$ ，$\alpha$ - 数据排序后上下两端去除掉 比例为 $\alpha$ 的极端值。$r$ - 满足 $r \leq n\alpha$ 的最大整数
		- n - 100个数，$\alpha$ - 5%，所以 $r$ = 5；然后对 $x_{(6)}$ 到 $x_{(95)}$ 求和，再除以 $n - 2r = 100 - 2 \times 5 = 90$ 
- **分位数**：p-分位数（**p-Quantil**），例如 $p_{0.25}, p_{0.5},p_{0.75}$ 也可以写为 $Q_{1},Q_{2},Q_{3}$；**随机变量表示**：$\bar{x_{p}} := argmin_{x \in T_{x}}{x : F(x) \geq p}$
	- 书写形式：$\tilde{x}_{p}$
		- 至少占比 $p$ 的数据 **小于等于** $\tilde{x}_{p}$
		- 至少占比 $1-p$ 的数据 **大于等于**  $\tilde{x}_{p}$
	- **中位数** 就是 $\tilde{x}_{0.5}$
	- 例如  $\tilde{x}_{0.25}$ 代表 至少 25% 的数据小于等于 $\tilde{x}_{0.25}$，至少 75% 的数据大于等于 $\tilde{x}_{0.25}$
	- 13个数据，0.25分位数，计算 13 * 0.25 = 3.25，**不是整数**，取大于 3.25 的最小整数 4，所以是 $x_{(4)}$
	- 12个数据，0.25分位数，计算 12 * 0.25 = 3，**是整数**，取 $x_{(3)}$ 或者 $x_{(4)}$ 都可以作为 0.25-分位数 --- !!!！**特别注意这点，这是定义**
	- **箱线图**： $\tilde{x}_{0.25}$ - 箱体的起点， $\tilde{x}_{0.75}$ - 箱体的终点， $\tilde{x}_{0.5}$ - 箱体中间的横线，$d_{Q}=IQR=\tilde{x}_{0.75}-\tilde{x}_{0.25}$ - **箱体长度**，$zo = \tilde{x}_{0.25} - 1.5IQR$ - **栅栏底部**，$zu = \tilde{x}_{0.75} + 1.5IQR$ - **栅栏顶部**
		- 简单箱线图(**Einfacher Boxplot**) - 强制将须线延伸到数据的**实际最小值和最大值**         
		- 修改的箱线图(**Modifizierter Boxplot**) -  引入“栅栏（**Zäune**）”的概念，识别并单独显示异常值（**Outlier**），注意黑线上下延申到 “**栅栏内**” 的最小/最大值，**而不是延申到 栅栏**
		- 如果一个图展示多个箱线图，例如按不同“**分组**”（比如 “房子里面房间数量” 分组统计 ”租金范围“），箱线图宽度可以代表**分组内数据的数量**
		- 通过箱体里面 p-0.5 中位数的”**上偏**“还是”**下偏**“，可以看出数据的”**偏度**“，异常值也可见，但是： **多峰分布不可见**
![[be5e93ca-3aad-457f-a395-f0e9c5d74944.png|400]]
- **期望**（Erwartungswert）： 注意取值范围（**支撑集**）的书写方法 -  $T_{X}$，**对于样本空间 $\Omega$ 中的一个随机实验结果 $\omega$，只有通过随机变量（是个函数）X 进行映射才能得到一个数值：$X(\omega)$**
	- **离散型（Diskreter）**：$E(X) := \Sigma_{X \in T_{X}} x \cdot P_{X}(X=x) := \Sigma_{\omega \in \Omega} P(\{\omega\}) \cdot X(\omega)$
	- **连续型（Stetiger）**：$E(X) := \int_{-\infty}^{+\infty} x \cdot f_{X}(x)dx$
	- 期望值也可以理解为随机变量所有取值的 “**加权算术平均值**”，其中，权重就是某个观测值的 **PDF（连续型的密度）/PMF（离散型的概率质量）**
	- **线性性** - $E(aX + bY) = aE(X) + bE(Y)$     **常数期望** - $E(a) = a$          **对称定义**：$f(c-x) = f(c+x), \forall x \in T_{X}$ ==> $E(X) = c$ 
	- **变换法则**：随机变量 X，对于：$Y = g(X)$，$E(Y) = E[g(X)] = \Sigma_{x \in T_{x}}g(x) \cdot f_{X}(x) = \int_{-\infty}^{+\infty}g(x) \cdot f_{X}(x)$
- **方差**：方差并非总是有限的！！方差 Var(X) 实际就是 **平方偏差的期望值**
	- $Var(X) = E[(X - E(X))^2]$ --  **若期望值不存在，则方差也一定不存在！！**
	- **离散型**：$Var(X) := \Sigma_{X \in T_{X}} (x - E(X))^2 \cdot P_{X}(X=x)$
	- **连续型**：$Var(X) := \int_{-\infty}^{+\infty} (x-E(X))^2 \cdot f_{X}(x)dx$
	- **平移定理**：$Var(X) = E(X^2) - E(X)^2$
	- **变换法则**：$Var(aX + b) = a^2Var(X)$
	- **线性性**：$Var(X+Y) = Var(X) + Var(Y)$  -  X 和 Y 独立，否则 $Var(X+Y) = Var(X) + Var(Y) + Cov(X,Y)$
	- **切比雪夫不等式（Tschebyscheff）**：不等式给出了一个**通用界限**：随机变量 X 偏离其期望值 E(X) 至少 c 的概率，不超过方差除以 $c^2$
		- $P(|X - E(X)| \ge c) \le \frac{\operatorname{Var}(X)}{c^2}$
	- **随机变量的标准差**：$\sigma(X) = \sqrt{ Var(X) }$，  $\sigma(aX+b) = |a|\sqrt{ Var(X) }$ -- 利用上面的变换法则后再开根号，**注意用绝对值**！！

### 离散度量(Maße für die Streuung)

- **极差（Range)** : $sp = x_{max} - x_{min}$，对异常值 **极其敏感**
- **四分位距（Der Quartilsabstand）**：$d_{Q}=IQR=\tilde{x}_{0.75}-\tilde{x}_{0.25}$  -- **箱线图中间箱体长度**，对异常值 **稳健**，定义了数据**中间 50%** 的范围
- **样本方差（Stichprobenvarianz）**：$s_{x}^2 := \frac{1}{n-1}\Sigma_{i=1}^n(x_{i} - \bar{x})^2$，至少需要**区间尺度（等距尺度）**，**注意！样本方差需要除以 $n - 1$，这样才有意义**，对异常值敏感
- **样本标准差（Standardabweichung）**：$s_{x} = \sqrt{s_{x}^2}$
- **方差/标准差在线性变化下的计算**：$y_{i} = a + bx_{i} \Rightarrow s_{y}^2 = b^2s_{x}^2 \Rightarrow s_{y} = |b|s_{x}$ 
- **平移定理(Verschiebungssatz)：** $\sum_{i=1}^{n} (x_i - c)^2 = \sum_{i=1}^{n} (x_i - \bar{x})^2 + n(\bar{x} - c)^2$ --- **解释：所有数据点围绕任意一个数 c 的总波动（平方和），等于“围绕均值的波动”加上“均值本身偏离 cc 的波动”**
	- 拓展一个方便计算的公式：$s_{x}^2 = \bar{x^2} - {\bar{x}}^2$ -- **方差 = 平方的平均数 − 平均数的平方**
- **方差分解(Streuungszerlegung)**：数据分组后，**总方差（Gesamtvarianz） = 组内方差(Innerhalb) + 组间方差(zwischen）**，$\tilde{s}_x^2 = \frac{1}{n} \sum_{j=1}^{r} n_j \tilde{s}_{x_j}^2 + \frac{1}{n} \sum_{j=1}^{r} n_j (\bar{x}_j - \bar{x})^2$
	![[8b4b4e34-b3aa-41e5-8fc8-e253929b8c58.png]]
- **变异系数（Variationskoeffizient）**：$v = \frac{\tilde{s}_{x}}{\bar{x}}, \bar{x} > 0$ - 标准差与均值之比，它是衡量**围绕均值** 的 **相对波动性** 的指标，仅适用于具有**正值**的特征，变异系数越小说明波动越少
- **平均绝对离差（MAD）：** $MAD_x = \frac{1}{n} \sum_{i=1}^{n} |x_i - \bar{x}|$ ，这个 **MAD < 标准差**，简单，应用少

### 对称性与偏度（symmetrisch und Schiefe）

- **左陡（linkssteil）** = **右偏（rechtsschief）**：均值 > 中位数 > 众数 ( $\bar{x} > x_{med} > x_{\text{mod}}$ )
- **右陡（rechtssteil）** = **左偏（linksschief）**:   均值 < 中位数 < 众数 ( $\bar{x} < x_{med} < x_{\text{mod}}$ )
- **对称（symmetrisch）**:  均值 = 中位数 = 众数 ( $\bar{x} = x_{med} = x_{\text{mod}}$ )
![[fd407a70-abfb-4e08-a93f-3eabc5f5f307.png|882]]

- **偏度判定方法**：
	- **基于四分位数的偏度系数**（Maßzahlen für die Schiefe I Quantilskoeffizient）：
		- $g_{0.25} = \frac{Q_3 + Q_1 - 2Q_2}{Q_3 - Q_1} = \frac{(\tilde{x}_{0.75} - \tilde{x}_{0.5}) - (\tilde{x}_{0.5} - \tilde{x}_{0.25})}{\tilde{x}_{0.75} - \tilde{x}_{0.25}}$
		- $g_{0.25} = 0$ - 对称分布，$g_{0.25} > 0$ - 左抖, $g_{0.25} < 0$ - 右抖
	- **偏度的矩系数**：$g_m = \frac{1}{n} \sum_{i=1}^{n} \left( \frac{x_i - \bar{x}}{s_x} \right)^3$
		- $g_{m} = 0$ - 对称，$g_{m} > 0$ - 左抖，$g_{m} < 0$，右抖
- **极端值**：
	- **峰度（Kurtosis）**：$k = \frac{1}{n} \sum_{i=1}^{n} \left( \frac{x_i - \bar{x}}{s_x} \right)^4$
	- **超额峰度（Exzess-Kurtosis）**：$k^* = k - 3$
	- $k^* = 0$ - 正态峰，与正态分布相当 ，$k^* > 0$ - 抖峰，极端值更频繁，$k^* < 0$ - 平峰，极端值少
	- 峰度衡量的是**分布尾部相对于中心部分的“重量”**，而不是峰本身的“尖度”。尽管名称叫“峰度”，但它更多地反映尾部行为
![[70d6056f-915a-4c9b-aab4-63302f3aab91.png|829]]

### 随机变量的矩(Moment)

- k 阶矩：$E(X^k)$ - 期望就是**一阶矩**
- k 阶中心矩：$E((X - E(X))^k)$ - 方差就是**二阶中心矩**
- 偏度是 **标准化值的 三阶中心矩**：$\text{Schiefe} = E\left[\left(\frac{X - E(X)}{\sigma(X)}\right)^3\right]$
- 峰度是 标准化值的 **四阶中心矩**：$\text{Kurtosis} = E\left[\left(\frac{X - E(X)}{\sigma(X)}\right)^4\right]$
### 集中度度量（Konzentrationsmaße）

- 衡量资源或总量在个体间分布的集中/分散程度，例如 一个国家的财富分配，企业在某一细分市场中的市场份额
- **洛伦兹曲线**（Lorenzkurve）：**单调递增**，所构造的折线始终位于**角平分线（对角线）的下方**
	- “最贫穷的”/“最小的” x% 拥有总量特征总和的 y%
	- “最富有的”/“最大的” x% 拥有总量特征总和的 y%
	- $u_{j}$ - 前 j 个个体占全部个体的比例  $v_{j}$ - 前 j 个个体拥有资源占全部资源的比例
![[5262f724-006a-4d7d-99e5-b4f832a7d11c.png|803]]

- **基尼系数（Gini-Koeffizient)**：即洛伦茨集中度度量，是描述集中程度的一个指标 $G = 2 \cdot F$，$F$  是 **对角线** 与 **洛伦兹曲线** 之间的面积
	- $G = 1 - \frac{1}{n} \sum_{i=1}^{n} (v_{i-1} + v_i)$
	- 端点 $v_{0}$ 和 $v_{n}$ 出现一次在加法中，中间的 v 出现2次，就是用 "梯形法则" 来计算面积
	- 取值范围：$0 \leq G \leq \frac{n-1}{n}$， 结果：0 - 完全平等   $\frac{n-1}{n}$ - 完全不平等， n - 数据总数
	- 标准化基尼系数：$G^+ = \frac{n}{n-1}G$，取值范围：$0 \leq G^+ \leq 1$, 0 - 完全平等， 1 - 完全集中
	- **非常不同的洛伦兹曲线可能对应相同的基尼系数值**
- **赫芬达尔指数（Herfindahl-Index）**：市场集中度指标，衡量行业中企业的市场份额分布
	- $p_i := \frac{x_i}{\sum_{j=1}^{n} x_j}, \qquad H := \sum_{i=1}^{n} p_i^2$
	- 取值范围：$\frac{1}{n} \leq H \leq 1$，1 - **完全寡头垄断**  $\frac{1}{n}$ - **无集中，充分竞争**
	- **举例**：四个公司，每个公司市场份额 25%，因此 $p_{i} = 0.25$，计算 H = $0.25^2 + 0.25^2 + 0.25^2 + 0.25^2 = \frac{1}{4}$ ，可见，充分竞争
