考点检查：贝叶斯

概率

  • 性质：非负 P(A)≥0；若 A⊆B，则 P(A)≤P(B)；可数离散样本空间中 ∑iP({ωi})=1
  • 分布函数：
    • (a,b] P(a<X≤b)=F(b)−F(a)
    • [a,b] P(a≤X≤b)=F(b)−F(a−)
    • (a,b) P(a<X<b)=F(b−)−F(a)
    • [a,b) P(a≤X<b)=F(b−)−F(a−)
  • 贝叶斯：P(B|A)=P(A|B)P(Bj)/∑P(A|B)P(Bi)
  • 概率形式全概率： P(A)=∑P(A|Bi)P(Bi)
  • 随机变量全概率：P(X≤x)=P(X≤x|Y=y1)P(Y=y1)+...+P(X≤x|Y=yn)P(Y=yn)
  • 条件全概率：P(R1∩R2)=∑jP(R1∩R2∣Sj)P(Sj)
  • 条件概率 → P(A∩B)=P(A|B)P(B)
  • 条件概率：P(X≤x|Y=1)=P(X≤x,Y=1)/P(Y=1)
  • 连续密度 → P(a<X≤b)=∫abf(x)dx；端点不影响
  • 离散 PMF → P(X∈A)=∑x∈APX(x)
  • 连续联合区域 A → P((X,Y)∈A)=∬AfXYdxdy
  • 离散联合区域 A → P((X,Y)∈A)=∑(x,y)∈ApXY(x,y)
  • 右尾：P(X>x)=1−F(x)
  • 右尾 ≥：P(X≥x)=1−F(x−)
  • 含左端 a→F(a−)；不含右端 b→F(b−)
  • 拉普拉斯：等概率（gleichwahrscheinlich）
  • 离散卷积　PX+Y(z)=∑xPX(x)PY(z−x)
  • 容斥定理: P(A U B) = P(A) + P(B) - P(AB)

分布

  • 性质：单调不减(monoton wachsend)、处处右连续(rechtsstetig)、归一性
    • F′(x)≥0，limt→x+F(t)=F(x)，F(−∞)=0,F(+∞)=1
  • 写分布函数最后一定是分段覆盖整个实数域，写成分段形式，注意等于号在哪
  • 连续：F(x)=∫−∞xf(t)dt 离散：F(x)=∑t≤xP(t)
  • 正态分布线性变换：X~N(μ,σ2) ，Y=aX+b，Y~N(aμ+b,a2σ2)
  • 分布变换：
    • Y=g(X)，g↑ → FY(y)=FX(g−1(y)) 变换函数连续且单调递增
    • Y=g(X)，g↓ → FY(y)=1−FX(g−1(y)) 变换函数连续且单调递减
    • Y=g(X)，g↓ → FY(y)=1−FX(g−1(y))+P(X=g−1(y)) 单调递减离散型用 !!!!!!
  • ECDF经验分布，阶梯，空心点和实心点
  • 混合分布 (gemischt stetig-diskrete Verteilung)：
    • 引入类别变量 C，“抽签”决定采用哪个分布
    • FV(v)=∑jP(C=j)FV∣C=j(v)
  • 逆变换法：生成随机数的方法， 先产生均匀随机数 U~U[0,1]，然后代入算 X=FX−1(U)
  • 分位数函数：Q(p)=FX−1(p)

密度

  • 性质：非负性(Nichtnegativität)，归一性(Normierung)
  • f(x)=F′(x)
  • 连续型-验证 PDF： (1) f(x)≥0 (2) ∫f(x)dx=1
  • 离散型-验证 PMF：(1) P(x)≥0，∑P(x)=1
  • 一维变换：Y=g(X)，单调 → fY(y)=fX(g−1(y))|(g−1)′(y)|
  • 一维卷积：Z=X+Y，独立 → fZ(z)=∫fX(x)fY(z−x)dx
  • 二维变换 → fUV=fXY(g−1)|detJg−1|
  • 贝叶斯：fX∣Y(x∣y)=fY∣X(y∣x)·fX(x)/fY(y)
  • 独立：fXY(x,y)=fX(x)·fY(y) -- 联合密度 很明显可拆分两部分==>独立
  • 离散 PMF形式：fX(x)=0.5·Ix=0(x)+0.3·Ix=1(x)+…
  • 变换计算步骤：1. 变换等式 2. 求反函数 3. 求导/雅可比行列式的绝对值 4.反函数和导数绝对值代入原密度 5.化简 6.重新计算随机变量支撑集

E(X)

  • E(X)=∑xxPX(x)=∫xfX(x)dx
  • E[g(X)]=∑g(x)PX(x)=∫g(x)fX(x)dx
  • E[g(X,Y)]=∬g(x,y)fXYdxdy（离散改双重和）
  • E(X|Z=z)=∑xP(x|z) 或 ∫xf(x|z)dx
  • 条件方差: X和Y独立,则 E(XY|Z) = E(X|Z)E(Y|Z)
  • **E(aX+bY+c)=aE(X)+bE(Y)+c
  • EX(X)=EY[EX(X|Y)]
  • 如 P(X>t)=f(t), 则 E(X)=∫0∞P(X>t)dt
  • 矩母函数：M(t)=E(etX)，例: MZ(t)=E(etZ)=E(et(X+Y))
  • 一二阶矩：E(X)=MX′(0),E(X2)=MX″(0)
  • 重期望法则：E(X)=EY[E(X∣Y)]
    • 全局期望 = 按类别分组后，组内期望的加权平均
  • 对称分布的期望就是 对称轴

E(X2) / E(XY)

  • E(X2)=Var(X)+[E(X)]2
  • E(XY)=Cov(X,Y)+E(X)E(Y)
  • E(XY)=∬xyfXY(x,y)dxdy
  • 独立 → E(XY)=E(X)E(Y)
  • 矩母函数：E(X2)=MX″(0)

Var(X)

  • 离散方差：Var(X)=∑i(xi−E(X))2PX(xi)
  • 连续方差：Var(X)=∫−∞∞(x−E(X))2·f(x)dx
  • Var(X)=E(X2)−[E(X)]2 -- 最常用
  • Var(X+Y)=VarX+VarY+2Cov(X,Y)
  • **Var(aX+bY)=a2VarX+b2VarY+2abCov(X,Y)
  • X,Y 独立 → Var(aX+bY)=a2VarX+b2VarY
  • 线性变换：Var(aX+b)=a2Var(X)
  • Var(X)=Var(−X)
  • MX(t) → VarX=M″(0)−[M′(0)]2
  • Var(X|Z)=E(X2|Z)−[E(X|Z)]2
  • 总方差定理：Var(X)=E(Var(X∣Z))+Var(E(X∣Z))

SXY

  • 样本协方差：Sxy=1n∑i=1n(xi−x¯)(yi−y¯)
  • Sxx=Sx2
  • 样本相关系数： rxy=SxySxSy rxx=1

Cov(X,Y)

  • 定义：Cov(X,Y)=E(XY)−E(X)E(Y)
  • Cov(X,Y)=E[(X−E(X))(Y−E(Y))]
  • Cov(X,Y)=∬(x−μX)(y−μY)fX,Y(x,y)dxdy
  • 双线性：Cov(aX+b,cY+d)=ac·Cov(X,Y)
  • Cov(X+Y,Z)=Cov(X,Z)+Cov(Y,Z)
  • 柯西施瓦茨： |Cov(X,Y)|≤VarX·VarY
  • Cov(X,X)=Var(X)
  • Cov(−X,Y)=−Cov(X,Y)
  • 给 Var(X+Y) → Cov=[Var(X+Y)−VarX−VarY]/2
  • 给 Var(X−Y) → Cov=[VarX+VarY−Var(X−Y)]/2
  • X,Y 独立 → Cov(X,Y)=0
  • **Cov(X,Y)=ρ·σX·σY=ρ·VarX·VarY

协方差矩阵

  • 协方差矩阵的要求：方阵、对称、对角元非负、半正定
    • 半正定（positiv semidefinit）如果行列式 < 0 非半正定，>= 0 未必半正定
    • 需要用二次型 aTΣa≥0 来判定 a=(x1,...xn)T，然后二次函数判别
  • Σ=Cov(X)=E[(X−EX)(X−EX)T]
  • 读 Σ → Σii=Var(Xi)；Σij=Cov(Xi,Xj)
  • Y=aTX+b → E(Y)=aTE(X)+b
  • Y=aTX → Var(Y)=aTΣa
  • Y=∑Xi → Var(Y)=1TΣ1（Σ 全部元素之和）
  • Y=AX+b → E(Y)=AE(X)+b；Cov(Y)=AΣAT
  • 分块正态　X1|X2=x2~N(μ1+Σ12Σ22−1(x2−μ2), Σ11−Σ12Σ22−1Σ21)
  • 二维标准正态　X|Y=y~N(ρy,1−ρ2)
  • 方差-协方差矩阵：
    • 描述性经验方差：SXX=n−1∑i(Xi−X¯)2
    • 描述性交叉矩：SXY=n−1∑i(Xi−X¯)(Yi−Y¯)（无偏样本协方差改除以 n−1）
    • 矩阵：把 SXX 当作 Var(X) 把 SXY 当作 Cov(X,Y) 构建 Σ
    • 相关系数：r=SXY/SXXSYY

相关系数：ρXY

  • 随机变量：ρ=Cov(X,Y)/(VarX·VarY)
  • −1≤ρ≤1，且 VarX,VarY>0
  • Pearson：捕捉线性关系(lineare Beziehung)、怕离群值(der Ausreißer)
    • 定量尺度（metrische Merkmale）
    • 对称性：rxy=ryx ==> Cov(X,Y)=Cov(Y,X)
  • Spearman：捕捉单调关系(monotone)，同向单调不变，反向单调变号
    • “定序尺度“（mindestens ordinale Merkmale）
    • rS=1−6∑di2/[n(n2−1)]
      • di - 两个变量的排序之差, 两个数据给定的顺序不可变的情况下计算
  • Kendall
    • 观测值排序后两两比较，看两个对象的两个属性排序一致性
    • 例如：(A,B) 数学排名 1 < 2，物理排序 2 < 1 不一致
    • n - 数据的总数
    • NC - 一致对（concordant pairs）的数量
    • ND - 不一致对（discordant pairs）的数量
    • τ=(NC−ND)/[n(n−1)/2] ∈[−1,1]
    • 1 - 完全正相关 -1 - 完全负相关 0 - 不相关
  • 距离相关系数 (Distance Correlation)：比皮尔逊相关系数对离群值更敏感，捕捉非线性

矩母函数

  • 矩 → E(X)=M′(0)；E(X2)=M″(0)；Var=M″(0)−[M′(0)]2
  • 伯努利 → M(t)=1−p+pet
  • 二项 → M(t)=(1−p+pet)n
  • 泊松 → M(t)=expλ(et−1)
  • 几何 → M(t)=p/[1−(1−p)et]
  • 正态 → M(t)=exp(μt+σ2t2/2)
  • 指数 → M(t)=λ/(λ−t)，t<λ
  • Gamma → M(t)=[λ/(λ−t)]α，t<λ
  • χ2(k) → M(t)=(1−2t)−k/2，t<1/2
  • U(a,b) → M(t)=(ebt−eat)/[t(b−a)]；t≠0，M(0)=1
  • 独立 X,Y → MX+Y(t)=MX(t)MY(t)

分位数

  • 分位函数 是分布函数的广义反函数
  • Q(p)=inf{x:FX(x)≥p}, p∈(0,1)，严格单调连续时才可写成普通反函数 FX−1(p)
  • Q1=x~.25；Med=x~.5；Q3=x~.75
  • IQR=Q3−Q1
  • 离群界 Q1−1.5IQR，Q3+1.5IQR

边缘概率/分布

  • 连续联合 → fX(x)=∫fXY(x,y)dy；fY(y)=∫fXY(x,y)dx
    • 分定义域讨论，求fX(x) 就是固定 x 对 y 求积分（上限为x)
    • 例如：fX(x)=∫0x2dt=x
  • 离散联合 → PX(x)=∑y∈YP(x,y)；PY(y)=∑x∈XP(x,y)
    • 例如：给列联，x=0 的条件时候：
    • P(X=0)=P(X=0,Y=y)=P(0,0)+P(0,1)=0.5
    • P(X=1)=P(X=1,Y=y)=P(1,0)+P(1,1)=0.5
  • 联合 CDF → FX(x)=limy→∞FXY(x,y)
    • 看 x 在联合分布定义里面的取值范围区间分别讨论
    • 在不同 x 的定义区间内，联合分布里面 y 趋近无穷时候的极限
  • 非矩形支撑 → 先找 ymin(x),ymax(x) 再积分

条件概率/密度

  • 定义连续 X∣Y → fX|Y(x|y)=fXY(x,y)/fY(y)，fY(y)>0
  • 定义离散 X∣Y → PX|Y(x|y)=PXY(x,y)/PY(y)
  • 变形：fX,Y(x,y)=fX|Y(x|y)·fY(y)=fY|X(y|x)·fX(x)
  • 事件 → P(A∩B)=P(A|B)P(B)
  • 多次条件化 等价于 对交集条件化：P((A|B)|C)=P(A|B∩C)
  • 条件独立：P(R1⋂R2∣Sj)=P(R1|Sj)P(R2|Sj) 在 Sj 条件下 R1,R2 独立

联合分布

  • 条件密度 + 边缘 → fXY=fX|YfY
  • 条件 PMF + 边缘 → PXY=PX|YPY
  • 连续边缘 + 独立 → fXY=fXfY
  • 离散边缘 + 独立 → PXY=PXPY
  • 边缘 CDF + 独立 → FXY=FXFY
  • 二维变换 → fUV=fXY(g−1)|detJg−1|
  • 仅有两个边缘、未说独立：不能确定联合

判断独立 / 不相关

  • 连续乘积 → fXY=fXfY⇒X⟂Y
  • 离散乘积 → PXY(x,y)=PX(x)PY(y) ∀x,y⇒X⟂Y
  • 条件分布：PX∣Y(x∣y)=PX(x)（对所有 PY(y)>0）⇒X⟂Y
  • 已知独立 → E[g(X)h(Y)]=E[g(X)]E[h(Y)]
  • 已知独立 → Cov=0；fX|Y=fX
  • 给定条件独立 → fXY|Z=fX|ZfY|Z
  • 联合正态且 Cov(X,Y)=0 → X⟂Y
  • Cov=0 一般不能反推独立
  • A⟂B⟺A¯⟂B⟺A⟂B¯⟺A¯⟂B¯

概率运算补口

  • 有限等可能模型：P(A)=|A|/|Ω|；一般都有 P(Ac)=1−P(A)
  • P(A∪B)=P(A)+P(B)−P(A∩B)
  • 链式　P(⋂Ai)=P(A1)∏i≥2P(Ai|A1∩⋯∩Ai−1)
  • 分层　P(A|X)=∑P(A|X,Z=zi)P(Z=zi|X)

平均 / 离散程度

  • 加权平均数：x¯w=∑wixi/∑wi
  • 几何平均数：x¯G=(∏xi)1/n 年均增长率
  • 调和平均数：x¯H=[n−1∑(1/xi)]−1
  • 样本方差　s2=∑(xi−x¯)2/(n−1)
  • 变异系数：CV=s/x¯（x¯>0）描述波动大小
  • 平均绝对偏差：MAD=n−1∑|xi−x¯|
  • 中位数：连续且严格单调时解 FX(m)=0.5；一般要求 FX(m)≥0.5 且 FX(m−)≤0.5
  • 层内离差（innerschichtliche Streuung）: 1n∑j=1knj·s~j2

常用分布

  • B(a,b)=∫01t(a−1)·(1−t)(b−1)dt
  • B(α,β)=Γ(α)Γ(β)Γ(α+β)
  • Γ(a)=(a−1)Γ(a−1)（等价地 Γ(a+1)=aΓ(a)）
  • χ2(n)
    • 众数 Modus = max(n−2,0)
    • 中位数：≈n−2/3
    • 期望：E(X)=n
  • t 分布：自由度 ν>1 时期望为 0；0<ν≤1 时期望不存在
  • 离散均匀分布 {a1,...,an}，E(X)=Σai/n
  • 几何分布：p - 实验成功概率, X 是 总实验次数，实验成功概率相同
    • 一系列独立的伯努利试验，直到第1次“成功”为止，总共试验次数, 支撑集合 {1,2,...}
    • X 是 总实验次数: P(X=k)=(1−p)k−1·p k - 总实验个数, {1,2,...} E(X)=1/p,Var(X)=(1−p)/p2
    • 变体: X 是总失败次数, P(X=k)=(1−p)k·p, E(X)=(1−p)/p,Var(X)=(1−p)/p2 k - 失败次数个数, {0,1,2,...}
    • 尾概率就是 "连续失败k次" 的概率: P(X≥k)=(1−p)k
  • 泊松分布：稀有事件, 单位时间 内 事件发生的次数（λ） X~𝒫(λ) 参数是单位时间内发生的 “平均” 次数
    • 时间等单位要 统一换算 随机变量 X 是单位时间内事件发生次数 P(X=x)=f(x)
    • 事件发生次数服从泊松分布的话，事件间隔服从指数分布
    • 二项分布在 n→∞,p→0,np=C常数 ，近似泊松分布
  • 负二项分布：是为了达到目标成功次数，需要的总数量 F~NegB(r,p) -- 注意标准的是成功+失败总次数
    • r - 成功次数，总实验次数 F（有别于二项分布的 X ）
    • 如果定义为式总失败次数，支撑集为 0,1,2....，
      • E(X)=r(1−p)/pVar(X)=r(1−p)/p2
      • PMF：P(X=x)=C(x+r−1,x)·pr·(1−p)x
  • 超几何分布 Hypergeometrische Verteilung：描述 无放回 抽样情况下，成功次数 的分布
    • X~ℋ(N,K,n)，参数 N（总体大小），K（成功品总数），n（抽取个数）
    • 支撑集：成功次数，0 <= x <= K 0 <= n - x(失败次数) <= N - K
    • E(X) = nK / N Var(X) = nK/N·(N−K)/N·(N−n)/(N−1)
  • 指数分布: 参数 λ 是事件发生的平均速率, 随机变量结果是 两次事件之间的时间间隔
    • 无记忆(Gedächtnislosigkeit)　P(X>s+t|X>s)=P(X>t) , s - 已经等待的时间, t - 继续等待的时间
  • 离散均匀分布 X~U{1,2,...,n}, 期望: E(X)=(1+n)/2 -- 注意和连续均匀分布写法区别 U(1,n)
  • 分布可加性(不限于2个随机变量):
    • X1,X2~Exp(λ), X1+X2~Ga(2,λ), 多个的话一样,第一个参数就是分布个数, 但是 λ 必须一样!
    • 如果 X1~Poi(λ1),X2~Poi(λ2), 则 X1+X2~Poi(λ1+λ2)
    • 如果 X1~B(n1,p),X2~B(n2,p), 则 X1+X2~B(n1+n2,p) , 但是 p 必须一样
    • 如果 X1~Ga(a1,b),X2~Ga(a2,b) , 则 X1+X2~Ga(a1+a2,b) , 但是 b 必须一样
  • 分布函数：
    • 指数分布：F(x)=1−exp(−λx),x≥0
    • 泊松分布: F(x)=exp(−λ)·Σk=0⌊x⌋|λk/k!,x≥0 - 注意 x 向下取整
    • 均匀连续：F(x)=(x−a)/(b−a),a≤x≤b
    • 几何分布：F(x)=1−(1−p)⌊x⌋,x≥1
    • 正态分布：F(X)=1/(σ2π)·∫−∞xexp(−(t−μ)2/2σ2)dt

    • V = 0 无关联 V = 1 完全关联

测度论

  • σ-代数(允许讨论的事件)需要满足三条公理：
    1. Ω∈ℱ
    2. 对补集封闭：A∈ℱ⇒Ac∈ℱ
    3. 对可数并封闭（等价于对有限并封闭）
  • 多维 Ω：{1,2,3,4,5,6}2——投掷两个骰子的结果
  • 补集：Ac=Ω⧵A　
  • 测度： 给集合分配大小：μ(∅)=0；μ(A)≥0
    • 原像空间测度：μ,μZ,λ
    • 像空间测度：μf：这个测度把像空间的一个集合映射到一个实数 μf:F2→ℝ
    • 测度具有单调性（Monotonie）：A⊆B，有 μ(A)≤μ(B)
    • 概率测度归一性(Normierung)：P(Ω)=1
    • 测度差　A⊂B,μ(A)<∞：μ(B⧵A)=μ(B)−μ(A)
    • 事件集合不相交，概率测度 P(A)+P(B)≤1
    • 针对两个集合的测度相等 不等于 两个集合相等
    • 构造新测度：若 f≥0 可测，则 ν(A)=∫Afdμ 定义一个测度
    • 集合测度等于指示函数的积分: ∫ICdμ=μ(C)
  • 测度证明三要素：
    • 空集测度：μ(∅)=∑ω∈∅=0
    • 非负性（Nichtnegativität）：μ(A)≥0，对所有 A∈ℱ
    • σ-可加性（Additivität）：对任意两两不交的集合(paarweise disjunkte Mengen)序列 (An)，有 ：μ(⋃n=1∞An)=Σiμ(Ai)
    • 如果概率测度, 增加归一性: P(Ω)=1
  • Dirac 测度：δa(A)=1A(a)，即 a∈A 时为 1，否则为 0
  • 计数测度　μZ(A)=|A|；μZ({x})=1 , 对于单点集合测度为1
  • Lebesgue 测度：λ((a,b))=λ([a,b])=λ((a,b])=b−a，在单离散点测度为 0: λ({x})=0
  • L–S 测度　区间：λF((a,b])=F(b)−F(a)，单点：λF({a})=F(a)−F(a−) 对右连续单调增函数 F
  • Lebesgue-Stieltjes 测度： G，区间 (a,b] 的测度定义为 λG((a,b])=G(b)−G(a)
  • 可测:
    • 可测函数：f - 把原像空间的一个集合映射到像空间的一个元素（实数） - f−1(B)={ω∈Ω:f(ω)∈B}，f:Ω→ℝ
    • ℱ1-ℱ2 可测：验证：∀B∈F2,f−1(B)∈F1 -- 右侧 集合的任意一个元素, 通过 可测映射的逆映射 后的集合 属于 左侧 集合
    • 连续函数(die stetige Funktion) ==> 可测
  • 简单函数积分　∫Bfdμ=∑aiμ(Ai) - 在积分
    • f：可测函数 - f(ω)=1/ω
    • B：事件，在 Ω 上的一个σ-代数里面的一个可测集合 - {1,2,3}
    • Ai：B 中的元素进行不重叠的划分后形成的第 i 个集合 - {2}
    • ai：Ai 中任意元素经过 f 映射后的结果 - 1/2
    • μ：测度，把 Ai 映射成一个实数 - 2
      • dμ 是积分时使用的“度量单位”，它指示每个点 x 处该给多大的b
      • 勒贝格测度 - dμ 就是普通积分
      • 计数测度 - dμ 就是求和
      • 概率测度 - dμ 就是求期望
    • ∫fdμ=Σi=1nai·μ(f−1({ai}))
      • ai - f 映射后的数值，代入 “逆映射”， 必须使用集合符号包裹
    • 积分线性分解:　∫(af+bg)dμ=a∫fdμ+b∫gdμ；f≤g⇒∫fdμ≤∫gdμ
  • Radon-Nikodym：概率测度 写成 密度函数的积分形式
    • 什么时候可以把一个测度写成“另一个测度的积分”形式（什么时候有密度）
    • ν(A)=∫Afdμ，测度 ν 写成 测度 μ 的积分形式，f - RN导数(密度)
    • 判定条件：μ(A)=0⇒ν(A)=0 ，找到反例，则没有密度
    • 例如：μ 是 λ(a,b) 或者 μz 测度，有密度函数积分后就是 概率测度 𝒫
  • 零测集 Nullmenge：测度为 0 的集合；不同测度有不同零测集，例如 λ({0})=0，但 μ({0})=1
    • 对于测度空间 (Ω,F,μ)，一个集合 N∈F 称为 零集（Nullmenge），如果 μ(N)=0
  • 前推/像测度　μf(B)=μ(f−1(B))
    • 像空间上的测度 Pf(A)=P(f−1(A))=P({ω∈Ω:f(ω)∈A}) 是（关于 P 和 f 的）前推测度
    • 例如：A = {1} ，可测映射 f 将 {1,3,5}里面的每一个元素 映射到像空间上的 {1}
