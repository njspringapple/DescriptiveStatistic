# 第一页（A 面：目标 → 已知 → 公式）

## 重点检查

- 分布函数是否完整分段写了所有实数区间，从0到1
- 密度函数是否完整写了所有实数区间，非定义域外为0
- 看到 $\prod$ 是否需要取 $\ln$，把乘积变成求和 $\sum$
- 这题的 **上面的 小问 的结果** 或者中间计算有使用吗？
- 看到上下界，看看 **马尔可夫，Jensen，切比雪夫**
- 上下界和 $\geq, \leq$ 符号有没有搞反
- 联合密度是否要求边缘密度
- 密度/卷积变换完后，有没有 **计算新定义域**，**绝对值** 加了吗
- 给定的密度函数是否符合某个已知期望，方便求期望方差
- 正态分布标准化分母是 标准差，不是方差，**需要方差开根号**
## $E(X)$

- **离散 $p_X(x)$** → $E(X)=\sum_{x}xp_{X}(x)$
- **连续 $f_X(x)$** → $E(X)=\int xf_{X}(x)dx$
- **离散 $g(X)$** → $E[g(X)]=\sum g(x)p_{X}(x)$
- **连续 $g(X)$** → $E[g(X)]=\int g(x)f_{X}(x)dx$
- **$Y=aX+b$** → $E(Y)=aE(X)+b$
- **$aX+bY+c$** → $aE(X)+bE(Y)+c$；**无需独立**
- **$E(X\mid Y)$** → $E(X)=E[E(X|Y)]$
- **$X\ge0$、给尾概率** → $E(X)=\int_{0}^{\infty}P(X>t)dt$
- **矩母函数 $M_X(t)$** → $E(X)=M'_{X}(0)$
- **要 $k$ 阶矩** → $M(t)=E(e^{tX})；E(X^{k})=M^{(k)}(0)$
- **重期望法则**：$E(X)=E_Y[E(X\mid Y)]$
	- **全局期望 = 按类别分组后，组内期望的加权平均**
- 对称分布的期望就是 **对称轴**
- **离散期望**：$E(X)=x_1p_X(x_1)+x_2p_X(x_2)+\cdots$
## $\rho_{XY}$

- **给 $Cov,\sigma_X,\sigma_Y$** → $\rho=Cov/(\sigma_{X}\sigma_{Y})$
- **给 $Cov,VarX,VarY$** → $\rho=Cov/(\sqrt{VarX}\cdot \sqrt{VarY})$
- **$-1\le\rho\le1$，且 $VarX,VarY>0$**
- **Pearson**：**捕捉线性**、**怕离群值** $S_{XY}=(n-1)^{-1}\sum(x_{i}-\bar x)(y_{i}-\bar y)$
	- **定量尺度**（metrische Merkmale）
- **Spearman**：**捕捉单调性**，同向单调不变，反向单调变号
	-  “**定序尺度**“（mindestens ordinale Merkmale）
	- $r_{S}=1-6\sum d_{i}^2/[n(n^2-1)]$
		- $d_i$ - 两个变量的排序之差
- **Kendall**
	- 观测值排序后两两比较，看两个对象的两个属性排序一致性
	- 例如：(A,B)  数学排名 1 < 2，物理排序 2 < 1 **不一致**
	- n - **数据对**的总数  $N_C$ - **一致对**（concordant pairs）的数量
	- $N_D$ - **不一致对**（discordant pairs）的数量
	- $\tau=(N_{C}-N_{D})/[n(n-1)/2]$  $\in [-1,1]$
	- 1 - 完全正相关  -1 - 完全负相关  0 - 不相关
## 矩母函数

- **矩** → $E(X)=M'(0)；E(X^2)=M''(0)；Var=M''(0)-[M'(0)]^2$
- **伯努利** → $M(t)=1-p+pe^{t}$
- **二项** → $M(t)=(1-p+pe^{t})^{n}$
- **泊松** → $M(t)=\exp{\lambda(e^{t}-1)}$
- **几何** → $M(t)=p/[1-(1-p)e^{t}]$ 
 - **正态** → $M(t)=\exp(\mu t+\sigma^2t^2/2)$
- **指数** → $M(t)=\lambda/(\lambda-t)$，**$t<\lambda$**
- **Gamma** → $M(t)=[\lambda/(\lambda-t)]^{\alpha}$，**$t<\lambda$**
- **$\chi^2(k)$** → $M(t)=(1-2t)^{-k/2}$，**$t<1/2$**
- **$U(a,b)$** → $M(t)=(e^{bt}-e^{at})/[t(b-a)]$；$t\ne0$，$M(0)=1$
- **独立 $X,Y$** → $M_{X+Y}(t)=M_{X}(t)M_{Y}(t)$

 若 X=1,2,…，结果再乘 $e^{t}$
## $Var(X)$

- **给 $E(X),E(X^2)$** → $Var(X)=E(X^2)-[E(X)]^2$
- **只给离散分布** → 算 $E(X), E(X^2)=\sum x^2p(x)$，再相减
- **只给连续密度** → 算 $E(X), E(X^2)=\int x^2f(x)dx$，再相减
- **线性变换**：$Var(aX+b)=a^2Var(X)$
- **$Var(aX+bY)$** → $a^2VarX+b^2VarY+2abCov(X,Y)$
- **$X \pm Y$** → $VarX+VarY\pm2Cov(X,Y)$
- **$X,Y$ 独立** → $Var(aX+bY)=a^2VarX+b^2VarY$
- **条件量** → $VarX=E[Var(X|Y)]+Var(E[X|Y])$
- **$Var(X) = Var(-X)$**
- **$M_X(t)$** → $VarX=M''(0)-[M'(0)]^2$
- **离散方差**：$Var(X)=\sum_i(x_i-E(X))^2p_X(x_i)$
## $E(X^2)$ / $E(XY)$

- **给 $E(X),Var(X)$** → $E(X^2)=Var(X)+[E(X)]^2$
- **给 $Cov,E(X),E(Y)$** → $E(XY)=Cov+E(X)E(Y)$
- **给联合密度** → $E(XY)=\iint xyf_{XY}(x,y)dxdy$
- **$X,Y$ 独立** → $E(XY)=E(X)E(Y)$
- **给 $M_X(t)$** → $E(X^2)=M''_{X}(0)$
## $Cov(X,Y)$

- **给 $E(XY),E(X),E(Y)$** → $Cov(X,Y)=E(XY)-E(X)E(Y)$
- **方差**： $|Cov(X,Y)|\le\sqrt{VarX\cdot VarY}$
- **给联合密度** → 先算 $E(XY)=\iint xyf_{XY}dxdy$，再代定义
- **给 $\rho,\sigma_X,\sigma_Y$** → $Cov=\rho\sigma_{X}\sigma_{Y}$
- **给 $\rho,VarX,VarY$** → $Cov=\rho\sqrt{VarX}\sqrt{VarY}$
- **给 $Var(X+Y)$** → $Cov=[Var(X+Y)-VarX-VarY]/2$
- **给 $Var(X-Y)$** → $Cov=[VarX+VarY-Var(X-Y)]/2$
- **双线性** → $Cov(aX+b,cY+d)=ac\cdot Cov(X,Y)$
- **同一变量** → $Cov(X,X)=Var(X)$
- **$Cov(−X,Y)=−Cov(X,Y)$**
- **和与 $Z$** → $Cov(X+Y,Z)=Cov(X,Z)+Cov(Y,Z)$
- **$X,Y$ 独立** → $Cov(X,Y)=0$
## 协方差矩阵

- **协方差矩阵的要求**：**方阵、对称、对角元非负、半正定**（$a^T\Sigma a\ge0$；仅有 $\det(\Sigma)\ge0$ 不够）
- $\Sigma=Cov(X)=E[(X-EX)(X-EX)^{T}]$
- **读 $\Sigma$** → $\Sigma_{ii}=Var(X_{i})；\Sigma_{ij}=Cov(X_{i},X_{j})$
- **$Y=a^{T}X+b$** → $E(Y)=a^{T}E(X)+b$
- **$Y=a^{T}X$** → $Var(Y)=a^{T}\Sigma a$
- **$Y=\sum X_i$** → $Var(Y)=\mathbf{1}^{T}\Sigma\mathbf{1}$（$\Sigma$ 全部元素之和）
- **$Y=AX+b$** → $E(Y)=AE(X)+b；Cov(Y)=A\Sigma A^{T}$
- **分块正态**　$X_{1}|X_{2}=x_{2}\sim N(\mu_{1}+\Sigma_{12}\Sigma_{22}^{-1}(x_{2}-\mu_{2}),\ \Sigma_{11}-\Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21})$
- **二维标准正态**　$X|Y=y\sim N(\rho y,1-\rho^2)$
- **方差-协方差矩阵**：
	- **描述性经验方差**：$S_{XX}=n^{-1}\sum_i(X_i-\bar X)^2$
	- **描述性交叉矩**：$S_{XY}=n^{-1}\sum_i(X_i-\bar X)(Y_i-\bar Y)$（无偏样本协方差改除以 $n-1$）
	- **矩阵**：把 $S_{XX}$ 当作 $Var(X)$ 把 $S_{XY}$ 当作 $Cov(X,Y)$ 构建 $\Sigma$ 
	- **相关系数**：$r = S_{XY}/\sqrt{S_{XX} S_{YY}}$
## $P(\cdot)$

- **性质**：非负 $P(A)\ge0$；若 $A\subseteq B$，则 $P(A)\le P(B)$；可数离散样本空间中 $\sum_iP(\{\omega_i\})=1$
- **分布函数**：
	- **$(a,b]$** $P(a<X\le b)=F(b)-F(a)$
	- **$[a,b]$** $P(a\le X\le b)=F(b)-F(a^{-})$
	- **$(a,b)$** $P(a<X<b)=F(b^{-})-F(a)$
	- **$[a,b)$** $P(a\le X<b)=F(b^{-})-F(a^{-})$
- **贝叶斯**：$P(B_{j}|A)=P(A|B_{j})P(B_{j})/\sum P(A|B_{i})P(B_{i})$
- **概率形式全概率**： $P(A)=\sum P(A|B_{i})P(B_{i})$ 
- **随机变量全概率**：$P(X \leq x) = P(X \leq x|Y = y_1)P(Y = y_1) + ... + P(X \leq x|Y = y_n)P(Y = y_n)$
- **条件全概率**：$P(R_1\cap R_2)=\sum_jP(R_1\cap R_2\mid S_j)P(S_j)$
- **条件概率**：$P(X \leq x|Y=1) = P(X \leq x, Y = 1) / P(Y = 1)$
- **连续密度** → $P(a<X\le b)=\int_{a}^{b}f(x)dx$；端点不影响
- **离散 PMF** → $P(X\in A)=\sum_{x\in A}p_X(x)$
- **连续联合区域 $A$** → $P((X,Y)\in A)=\iint_{A}f_{XY}dxdy$
- **离散联合区域 $A$** → $P((X,Y)\in A)=\sum_{(x,y)\in A}p_{XY}(x,y)$
- **条件概率** → $P(A\cap B)=P(A|B)P(B)$
- **右尾 $>$** → $P(X>x)=1-F(x)$
- **右尾 $\ge$** → $P(X\ge x)=1-F(x^{-})$
- **含左端 $a\to F(a^-)$；不含右端 $b\to F(b^-)$**
## $F_X(x)$

- **性质**：**单调不减、处处右连续** $\lim_{t\downarrow x}F(t)=F(x)$，且 $F(-\infty)=0,F(+\infty)=1$（可导处才有 $F'(x)\ge0$）
- **写分布函数最后一定是分段覆盖整个实数域，写成分段形式，注意等于号在哪**
- ECDF经验分布，阶梯，**空心点和实心点**
- **连续密度** → $F(x)=\int_{-\infty}^{x}f(t)dt$
- **支撑 $[a,b]$** → $0(x<a)；\int_{a}^{x}f(t)dt(a\le x\le b)；1(x>b)$
- **离散 PMF** → $F(x)=\sum_{t\le x}p(t)$
- **样本 $X_1,\ldots,X_n$** → $F_{n}(x)=n^{-1}\sum\mathbf{1}_{\{X_i\le x\}}$
- **分布变换**：**$Y=g(X)$，$g\uparrow$** → $F_{Y}(y)=F_{X}(g^{-1}(y))$ **单调递增连续变换函数**
- **$Y=g(X)$，$g\downarrow$** → $F_{Y}(y)= 1-F_{X}(g^{-1}(y))$ **单调递减连续型用**
- **$Y=g(X)$，$g\downarrow$** → $F_{Y}(y)= 1-F_{X}(g^{-1}(y)) + P(X = g^{-1}(y))$ **单调递减离散型用**   !!!!!!
- **正态分布线性变换**：$X \sim N(\mu, \sigma^2)$ ，$Y = aX + b$，$Y \sim N(a\mu + b, a^2\sigma^2)$
- **混合分布** (gemischt stetig-diskrete Verteilung)：
	- 引入类别变量 $C$，“抽签”决定采用哪个分布
	- $F_V(v)=\sum_jP(C=j)F_{V\mid C=j}(v)$
## 分位数

- **分位函数** 是分布函数的**广义反函数**
- $Q(p)=\inf\{x:F_X(x)\ge p\},\ p\in(0,1)$，严格单调连续时才可写成普通反函数 $F_X^{-1}(p)$
- $Q_{1}=\tilde x_{.25}；Med=\tilde x_{.5}；Q_{3}=\tilde x_{.75}$
- $IQR=Q_{3}-Q_{1}$
- **离群界** $Q_{1}-1.5IQR，Q_{3}+1.5IQR$
## 密度

- **性质**：非负性，归一性，
- **可导 CDF** → $f(x)=F'(x)$；分段求导并保留区间
- **验证密度** → $f(x)\ge0，\int f(x)dx=1$
- **验证 PMF** → $p(x)\ge0，\sum p(x)=1$
- **一维变换**：**$Y=g(X)$，单调** → $f_{Y}(y)=f_{X}(g^{-1}(y))|(g^{-1})'(y)|$
- **一维卷积**：**$Z=X+Y$，独立** → $f_{Z}(z)=\int f_{X}(x)f_{Y}(z-x)dx$
- **二维变换** → $f_{UV}=f_{XY}(g^{-1})|\det J_{g^{-1}}|$
- **贝叶斯**：$f_{X\mid Y}(x\mid y)=f_{Y\mid X}(y\mid x)f_X(x)/f_Y(y)$
- **独立**：联合密度函数可以直接分解为两个边缘密度乘积
- **离散 PMF形式**：$f_X(x) = 0.5 \cdot I_{x = 0}(x) + 0.3 \cdot I_{x = 1}(x) + \dots$
- **变换计算步骤**：1. 变换等式 2. 求反函数 3. 求导/雅可比行列式的绝对值 
	4.反函数和导数绝对值代入原密度 5.化简 6.重新计算随机变量支撑集
## 边缘分布

- **连续联合** → $f_{X}(x)=\int f_{XY}(x,y)dy；f_{Y}(y)=\int f_{XY}(x,y)dx$
- **离散联合** → $p_{X}=\sum_{y}p_{XY}；p_{Y}=\sum_{x}p_{XY}$
- **联合 CDF** → $F_{X}(x)=\lim_{y\to\infty}F_{XY}(x,y)$；Y 同理
- **非矩形支撑** → 先找 $y_{\min}(x),y_{\max}(x)$ 再积分
## 条件分布

- **连续 $X\mid Y$** → $f_{X|Y}(x|y)=f_{XY}(x,y)/f_{Y}(y)$，**$f_Y(y)>0$**
- **连续 $Y\mid X$** → $f_{Y|X}(y|x)=f_{XY}(x,y)/f_{X}(x)$
- **离散 $X\mid Y$** → $P_{X|Y}(x|y)=P_{XY}(x,y)/p_{Y}(y)$
- **条件 × 边缘** → $f_{XY}=f_{X|Y}f_{Y}$（离散同理）
- **事件** → $P(A\cap B)=P(A|B)P(B)$
- **条件独立**：$P(R_1 \bigcap R_2∣S_j) = P(R_1|S_j)P(R_2|S_j)$ 在 $S_j$ 条件下 $R_1,R_2$ 独立
## 联合分布

- **条件密度 + 边缘** → $f_{XY}=f_{X|Y}f_{Y}$
- **条件 PMF + 边缘** → $P_{XY}=P_{X|Y}p_{Y}$
- **连续边缘 + 独立** → $f_{XY}=f_{X}f_{Y}$
- **离散边缘 + 独立** → $P_{XY}=P_{X}p_{Y}$
- **边缘 CDF + 独立** → $F_{XY}=F_{X}F_{Y}$
- **二维变换** → $f_{UV}=f_{XY}(g^{-1})|\det J_{g^{-1}}|$
- **仅有两个边缘、未说独立：不能确定联合**
## 判断独立 / 不相关

- **连续乘积** → $f_{XY}=f_{X}f_{Y} \Rightarrow X\perp Y$
- **离散乘积** → $p_{XY}(x,y)=p_X(x)p_Y(y)\ \forall x,y \Rightarrow X\perp Y$
- **条件分布**：$p_{X\mid Y}(x\mid y)=p_X(x)$（对所有 $p_Y(y)>0$）$\Rightarrow X\perp Y$
- **已知独立** → $E[g(X)h(Y)]=E[g(X)]E[h(Y)]$
- **已知独立** → $Cov=0；f_{X|Y}=f_{X}$
- **给定 $Z$ 条件独立** → $f_{XY|Z}=f_{X|Z}f_{Y|Z}$
- **联合正态且 $Cov=0$** → $X\perp Y$
- **$Cov=0$ 一般不能反推独立**
- **乘积要在完整支撑集成立**
## 概率运算补口

- **有限等可能模型**：$P(A)=|A|/|\Omega|$；一般都有 $P(A^{c})=1-P(A)$
- $P(A\cup B)=P(A)+P(B)-P(A\cap B)$
- **链式**　$P(\bigcap A_{i})=P(A_{1})\prod_{i\ge2}P(A_{i}|A_{1}\cap\cdots\cap A_{i-1})$
- **分层**　$P(A|X)=\sum P(A|X,Z=z_{i})P(Z=z_{i}|X)$
## 平均 / 离散程度

- **加权平均数**：$\bar x_{w}=\sum w_{i}x_{i}/\sum w_{i}$
- **几何平均数**：$\bar x_{G}=(\prod x_{i})^{1/n}$ **年均增长率**
- **调和平均数**：$\bar x_{H}=[n^{-1}\sum(1/x_{i})]^{-1}$  
- **样本方差**　$s^2=\sum (x_{i}-\bar{x})^2/(n-1)$
- **变异系数**：$CV=s/\bar x$（$\bar x>0$）**描述波动大小**
- **平均绝对偏差**：$MAD=n^{-1}\sum|x_{i}-\bar x|$
- **中位数**：连续且严格单调时解 $F_X(m)=0.5$；一般要求 $F_X(m)\ge0.5$ 且 $F_X(m^-)\le0.5$
## 偏度 / 峰度

- **左陡-linkssteil** = **右偏-rechtsschief**：均 > 中 > 众 ( $\bar{x} > x_{med} > x_{\text{mod}}$ )
- **右陡-rechtssteil** = **左偏-linksschief**：均值 < 中 < 众 ( $\bar{x} < x_{med} < x_{\text{mod}}$ )
- **四分位数的偏度系数**：$g_{Q}=(Q_{3}+Q_{1}-2Q_{2})/(Q_{3}-Q_{1})$ **>0 右偏 =0 对称**
- **偏度**：$\gamma_{1}=E[(X-\mu)^3]/\sigma^3$  **>0 右偏 =0 对称**，三阶中心矩
- **峰度**：$K=E[(X-\mu)^4]/\sigma^4；K_{ex}=K-3$，四阶中心矩
	- $K_{ex}>0$ 陡峰；$K_{ex}=0$ 与正态同峰度；$K_{ex}<0$ 较平坦
## 联合 / 条件计算

- $E[g(X,Y)]=\iint g(x,y)f_{XY}dxdy$（离散改双重和）
- **离散卷积**　$p_{X+Y}(z)=\sum_{x}p_{X}(x)p_{Y}(z-x)$
- $E(X|Z=z)=\sum xP(x|z)$ 或 $\int xf(x|z)dx$
- $Var(X|Z)=E(X^2|Z)-[E(X|Z)]^2$
# 第二页（B 面：补充公式、测度论与证明模板）

## 常用分布

- $B(a,b) = \int_0^1 t^{(a-1)} \cdot (1-t)^{(b-1)}dt$
- $B(\alpha,\beta) = \frac{\Gamma{(\alpha)}\Gamma{(\beta)}}{\Gamma(\alpha+\beta)}$
- $\Gamma(a)=(a-1)\Gamma(a-1)$（等价地 $\Gamma(a+1)=a\Gamma(a)$）
- $\chi^2(n)$
	- 众数 Modus = $\max(n-2,0)$
	- 中位数：$\approx n - 2/3$
	- 期望：$E(X) = n$
- **t 分布**：自由度 $\nu>1$ 时期望为 $0$；$0<\nu\le1$ 时期望不存在
- **指数无记忆**　$P(X>s+t|X>s)=P(X>t)$
- **离散均匀分布** $\{a_1,...,a_n\}$，$E(X) = \Sigma a_i /n$
- **几何分布**：......直到第一次..... $p$ - 实验成功概率
- **泊松分布**：**单位时间** 内 **事件发生的次数（$\lambda$）** $X \sim \mathcal{P}(\lambda)$
	- 时间等单位要 **统一换算**      随机变量 $X$ 是单位时间内事件发生次数 $P(X=x) = f(x)$
	- 事件发生次数服从泊松分布的话，事件间隔服从指数分布
	- **泊松分布可加性**：$S_n ∼ Poi(n\lambda)$
- **负二项分布**：是为了达到目标次数，需要的总数量  $F \sim NegB(m, p)$
	- m - **成功次数**，**总实验次数** F（有别于二项分布的 $X$ ）
- **二项分布可加性**：$\operatorname{Bin}(n,p)+\operatorname{Bin}(m,p)\sim\operatorname{Bin}(n+m,p)$；**独立且 $p$ 相同**
## 列联表

- 根据列联表按行/列汇总相对频数得到 **离散概率分布**
- 只要一个单元格代表的 $f_{XY}$ 不等于对应 $X,Y$ 的 $f_X,f_Y$ 的乘积，就不独立
- $E(XY)=\sum_i\sum_j x_i y_j f_{ij}$
- **期望频数**：**如果两个变量独立，理论上应该出现的频数**
	-  $E_{ij} = (n_{i·} \times n_{·j}) / n$     -- **独立性判定条件**
- $n$ - **总观测数**，**绝对频数** - $h_j$，$f_j = h_j/n$ - **相对频数**
- **直方图额外需要**：$b_j$ - **组距**，$H_j=f_j/b_j$ - **组高**，**！矩形面积 = 相对频数！**
- $fi·$ - **按行** 相对频数汇总  $f·j$ - **按列** 相对频数汇总
- $n_{i \cdot}$ - **按行** 绝对频数汇总  $f_{\cdot j}$ - **按列** 绝对频数汇总
- $n_{\cdot\cdot}=n$（总绝对频数），$f_{\cdot\cdot}=1$（总相对频数）
- **2 x 2 列联系数**：$[[a,b],[c,d]]；n=a+b+c+d$
	- $\chi^2=n(ad-bc)^2/[(a+b)(a+c)(b+d)(c+d)]$
	- $K=\sqrt{\chi^2/(n+\chi^2)}$
	- $K^{*}=K/\sqrt{(M-1)/M}；0\le K^{*}\le1$
	- **$K^*=0$：关联弱；1：关联强**
- **② 一般 $\chi^2$**　
	- $\chi^2=\sum_{i,j}(O_{ij}-E_{ij})^2/E_{ij}\ge0$；$O_{ij}$ 是**单元格的绝对频数**
	- 越大＝偏离独立越明显
## 直方图和箱线图

- **直方图**：
	- 多峰性（Multimodalität）可见（sichtbar）
	- 当组距（Klassenbreite）很窄且样本（Stichprobe）很大时，逼近（nähert ... an）密度函数（Dichte）
	- 视觉效果（optischer Eindruck）受到任意（arbiträr）选择的组距（Klassenbreite）和组限（Klassengrenzen）位置的强烈影响（beeinflusst）
- **箱线图**：
	- 不受组距（Klassenbreite）和组限（Klassengrenzen）选择的影响（unabhängig），稳健（robust）
	- 中位数（Median）、四分位数（Quartile）和离群值（Ausreißer）直接可读（direkt ablesbar）
	- 便于多个分布（mehrere Verteilungen）直接比较（direkt vergleichbar）
	- 分布形状（Verteilungsform）不可见（nicht sichtbar）
## 常用不等式

- **Markov**　$X\ge0,a>0$：$P(X\ge a)\le E(X)/a$ 
- **Chebyshev**：
	- $P(|X-\mu|\ge c)\le\sigma^2/c^2$
	- $P(|X-\mu|<c)\ge1-\sigma^2/c^2$ 
	 **围绕均值的对称区间**
- **Jensen**　**凸**：$f(E(X))\le E[f(X)]$；**凹**：反向
	- 判断：$f''\ge0\Rightarrow\text{凸}$；$f''\le0\Rightarrow\text{凹}$
- **Cauchy–Schwarz**：
	- $|E(XY)|\le\sqrt{E(X^2)E(Y^2)}$
	- $|Cov(X,Y)|\le\sqrt{VarX\cdot VarY}$
- **Minkowski**　$(E|X+Y|^{p})^{1/p}\le(E|X|^{p})^{1/p}+(E|Y|^{p})^{1/p}$
## 正态标准化 / CLT

- **常用充分条件**：$X_i$ i.i.d.，且 $E(X_i)$、$Var(X_i)$ 有限
- **标准化**　$Z=(X-\mu)/\sigma\sim N(0,1)$；**分母是 $\sigma=\sqrt{Var}$**
- **求和CLT**：$\sum X_{i}\overset{a}{\sim}N(n\mu,n\sigma^2)$　标准化后：$\frac{S_n-n\mu}{\sqrt n\,\sigma}\xrightarrow{d}N(0,1)$
- **均值CLT**：$\bar{X}_n \overset{a}{\sim} \mathcal{N}\left(\mu = \mu_X,\ \sigma^2 = \frac{\sigma_X^2}{n}\right)$
- **均值CLT(标准化后)**：$\sqrt{n}( \bar X-\mu)/\sigma \approx N(0,1)$
- **标准误** $SE=\sigma/\sqrt{n}$
- **对称性**　$\Phi(-z)=1-\Phi(z)$；$P(|Z|\le z)=2\Phi(z)-1$
- **多元联合正态**：任意两个分量协方差为 $0\Rightarrow$ 二者独立（一般分布不能反推）
- **多元正态**　$X\sim N(\mu,\Sigma)\Rightarrow AX+b\sim N(A\mu+b,A\Sigma A^{T})$
- $a^{T}X+b\sim N(a^{T}\mu+b,a^{T}\Sigma a)$
- **和的方差**：$Var(\sum_iX_i)=\sum_iVar(X_i)+2\sum_{i<j}Cov(X_i,X_j)$
## 集中度

- **准备阶段**：数据首先从小到大排序，计算每个维度的数据占比（相对频数）和 **累积比例**　
- **Lorenz** 坐标：$(u_i,v_i)$＝（累计单位占比，**累计数值占比**）；等权时 $u_i=i/n$
- **Gini**　$G=1-n^{-1}\sum(v_{i-1}+v_{i})$  -- 从小到大，迭代两两求和，第一个数据 + 0
- **标准化**：$G^{+}=nG/(n-1)$；**接近 0 平均，接近 1 集中**
- $G = 2 \cdot F$ $F$  是 **对角线** 与 **洛伦兹曲线** 之间的面积，面积越小，集中度越小 
- **Herfindahl**　$H=\sum p_{i}^2$，其中 $p_i=x_i/T$   -- **相对频数的平方和** $1/n\le H\le1$；越大越集中

## 收敛 / 大数定理

- **依概率**　$X_{n}\xrightarrow{P}X \Leftrightarrow P(|X_{n}-X|>\varepsilon)\to0，\forall\varepsilon>0$
- **依分布**　$X_{n}\xrightarrow{D}X \Leftrightarrow F_{n}(x)\to F(x)$，只查 $F$ 的连续点
- **几乎必然**　$P{\omega:\lim X_{n}(\omega)=X(\omega)}=1$
- **$L^r$**　$E(|X_{n}-X|^{r})\to0$
- $L^{r}\Rightarrow P\Rightarrow D；a.s.\Rightarrow P\Rightarrow D$
- 极限为常数：$X_{n}\to^{D}c \Rightarrow X_{n}\to^{P}c$
- **弱大数**　$\bar X_{n}\to^{P}E(X_{1})$
- **强大数**　$\bar X_{n}\to^{a.s.}E(X_{1})$
- **常见条件：i.i.d. 且 $E|X_{1}|<\infty$**
- **样本方差**　$\sqrt{n}(S_{n}^2-\sigma^2)\xrightarrow{D}N(0,\tau^2)$，$\tau^2=Var((X-\mu)^2)$
## 测度论

- **$\sigma$-代数**＝允许讨论的事件：$\Omega\in\mathcal F$；$A\in\mathcal F\Rightarrow A^{c}\in\mathcal F$；可数并仍属于 $\mathcal F$
- **多维** $\Omega$：$\{1,2,3,4,5,6\}^2$——投掷两个骰子的结果
- **补集**：$A^c=\Omega\setminus A$　**Lebesgue 测度（长度）**：$\lambda$　**计数测度**：$\mu_Z$
- **测度**＝给集合分配大小：$\mu(\varnothing)=0；\mu(A)\ge0$
- **测度可加性**：
	- **两两不交时**：$\mu(\bigcup A_{i})=\sum\mu(A_{i})$
	- $\mu(A \bigcup B) = \mu(A) + \mu(B)$，例如：$\mu(\{\omega_1,\omega_2\}) = \mu(\{\omega_1\}) + \mu(\{\omega_2\})$
- **测度差**　$A\subset B,\mu(A)<\infty$：$\mu(B\setminus A)=\mu(B)-\mu(A)$
- 概率测度的**单调性**：$A \subseteq B \Rightarrow P(A) \leq P(B)$
- **概率测度归一性**：$P(\Omega)=1$
- **Dirac 测度**：$\delta_a(A)=\mathbf1_A(a)$，即 $a\in A$ 时为 $1$，否则为 $0$
- **构造新测度**：若 $f\ge0$ 可测，则 $\nu(A)=\int_A f\,d\mu$ 定义一个测度
- **计数测度**　$\mu_{Z}(A)=|A|；\mu_{Z}({x})=1$
- **Lebesgue 测度**：$\lambda((a,b))=\lambda([a,b])=\lambda((a,b])=b−a$，在**单离散点**测度为0
- **L–S 测度**　**区间**：$\lambda_{F}((a,b])=F(b)-F(a)$，**单点**：$\lambda_{F}(\{a\}) = F(a) - F(a^-)$
- **前推/像测度**：前推测度就是在 **输出/像空间** 的 概率测度，概率测度是在 **输入空间** $\Omega$ 上的测度
	- $P_f(A) = P(f^{-1}(A)) = P(\{\omega \in \Omega : f(\omega) \in A\})$
- **事件集合不相交**，概率测度 $P(A) + P(B) \leq 1$
- **概率相等**：只是 **集合测度** 相等，并不能推出集合本身相等
- **简单函数积分**　$\int_B f\,d\mu=\sum a_{i}\mu(A_{i})$ - 在积分
	- $f$：可测函数 - $f(\omega) = 1/\omega$
	- $B$：事件，在 $\Omega$ 上的一个$\sigma$-代数里面的一个**可测集合** - $\{1,2,3\}$
	- $A_i$：$B$ 中的元素进行不重叠的划分后形成的第 $i$ 个集合 - $\{2\}$
	- $a_i$：$A_i$ 中任意元素经过 $f$ 映射后的结果 - $1/2$
	- $\mu$：测度，把 $A_i$ 映射成一个实数 - $2$
- **Radon-Nikodym**：**概率测度** 写成 **密度函数的积分形式**
	- 什么时候可以把一个测度写成“**另一个测度的积分**”形式（什么时候有密度）
	- $\nu(A) = \int_A fd\mu$，测度 $\nu$ 写成 测度 $\mu$ 的积分形式，$f$ - **RN导数(密度)**
	- **判定条件**：$\mu(A) = 0 \Rightarrow \nu(A) = 0$ ，找到反例，则没有密度
- **零测集**：测度为 $0$ 的集合；不同测度有不同零测集，例如 $\lambda(\{0\})=0$，但 $\mu_Z(\{0\})=1$
- **前推/像测度**　$\mu_{f}(B)=\mu(f^{-1}(B))$
	- 用途：用 $f$ 把原空间测度搬到新空间；随机变量的分布就是前推测度
- **积分性质**　$\int(af+bg)\,d\mu=a\int f\,d\mu+b\int g\,d\mu$；$f\le g\Rightarrow\int f\,d\mu\le\int g\,d\mu$
## 固定证明模板 I

- **$\sigma$-代数**  
 ① $\Omega\in\mathcal F$　② 补集封闭　③ 可数并封闭：任意 $A_i\in\mathcal F$ 都有 $\bigcup_{i=1}^\infty A_i\in\mathcal F$（只验证有限并不够）
- **测度**  
 ① $\mu(\varnothing)=0$　② $\mu(A)\ge0$　③ 两两不交集合的可数可加：$\mu(\bigcup_{j=1}^{\infty}A_j)=\sum_{j=1}^{\infty}\mu(A_j)$
- **概率测度** 
 ① $P(\varnothing)=0$　② 非负　③ 两两不交时可数可加　④ $P(\Omega)=1$
- **概率密度 / PMF** 
 连续：$f\ge0，\int f=1$；离散：$p\ge0，\sum p=1$
- 关于测度 $\mu$ 的密度：$f\ge0\ \mu\text{-a.e.}；\int f\,d\mu=1$
- **分布函数 CDF** 
 ① 单调不减　② 右连续　③ $F(-\infty)=0$　④ $F(+\infty)=1$
- **一般 CDF 不要求处处连续；只要求右连续**
## 固定证明模板 II

- **独立** 
 连续查 $f_{XY}=f_{X}f_{Y}$；离散查 $p_{XY}=p_{X}p_{Y}$，须在完整支撑成立
- **一个反例点可否定独立；一个相等点不能证明独立**
- **函数可测** 
 证 $f^{-1}(B)\in\mathcal F$ 对所有 Borel $B$；常用查 $\{f\le x\}\in\mathcal F，\forall x$
- **依概率收敛** 
 任取 $\varepsilon>0$ → 写 $P(|X_n-X|>\varepsilon)$ → 化简/估计 → 极限证为 0
- **依分布收敛** 
 写 $F_n$ 和 $F$ → 找 $F$ 连续点 → 逐段证 $F_n(x)\to F(x)$
- **Glivenko–Cantelli**　$\sup_{x}|F_{n}(x)-F(x)|\to^{a.s.}0$
- $r>s\ge1：L^{r}\Rightarrow L^{s}$
- **Borel–Cantelli**　$\sum P(A_{n})<\infty\Rightarrow P(A_{n} i.o.)=0$
- **多元 CLT**　$\sqrt{n}(\bar X-\mu)\xrightarrow{D}N_{k}(0,\Sigma)$
- **R–N 密度存在** 
 查 $\nu\ll\mu$ → 写候选 $f=d\nu/d\mu$ → 验证 $\nu(A)=\int_A f\,d\mu$
- **R–N 密度不存在** 
 找 $A$：$\mu(A)=0，\nu(A)>0$
## Markov 链

- **状态空间** $S=\{s_1,...,s_n\}$ 
	- 设计包括 **吸收(终结)状态** 在内的状态
	- 注意下标就是**状态编号**
- **状态矩阵**：
	- 矩阵行＝**当前状态**，列＝下一状态；**每行和为 1**
	- **(行，列)**：当前状态到下一状态的概率
	- 吸收状态对应的行在其自身位置为 $1$、其余为 $0$；它不一定是第一行
	- $p_{ij}=P(X_{t+1}=j|X_{t}=i)$
- **转移过程**：
	- $X_0 = x$，第 0 时刻的状态，$x$ 是个具体含义，例如2块钱
	- $\mu^{(0)}$ ，初始状态是确定状态
		- 如果初始状态确定，$(s_0,...,s_n)$ 赋予一个确定的值，例如(0,1,0,0)
		- 如果初始状态随机，按概率给不同状态下一个值
	- $\mu^{(n+1)}=\mu^{(n)}P；\mu^{(n)}=\mu^{(0)}P^{n}$（行向量）
- **平稳分布**：$\pi=\pi P；\pi_{i}\ge0；\sum\pi_{i}=1$
