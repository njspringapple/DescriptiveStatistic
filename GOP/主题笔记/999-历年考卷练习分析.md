### 3. 概率分布和密度

#### 3.1 2022-3

设$$
F(x)=
\begin{cases}
0, & x < 0 \\
\log(ax + b), & 0 \le x \le \exp(1) \\
1, & x > \exp(1)
\end{cases}
$$
1. 对于参数 $a$ 和 $b$ 的哪些取值，$F(x)$ 是一个连续随机变量的分布函数（CDF）？

	要使 $F(x)$ 成为连续随机变量的分布函数，$F(x)$ 必须 处处连续 且 单调不减
	
	1.  **在 $x=0$ 处的连续性**： $\lim_{x \to 0^-} F(x) = 0, \quad \lim_{x \to 0^+} F(x) = \log(b)$，因此 $log(b) = 0 \Rightarrow b = 1$       **--- 注意，根据题目的条件，是 $x \to 0^-$ 左极限 = 常数值 0** 
	2.  **在 $x=exp(1)=e$ 处的连续性**：$\lim_{x \to e^-} F(x) = \log(ae + b), \quad \lim_{x \to e^+} F(x) = 1$，因此 $\log(ae + b) = 1 \Rightarrow ae + b = e$，代入 $b = 1$，得到 $a = \frac{e - 1}{e} = 1 - \frac{1}{e}$
	3.  **单调性检验** $(x \in [0, e]$）： $F'(x) = \frac{a}{ax + b}$，由于 $a = \frac{e-1}{e} > 0$ 且 $ax+b > 0$，故 $F'(x) > 0$，满足 **单调不减** 条件
	
	**最终答案**：
	
	$\boxed{a = 1 - \frac{1}{e}, \quad b = 1}$
	
	**考察点**：
	
	- 函数连续性判定，分段函数在每个分段点 求 左极限和右极限，连续要求：**左极限 = 右极限**
	- 分布函数判定，要求 **单调不减**，即 $F'(x) \geq 0$
	- 对数函数求 **一阶导数**
	- 左右极限的 **书写方式**

2. **对应的密度函数是什么？**

$$\frac{\partial F(x)}{\partial x} = \frac{a}{ax+b} = \frac{e-1}{(e-1)x+e}$$
$$
f(x) = \frac{e-1}{(e-1)x+e} \cdot \mathbf{1}_{[0,e]}(x)
$$
	定义域分开的写法 :
$$
f(x)=
\begin{cases}
\frac{e-1}{(e-1)x+e}, & 0 \le x \le e,\\
0, & \text{sonst}.
\end{cases}$$

**考察点**：

- 分布函数 **求一阶导数** 得到密度函数
- 洛必达求导法则
- 对数函数求导法则
- 用指示函数替代分段函数的书写方式
- 密度函数在定义域外取值为 0（**没有密度**），这个和分布函数不一样！！！

3. **分位函数（Quantilfunktion）是什么？计算 95% 分位数**？

	- 写出 p 值：$p = log(ax +b), exp(p) = ax + b, x = \frac{e(e^p-1)}{e-1}$ --- **一般来说，分布函数的取值就是 p值，很明显， p的取值范围是【0，1】**
	- **分位函数** 是 **分布函数** 的 **反函数**：$Q(p) = F^{-1}(p)=\frac{e(e^p-1)}{e-1}$
	- **通过分位函数求分位数**：$Q(0.95) = x_{0.95}=F^{-1}(0.95)=\frac{e(e^{0.95}-1)}{e-1}$
	- **求解得到**：$\boxed{x_{0.95}=\frac{e(e^{0.95}-1)}{e-1}}= 2.508$

	**考察点**：

	- p值就是分布函数的值，即 **分位值**
	- **分位函数** 是分布函数的 **反函数**，一般记为 $Q(p)$
	- 反函数的写法：$y = F(x) , x = F^{-1}(y)$     如果是分位函数，写为：$p = F(x) , x = F^{-1}(p)$
	- 已知分位函数，代入概率值，得到 “**分位数**”
	- 弄清楚哪个代表 **分位函数**，哪个代表 **分位值**

4. 通过分布函数，是否唯一确定了一个分布？ --- 根据分布函数定义，**是的**
5. 通过密度函数来确定分布函数，密度函数是否唯一？ --- 根据Radon-Nikodym定理，**不一定**

### 9. 条件概率

#### 9.1 2024-2

- 可供选择的是 N+1 叠轮盘筹码 $S_0, S_1, \dots, S_N$，它们具有不同的红色和蓝色筹码比例
- 每叠筹码总共包含 N 个筹码，在叠 $S_j$ 中恰好有 j 个红色筹码和 N−j 个蓝色筹码 
- 从这 N+1 叠筹码中**随机选择**一叠，然后从该叠中 **不放回** 地随机抽取 **两个** 筹码

- 用 $S_j，j \in \{0, ..., N\}$ 表示：“第 $j$ 叠筹码 $S_j$ **被选中的事件**  
- 用 $R_i，i = 1,2$ 表示：“第 i 个抽出的筹码 **是红色** 的事件
- $\sum_{j=0}^{N} j = \frac{N(N+1)}{2}\quad \text{und} \quad\sum_{j=0}^{N} j^2 = \frac{N(N+1)(2N+1)}{6}$


1. 给出 $P(R_1 | S_j)$，这个量在内容上意味着什么？

	- 在已知抽中了第 j 叠筹码的条件下，第一个筹码是红色的概率
	- 因为每叠筹码的总数为 N，其中红筹码数为 j，所以，概率：$P(R_1 | S_j) = j / N$

2. 请证明： $P(R_1) = 1/2$

	- 根据全概率 公式：
	- $P(R_1) = \Sigma_j P(R_1|S_j)P(S_j)$ 
	- = $\Sigma_j (j / N) 1/(N+1)$
	- = $\Sigma_j j / N(N+1)$
	- = $1/N(N+1) \cdot \Sigma_j j$
	- = $1/N(N+1) \cdot N(N+1)/2$
	- = 1/2


	**考察点：**

	- 全概率公式

3. 请确定 $P(R_1 \bigcap R_2∣S_j)$ 尽可能简化该表达式

	- **条件独立性**
	- $P(R_1 \bigcap R_2∣S_j) = P(R_1|S_j)P(R_2|S_j)$
	- $= j/N \cdot (j-1)/(N-1)$
	- $=j(j-1) / N(N-1)$
	- 所以，
		- $j \geq 2, j(j-1) / N(N-1)$
		- $j < 2, 0$
	- 或者，$j(j-1) / N(N-1) \cdot I_{j \geq 2}(j)$
		
	**考察点：**

	- 条件独立性
	- 概率结果中如果有 未知变量，需要按定义域写出分段概率，或者用指示函数，例如 $I_{j \geq 2}(j)$ 给出

4. 请计算（边缘）概率，即第一个和第二个抽出的筹码都是红色的概率

	- $P(R_1,R_2)$
	- $= \Sigma_j P(R_1,R_2|S_j)P(S_j)$
	- $=\Sigma_j j(j-1) / N(N-1) \cdot 1/(N+1)$
	- $=1/N(N-1)(N+1) \Sigma_j j^2 - j, j = 0,1,...,N$
	- $=1/3$

	**考察点：**

	- 条件全概率公式
	- 利用前面的结论
