### 3. 概率分布和密度


#### 3.1 2022-3

设$$
F(x)=
\begin{cases}
0, & x < 0 \\
\log(ax + b), & 0 \le x \le \exp(1) \\
1, & x > \exp(1)
\end{cases}
$$
1. 对于参数 $a$ 和 $b$ 的哪些取值，$F(x)$ 是一个连续随机变量的分布函数（CDF）？

	要使 $F(x)$ 成为连续随机变量的分布函数，$F(x)$ 必须 处处连续 且 单调不减
	
	1. **分布函数是 右 连续**，如果有 “连续”，则需要求左极限，否则只要求右极限和函数值相同
	2. **在 $x=0$ 处的连续性**： $\lim_{x \to 0^-} F(x) = 0, \quad \lim_{x \to 0^+} F(x) = \log(b)$，因此 $\log(b) = 0 \Rightarrow b = 1$。注意：根据题目的条件，左极限 $=0$ 来自 $x<0$ 时 $F(x)=0$
	3.  **在 $x=exp(1)=e$ 处的连续性**：$\lim_{x \to e^-} F(x) = \log(ae + b), \quad \lim_{x \to e^+} F(x) = 1$，因此 $\log(ae + b) = 1 \Rightarrow ae + b = e$，代入 $b = 1$，得到 $a = \frac{e - 1}{e} = 1 - \frac{1}{e}$
	4.  **单调性检验** $(x \in [0, e]$）： $F'(x) = \frac{a}{ax + b}$，由于 $a = \frac{e-1}{e} > 0$ 且 $ax+b > 0$，故 $F'(x) > 0$，满足 **单调不减** 条件
	
	**最终答案**：
	
	$\boxed{a = 1 - \frac{1}{e}, \quad b = 1}$
	
	**考察点**：
	
	- 函数连续性判定，分段函数在每个分段点 求 左极限和右极限，连续要求：**左极限 = 右极限**
	- 分布函数判定，要求 **单调不减**，即 $F'(x) \geq 0$
	- 对数函数求 **一阶导数**
	- 左右极限的 **书写方式**

2. **对应的密度函数是什么？**

$$\frac{\partial F(x)}{\partial x} = \frac{a}{ax+b} = \frac{e-1}{(e-1)x+e}$$
$$
f(x) = \frac{e-1}{(e-1)x+e} \cdot \mathbf{1}_{[0,e]}(x)
$$
	定义域分开的写法 :
$$
f(x)=
\begin{cases}
\frac{e-1}{(e-1)x+e}, & 0 \le x \le e,\\
0, & \text{sonst}.
\end{cases}$$

**考察点**：

- 分布函数 **求一阶导数** 得到密度函数
- 洛必达求导法则
- 对数函数求导法则
- 用指示函数替代分段函数的书写方式
- 密度函数在定义域外取值为 0（**没有密度**），这个和分布函数不一样！！！

3. **分位函数（Quantilfunktion）是什么？计算 95% 分位数**？

	- 写出 p 值：$p = log(ax +b), exp(p) = ax + b, x = \frac{e(e^p-1)}{e-1}$ --- **一般来说，分布函数的取值就是 p值，很明显， p的取值范围是【0，1】**
	- **分位函数** 是 **分布函数** 的 **反函数**：$Q(p) = F^{-1}(p)=\frac{e(e^p-1)}{e-1}$
	- **通过分位函数求分位数**：$Q(0.95) = x_{0.95}=F^{-1}(0.95)=\frac{e(e^{0.95}-1)}{e-1}$
	- **求解得到**：$\boxed{x_{0.95}=\frac{e(e^{0.95}-1)}{e-1}}= 2.508$

	**考察点**：

	- p值就是分布函数的值，即 **分位值**
	- **分位函数** 是分布函数的 **反函数**，一般记为 $Q(p)$
	- 反函数的写法：$y = F(x) , x = F^{-1}(y)$     如果是分位函数，写为：$p = F(x) , x = F^{-1}(p)$
	- 已知分位函数，代入概率值，得到 “**分位数**”
	- 弄清楚哪个代表 **分位函数**，哪个代表 **分位值**

4. 通过分布函数，是否唯一确定了一个分布？ --- 根据分布函数定义，**是的**
5. 通过密度函数来确定分布函数，密度函数是否唯一？ --- 根据Radon-Nikodym定理，**不一定**

方法1：贝叶斯公式

- K - 患病
- Pos - 诊断
- $\gamma(K) = 1:999$  ==> P(K) = 0.001

- = (0.95 * 0.001) / (0.95 * 0.001 + 0.01 * 0.999) 
- = 8.68%

- 设有 x 患者，y 健康
- 设计混淆矩阵

| 检测出来   | 5x   | 95x  |

	- 因为每叠筹码的总数为 N，其中红筹码数为 j，所以，概率：$P(R_1 | S_j) = j / N$

	- $P(R_1) = \Sigma_j P(R_1|S_j)P(S_j)$ 
	- = $\Sigma_j (j / N) 1/(N+1)$
	- = $\Sigma_j j / N(N+1)$
	- = $1/N(N+1) \cdot \Sigma_j j$
	- = $1/N(N+1) \cdot N(N+1)/2$
	- = 1/2

	- 全概率公式

3. 请确定 $P(R_1 \bigcap R_2∣S_j)$ 尽可能简化该表达式

	- $P(R_1 \bigcap R_2∣S_j) = P(R_1|S_j)P(R_2|S_j)$

	- $=j(j-1) / N(N-1)$
	- 所以，
		- $j \geq 2, j(j-1) / N(N-1)$
		- $j < 2, 0$

#### 11.1 2025-7

设 $X_n$ 和 $X$ 是取值于 $\{0,1\}$ 的离散随机变量。证明：$X_n\xrightarrow{d}X$，当且仅当 $P(X_n=0)\to P(X=0)$

- **依分布收敛定义**：设 $X_i$ 有分布函数 $F_i$。**若对每个 $F$ 的连续点 $x$**，$\lim_{n \to \infty} F_n(x) = F(x)$，则称 $(X_n)$ 依分布收敛于 $X$，记作 $X_n \xrightarrow{D} X$
- **条件**：
	- $Xn$ 的分布函数：
		- x < 0,  $F_n(x) = 0$  -- 不可能发生，所以是 0
		- 0 <= x < 1，$F_n(x) = P(X_n=0)$
		- x >= 1，$F_n(x) = 1$
	- $X$ 的分布函数：
		- x < 0,  $F_(x) = 0$
		- 0 < x <= 1，$F(x) = P(X=0)$
		- x > 1，$F(x) = 1$
- **充分性**：
	- 在 $x < 0$ 和 $x \geq 1$ 两个区间，$F_n(x) = F(x)$
	- 在 $0 \leq x < 1$ 区间， $P(X_n=0) \to P(X=0)$
	- 所以，在 $x \in \mathbb{R}$，有 $F_n(x) \to F(x)$
- **必要性**：
	- 因为 $X_n\xrightarrow{d}X$, **所以对于所有 $F(x)$的连续点**， $F_n(x) \to F(x)$
		- x = 0，左极限 = 0， 右极限 = P(X = 0)，**不连续**
		- x = 1,   左极限 = P(X=0)， 右极限 = 1 ，**不连续** -- 注意 左极限，那就是趋近于1，不到1，因为只有2个取值，所以只能是 P(X=0)
	- 所以，我们必须找一个 F 的连续点代入，因为在 x = 0 ， x = 1 是不连续的，所以我们在 【0，1】之间找一个点，例如 1/2
		- 在 【0，1）区间内连续，因为 左极限 = 右极限 = P(X=0)
	- $F_n(1/2) = P(X_n \leq 1/2) = P(X_n = 0)$
	- 同理，$F(1/2) = P(X=0)$
	- 根据条件，因为 $F_n(1/2) \to F(1/2)$
	- 所以  $P(X_n=0)\to P(X=0)$


	**考察点：**

	- 离散随机变量的分布函数书写：
		- 离散随机变量写分布函数，**一定要在 $(-\infty,+\infty)$ 上写完整**！！！！可以采用分段函数形式，或者指示函数形式
		- 分布函数的区间 写成 **区间左闭右开**  ，因为分布函数要求 **右连续** ！！！
	- 离散型随机变量为什么要写 例如 x < 0 或者 x > 1 这两个区间，因为 分布函数是问的 F(x) = P(X <= x) 的概率，而不是 x = 1 的概率，例如这题 F(2) = P(X <= 2) = P(X = 0) + P(X = 1)
	- 离散随机变量在分割点的**连续性判断**
	- 分布收敛定义
