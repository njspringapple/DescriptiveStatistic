函数性质、坐标轴交点、导数与原函数

A4 横向 · 1 页

二次函数

y = x² − 2x − 3

定义域：R

值域：[−4，+∞)

对称轴：x = 1

顶点：(1，−4)

x轴交点： (−1，0)、(3，0)

y轴交点：(0，−3)

导数： y′ = 2x − 2

原函数： x³/3 − x² − 3x + C

二次函数

y = −2x² + 3

定义域：R

值域：(−∞，3]

对称轴：x = 0

顶点：(0，3)

x轴交点： (±√6/2，0)

y轴交点：(0，3)

导数： y′ = −4x

原函数： −2x³/3 + 3x + C

一次函数

y = kx + b

条件：k ≠ 0

定义域：R

值域：R

单调性： k>0递增，k<0递减

x轴交点：(−b/k，0)

y轴交点：(0，b)

导数： y′ = k

原函数： kx²/2 + bx + C

图中示例：k=1，b=1。

反比例函数

y = 1/x

定义域：x ≠ 0

值域：y ≠ 0

奇偶性：奇函数

单调性： 两个区间内均递减

渐近线：x=0，y=0

坐标轴交点：无

导数： y′ = −1/x²

原函数： ln|x| + C

绝对值函数

y = |x|

定义域：R

值域：[0，+∞)

奇偶性：偶函数

对称轴：y轴

最小值：0

坐标轴交点：(0，0)

导数： −1(x<0)，1(x>0)

x=0：不可导

原函数： x|x|/2 + C

指数函数

y = eˣ

定义域：R

值域：(0，+∞)

单调性：单调递增

水平渐近线：y = 0

x轴交点：无

y轴交点：(0，1)

导数： y′ = eˣ

原函数： eˣ + C

对数函数

y = ln x

定义域：(0，+∞)

值域：R

单调性：单调递增

垂直渐近线：x = 0

x轴交点：(1，0)

y轴交点：无

导数： y′ = 1/x

原函数： x ln x − x + C

正弦函数

y = sin x

定义域：R

值域：[−1，1]

奇偶性：奇函数

周期：2π

零点：x = kπ，k∈Z

导数： y′ = cos x

原函数： −cos x + C

余弦函数

y = cos x

定义域：R

值域：[−1，1]

奇偶性：偶函数

周期：2π

零点： x = π/2 + kπ

y轴交点：(0，1)

导数： y′ = −sin x

原函数： sin x + C
