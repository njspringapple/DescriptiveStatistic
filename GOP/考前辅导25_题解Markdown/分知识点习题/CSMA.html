看懂每一段时间到底是什么时间

先搞懂 “bit time（比特时间）”

bit time = 发送 1 个比特所需的时间。它不是固定的秒数，而是取决于链路速率 R： 发送越快，1 bit 占用的时间越短。

1 bit time = 1 / R 秒

碰撞后的三个关键时间参数

djam = 32 bit  — 干扰信号

检测到碰撞后，网卡故意再发一小段噪声，让整个冲突域里所有主机都确认“撞了”。作用：广播碰撞消息。

dslot = 512 bit  — 退避时隙

退避算法的基本时间单位。碰撞后随机选一个整数 r，等待 r × dslot。作用：把大家的重发时间错开。

dfrei = 96 bit  — 帧间间隔（发送前空闲）

真正发送前，信道必须连续保持空闲这么久才允许开始发。作用：给网络一个恢复缓冲（Interframe Gap）。

一句话记忆：
碰撞后 → 先发 jam 噪声 → 随机等若干个 slot → 确认信道空闲 dfrei → 再发送
