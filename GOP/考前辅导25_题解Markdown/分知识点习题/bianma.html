1 什么是曼彻斯特编码？

曼彻斯特编码的关键特征：每个比特的中间一定发生一次电平跳变。

普通二进制信号

普通信号可能长时间保持高电平或低电平。 如果连续传输很多个相同的比特，接收方可能难以判断每一位从哪里开始。

曼彻斯特编码

每一个比特周期都被分成前、后两个半周期， 中间的跳变既表示数据，也能够帮助发送方和接收方同步时钟。

本题使用的规则： 比特中间由低电平跳到高电平表示 0； 由高电平跳到低电平表示 1。
0
0 = 低 → 高
在比特周期的中间出现上升沿。
1
1 = 高 → 低
在比特周期的中间出现下降沿。
注意： 曼彻斯特编码存在不同约定。有些教材会把 0 和 1 的跳变方向对调。 做题时必须先根据题目、教材或已知波形确认规则。 本页面完全按照图片中的规则： 低→高为 0，高→低为 1。

问题（a）：波形表示的比特序列是什么？

请连续输入所有比特，不需要空格。例如： 0101

读取方法

  1. 先利用竖直虚线将波形划分成 12 个比特周期。
  2. 只观察每个比特正中间的跳变，不要优先分析边界跳变。
  3. 中间低→高，记录为 0。
  4. 中间高→低，记录为 1。
  5. 从左到右组合全部结果。

最终序列为： 011010011001

点击模糊的答案可以显示或隐藏。

4 传输速率和波特率

传输速率 Bit Rate

表示每秒传输了多少个数据比特，单位通常为 bit/s 或 bps。

Rb = N ÷ T N 是比特数，T 是以秒为单位的时间

波特率 Baud Rate

在本题的计算模型中，一个数据比特包含两个信号单元， 因此曼彻斯特编码的波特率是比特率的 2 倍。

Rs = 2 × Rb Rₛ 为波特率，单位是 Baud
时间必须先换算为秒： 1 ms = 0.001 s = 10-3 s

问题（b-i）：12 bit 在 1 ms 内传完，传输速率是多少？

bit/s

问题（b-ii）：曼彻斯特信号的波特率是多少？

Baud
步骤 计算 结果
时间换算 1 ms = 1 ÷ 1000 s 0.001 s
计算比特率 12 bit ÷ 0.001 s 12000 bit/s
计算波特率 2 × 12000 24000 Baud

7 解题口诀与最终答案

读取波形口诀

  1. 先按照虚线划分比特周期。
  2. 观察每一位中间的跳变。
  3. 低到高记作 0。
  4. 高到低记作 1。
  5. 从左到右连接全部比特。

速率计算口诀

  1. 毫秒先除以 1000，换算成秒。
  2. 比特率 = 比特数 ÷ 时间。
  3. 本题曼彻斯特波特率 = 2 × 比特率。
  4. 注意区分 bit/s 和 Baud。
原题最终答案：
（a）比特序列： 011010011001
（b-i）传输速率： 12000 bit/s
（b-ii）波特率： 24000 Baud
