Im Unterricht 01

Süß oder sauer?

关闭「中文」，指图提问 Wie schmeckt das? 学生用 süß / sauer / saftig / bitter / reif 回答，练形容词。

Im Unterricht 02

Obstsalat-Spiel

每人抽三张卡组成水果沙拉并说出来：In meinen Obstsalat kommen eine Banane, zwei Kiwis und Erdbeeren.（练第四格与复数）

Im Unterricht 03

Saft & Marmelade

用「打乱」随机点词做复合词造词：Apfel → der Apfelsaft, der Apfelkuchen, das Apfelmus；Erdbeere → die Erdbeermarmelade。

Genus-Trick & Mengenangaben

水果的词性与量词

90 % = die

几乎所有水果都是阴性：die Birne, die Kirsche, die Banane, die Orange …
以 -e 结尾的名词大多是 die。

3 个常见例外 = der

der Apfel · der Pfirsich · der Granatapfel
（还有 der Pflaumenbaum 等以树命名的词）

统称 = das Obst

das Obst 不可数，无复数：
Ich esse viel Obst.
单个果实用 die Frucht / die Früchte。

  • ein Kilo Äpfel · ein Pfund Kirschen一公斤苹果 · 一磅樱桃（Pfund = 500 g）
  • eine Schale Erdbeeren · eine Kiste Orangen一盒草莓 · 一箱橙子
  • ein Stück Melone · eine Scheibe Ananas一块瓜 · 一片菠萝
  • Obst schälen / schneiden / pressen削皮 / 切 / 榨汁
  • Beeren pflücken · Obst waschen采浆果 · 洗水果
  • reif ↔ unreif · frisch ↔ verdorben熟 ↔ 生 · 新鲜 ↔ 坏了
