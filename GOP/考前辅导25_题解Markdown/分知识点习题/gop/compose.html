一张带墨迹的透明塑料布

横轴是身高 X，纵轴是体重 Y；墨越浓，附近的人越多。

身高—体重平面：每个光点代表一个人

联合密度在描述什么？

在旧坐标纸上取一个很小的格子：

P(x ≤ X ≤ x+dx, y ≤ Y ≤ y+dy) ≈ fX,Y(x,y) dx dy

因此，fX,Y(x,y) 不是某个点上的人数， 而是“每单位旧面积所含的概率”。

塑料布比喻： 把概率看作布上的墨。密度大表示单位面积内墨多， 但整个布上的墨迹总量始终是 1。

补一个变量：让“一人一位”重新成立

Z 是队伍号，W 是队伍中的位置标签。

选择辅助变量 W = Y

给每个人贴两个新标签：

Z = Y/X²,    W = Y

因为 w = y，所以可以反解：

x = √(w/z),    y = w

只要 z > 0、w > 0，每一组 (z,w) 都能找回唯一的 (x,y)。因此二维到二维的换元重新变得可逆。

W 是脚手架。 它不是最终目标，只是为了在换元过程中保留“这个人究竟是谁”的信息。

重点：补变量不是多此一举，而是为了恢复可逆性。

为什么最后必须积分？

一条线没有面积；密度真正统计的是宽度为 dz 的薄条。

不能直接数“第 z 条线”

对连续型随机变量，精确等于某个数的概率通常为零：

P(Z = z) = 0

密度的含义是：

P(z ≤ Z ≤ z+dz) ≈ fZ(z) dz

所以应该统计新坐标平面中宽度为 dz 的竖直薄条。 薄条内部，w 从队头到队尾连续变化。

∫…dw 的直观意义： 将同一个 BMI 队伍中所有不同体重位置的贡献加起来。 积分完成后，不再关心座位号 W，所以 W 被“边缘化”掉。
积分不是额外技巧，而是在把整条队伍从头到尾数一遍。

完整推导：四步走

从目标变量到最终边缘密度。

确定目标变量

Z = Y/X²

单独的 Z 不足以找回 X、Y，因此映射不可逆。

补辅助变量

Z = Y/X²,   W = Y

此时可以反解 x = √(w/z)、y = w。

做二维密度换元

fZ,W(z,w) = fX,Y(√(w/z),w) · √w/(2z3/2)

积分消去辅助变量

fZ(z) = ∫fZ,W(z,w)dw

一句话记忆

补 W： 让每个人在新坐标中仍有唯一位置。

乘 |J|： 把“每单位旧面积”兑换成“每单位新面积”。

对 W 积分： 把同一 BMI 队伍中的所有位置贡献加起来。

先保留信息 → 再换算面积 → 最后收拢信息
积分上下限不能机械地写成 −∞ 到 +∞。 严格地说，应在所有满足 (√(w/z),w) 位于原联合密度支持集内的 w 上积分。
