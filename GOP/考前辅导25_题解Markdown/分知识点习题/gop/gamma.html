看得见的 Gamma

两个常被搞混的东西：Γ 函数——阶乘的连续版；Gamma 分布——「等到第 k 件事发生」要花多久。

它们的关系其实特别简单：Γ 函数只是 Gamma 分布用来「把面积压成 1」的那个分母。本页一步步把它们画出来，最后你会看到 χ² 只是 Gamma 的一个特例。

0先把两个「Gamma」分开放

　Γ 函数 Gamma functionGamma 分布 Gamma distribution
它是什么一个普通的数学函数：输入一个数，输出一个数一个概率分布：描述某个随机量的取值规律
解决什么问题阶乘只能算整数，3.5! 是多少？顾客一个个来，等到第 3 个要多久？
一句话Γ(n) = (n−1)!，把阶乘连成光滑曲线k 个「指数等待」接力赛的总时间
两者的关系Gamma 分布的密度公式里要除一个数，才能让总面积＝1。那个数正好就是 Γ 函数的值。—— 仅此而已，别再混了。
本页的主线：阶乘 → Γ 函数（一块面积）→ 把面积压成 1 → Gamma 分布 → 特例（指数 / 卡方 / 正态）。

1Γ 函数的由来：把阶乘的「点」连成「线」

300 年前欧拉的问题很朴素：1!=1, 2!=2, 3!=6 … 这些孤立的点，能不能用一条光滑曲线穿过去？

Γ(n) = (n − 1)!　　例：Γ(1)=0!=1,　Γ(4)=3!=6,　Γ(5)=4!=24
看图能直接读出的三件事：
① 金色曲线正好穿过所有阶乘点（1,1)(2,1)(3,2)(4,6)…——阶乘被「连续化」了。
② 递推关系 Γ(x+1) = x·Γ(x)：这就是阶乘 n!=n·(n−1)! 的翻译版，拖动滑块可自己验证。
③ 0 和负整数处炸成竖直渐近线（0!、(−1)! 本来就没意义）；负半轴还会正负翻转——所以 Γ 只在 x>0 时被概率论使用。
⭐ 一个必须记住的特殊值：Γ(1/2) = √π ≈ 1.7725。
为什么冒出 π？因为它等价于高斯积分 ∫e−x²dx=√π ——正态分布的那个 √(2π) 就是它的亲戚。
这解释了一个你早就见过的现象：χ²、t 分布的密度公式里为什么老是出现 Γ 和 √π。它们本质上都在做「把面积归一化」这一件事。

历史小坑：为什么是 (n−1)! 而不是 n!？纯属勒让德当年定义时的选择，后人沿用至今。把这个「错位一」当成一个必须硬记的历史遗产就好。

2Γ(a) 到底是什么？——它是一块面积

别怕这个积分，它只是「一条曲线下面的面积」。你只需要看图。

Γ(a) = ∫0∞ xa−1 e−x dx　←　就是下图阴影的面积
为什么这个形状必然是「先升后降的鼓包」？因为它是两股力量打架的结果：
• xa−1：往上推（x 越大越大）
• e−x：往下压（指数衰减，压得非常狠）
前期推力赢 → 上升；后期指数衰减一定赢 → 迅速趋 0。所以面积是有限的，Γ(a) 才存在。
a 越大，鼓包越往右移、越高 → 面积暴涨 → 这正是阶乘爆炸式增长的几何解释。

3关键一步：把这块面积「压成 1」，概率分布就诞生了

概率密度只有一个硬要求：总面积必须等于 1。而上面那条曲线的面积恰好是 Γ(a)。怎么办？除掉它就行。

f(x) = xa−1 e−x ⁄ Γ(a)　　⟹　面积 = Γ(a)/Γ(a) = 1 ✔

原始曲线：面积 = Γ(a)，不是概率密度

除以 Γ(a) 之后：面积 = 1，正式成为 Gamma 分布

⭐ 全页最重要的一句话：
Γ 函数在 Gamma 分布里的唯一职责，就是当那个「归一化常数」（分母）。
它不神秘，也不参与任何概率意义。你以后看到密度公式里的 Γ、B（Beta 函数）、√(2π)，一律翻译成「负责把面积调成 1 的那个数」，公式立刻不可怕了。

再加一个「尺度参数」θ 把横轴单位换掉（分钟→小时、元→万元），就得到完整形式：

f(x) = xk−1 e−x/θ ⁄ ( Γ(k) · θk )　,　x > 0

k = 形状参数（shape，也写 α）；θ = 尺度参数（scale）；有些书用速率 λ = 1/θ（rate）。这两种写法混用是 Gamma 的第一大坑，见第 9 节。

4Gamma 分布的由来：等到第 k 个人来，要多久？

上面是「代数上的由来」，这里是「现实中的由来」——也是你真正该记住的那个画面。

场景：便利店顾客随机来，平均每 θ 分钟来 1 位（泊松过程）。

  • 等到 第 1 位 顾客的时间 → 指数分布 Exp(θ)
  • 等到 第 k 位 顾客的时间 → Gamma(k, θ)（k 为整数时也叫 Erlang 分布）
Gamma(k, θ) = Exp(θ) + Exp(θ) + … + Exp(θ)　（k 个独立相加）

↑ 时间轴：每个蓝点是一位顾客到店；粉色是第 k 位到店的时刻，它就是本次抽样值。

模拟直方图 理论 Gamma(k,θ) 密度 k=1 的指数分布（对比）
把 k 从 1 拖到 8，观察这个极其重要的变化：
• k=1：密度最高点贴在 0 上，「最可能马上就来」——这是指数分布的无记忆性。
• k 变大：鼓包离开 0、右移、变对称。因为「运气会互相抵消」：有的间隔长、有的短，加起来越来越稳。
• 均值 = kθ（k 段，每段平均 θ）；方差 = kθ²；相对波动 CV = 1/√k → 等的人越多，总时间反而越「可预测」。
• k 很大时几乎变成正态——中心极限定理，因为它就是一堆独立随机量之和。

5两个参数各管什么？（这是最实用的直觉）

k：形状参数 —— 管「长相」
  • k < 1：密度在 0 处冲向无穷（一根尖刺）。含义：绝大多数取值极小，偶尔很大。⚠ 密度无界但面积仍是 1，合法。
  • k = 1：正好是指数分布，从最高点一路下滑（滑梯）。
  • k > 1：出现鼓包，众数 = (k−1)θ。
  • k → 大：右偏消失，趋近正态。
θ：尺度参数 —— 只管「刻度」
  • 改 θ 只是横轴拉伸/压缩（形状一模一样），相当于把「分钟」换成「小时」。
  • 所以 θ 是单位，k 才是性格。
  • 右偏分布的铁律：众数 < 中位数 < 均值（看图上三条线的顺序，永远这样）。

6家谱：Gamma 是一整个家族的「母分布」

上一课的 χ² 到这里终于露出真身：χ²(v) 就是 Gamma(k=v/2, θ=2)。不信？下面这张图叠给你看。

眼见为实：Gamma(v/2, 2) 与 χ²(v) 完全重合

怎么记这个换算？「自由度对半，尺度取二」。
验算法（不用背公式）：Gamma 均值 = kθ = (v/2)·2 = v ✔ 与卡方均值一致；方差 = kθ² = (v/2)·4 = 2v ✔ 也一致。
更深的原因：χ² 是 Z² 之和，而单个 Z² 就是 Gamma(1/2, 2)；相加封闭性一用，v 个加起来就是 Gamma(v/2, 2)。
彩蛋：Γ(1/2)=√π 正是这里出现的——Z² 的密度归一化常数需要它。上一课的公式和这一课在此闭环。

再看那条青色虚线：泊松 ↔ Gamma 对偶

同一条时间轴，两种数法：
• 泊松：竖着数——「30 分钟内来了几个人？」（时间固定，个数随机，离散）
• Gamma：横着量——「攒够 3 个人花了多久？」（个数固定，时间随机，连续）
于是必然有恒等式：P(等第 k 个人 ≤ t) = P(t 时间内至少来了 k 个人)。第 11 节会用它做一道题。

9踩坑清单（Gamma 的坑比 t/F 更隐蔽）

🔥 第一大坑：scale 还是 rate？

同一个分布有两套写法，方向正好相反：

θ（scale，尺度）= 1 / λ（rate，速率）
  • 「平均每 4 分钟来一位」→ θ=4，λ=0.25。写错就差 16 倍。
  • R：rgamma(n, shape, rate=) 默认用 rate；也可写 scale=。
  • Python/SciPy：gamma(a, scale=) 用 scale，没有 rate 参数。
  • 自检法：算一下均值。kθ = k/λ 是否等于你心里那个「大概多少」？数量级不对就是搞反了。

其它常见坑

  • Γ 函数 ≠ Gamma 分布。前者是归一化常数，后者是分布。别在报告里写「数据服从 Gamma 函数」。
  • Γ(n) = (n−1)!，错位一。Γ(5)=24 不是 120。
  • k<1 时密度在 0 处无界，这不是 bug；密度可以无穷大，只要面积是 1。但此时不要用「众数」描述中心。
  • 只有 k=1（指数）才无记忆。k>1 时「已经等了很久」确实意味着「快到了」，不能乱套用指数的结论。
  • 相加封闭要求 θ 相同：Gamma(2,3)+Gamma(5,3)=Gamma(7,3) ✔；θ 不同则不再是 Gamma ✘。
  • 右偏 ⇒ 均值会骗人：平均赔付 12 万，但一半的案子低于 10.7 万。汇报时给中位数和分位数。
  • x>0 严格成立：数据里有 0 或负值时不能直接拟合 Gamma（考虑零膨胀模型或 Tweedie）。
  • 数值溢出：Γ(171) 就超出双精度了。永远用 lgamma（对数版）再取指数——本页代码就是这么做的。
  • k 是「形状」不是「个数」：k 允许是 2.7 这样的小数（此时不再有「等第 k 个人」的字面解释，纯粹当拟合参数用）。

10怎样才不容易忘

① 两句话总纲（背这个）

Γ 函数：阶乘的连续版，也是让面积等于 1 的那个分母。
Gamma 分布：k 个指数等待的接力赛总时间。

前者管「公式长相」，后者管「现实含义」。

② 参数口诀

形状定长相，尺度定刻度。

k 决定像滑梯还是像钟；θ 只是把横轴单位换掉。

③ 数字全部从「一个指数」推出来，不用死背

一段等待：均值 θ，方差 θ²。k 段独立相加 → 两个都乘 k：

均值 = kθ　方差 = kθ²　标准差 = √k·θ　CV = 1/√k

众数 = (k−1)θ（记法：「去掉一段」才到峰顶，k=1 时峰顶就在 0）。

④ 形状联想（看图记）

  • k<1：贴墙的一根尖刺。
  • k=1：滑梯（指数）。
  • k=2~5：右偏的小山包，慢慢往右挪、慢慢变对称。
  • k 很大：钟（正态）。

一句话动画：「刺 → 滑梯 → 小山 → 钟」，k 一路变大就是这个顺序。

⑤ 三个必记特殊值/换算

  • Γ(1/2) = √π（半整数出 π，正态的老朋友）
  • Γ(n) = (n−1)!（错位一）
  • χ²(v) = Gamma(v/2, 2)（自由度对半，尺度取二）

⑥ 用一个故事串全场

便利店等第 3 位顾客 → Gamma；只等第 1 位 → 指数；问「半小时来几个」→ 泊松；把 Z 平方堆起来 → 卡方也是 Gamma。一条时间轴，四个分布。

11实战：一家便利店，把 Gamma 全用一遍

设定：顾客随机到店，平均每 4 分钟 1 位（θ=4 分钟，λ=0.25 位/分钟）。

指数 Q1：等第 1 位顾客，超过 10 分钟没人来的概率？

T₁ ~ Exp(θ=4)，均值 4 分钟 P(T₁ > 10) = e^(−10/4) = e^(−2.5) ≈ 8.2% ※ 无记忆性：已经空等了 7 分钟，再等 10 分钟没人的概率还是 8.2%（不会“越等越快来”）。

Gamma Q2：你想「凑够 3 单」就去后厨休息，要等多久？

T₃ ~ Gamma(k=3, θ=4) 均值 = kθ = 3×4 = 12 分钟 方差 = kθ² = 3×16 = 48 标准差 = √48 ≈ 6.93 分钟 众数 = (k−1)θ = 2×4 = 8 分钟 ← 最“常见”的等待 中位数 ≈ 10.7 分钟 CV = 1/√3 ≈ 58% （若等第 12 单，CV 降到 29%：越多越稳） ⇒ 右偏铁律：众数 8 < 中位数 10.7 < 均值 12 ✔
落地解读：“平均 12 分钟”其实有点骗人——一半的日子 10.7 分钟内就凑够了，但偶尔会拖到 25 分钟以上。 排班/承诺时效要看分位数，不能只看均值。

对偶 Q3：10 分钟内能凑够 3 单吗？——用泊松换个算法

要算 P(T₃ ≤ 10)。直接积分麻烦，用对偶恒等式： P(T₃ ≤ 10) = P(10 分钟内至少来 3 位) = 1 − P(N ≤ 2)，其中 N ~ 泊松(λt = 0.25×10 = 2.5) P(N ≤ 2) = e^(−2.5) × (1 + 2.5 + 2.5²/2) = 0.0821 × 6.625 ≈ 0.544 ⇒ P(T₃ ≤ 10) ≈ 45.6% （不到一半，符合“中位数 10.7 > 10”）

这就是 Erlang 分布 CDF 的来历：一个连续分布的概率，被一串离散泊松项算了出来。看到「第 k 个事件」就想到这条桥。

自己动手玩：

可靠性 Q4：3 块备用电池接力，总续航？

每块电池平均寿命 200 小时（近似指数）→ 总续航 ~ Gamma(3, 200) 均值 = 600 小时，标准差 = √3×200 ≈ 346 小时，CV = 58% 带 12 块：均值 2400 小时，CV 降到 29% ← 备件越多，总寿命越可预测（这就是冗余设计的统计学意义）

🥚 彩蛋 Q5：你上一课算过的 χ² 也在这里

做方差推断时用的 χ²(4)，其实就是 Gamma(k=2, θ=2)：
均值 kθ = 2×2 = 4 ✔（等于自由度）；方差 kθ² = 2×4 = 8 ✔（等于 2v）。
所以卡方的「右偏、非负、df 越大越像正态」这三条性质，你现在有了更根本的解释：因为它就是一个 Gamma。

12三十秒自测（点击题目看答案）

Q1. Γ 函数在 Gamma 分布的密度公式里扮演什么角色？ ▸

归一化常数（分母）。曲线 x^(k−1)e^(−x/θ) 下的面积是 Γ(k)θ^k，除掉它，面积才等于 1，才配叫概率密度。它本身没有概率含义。

Q2. Γ(6) 等于多少？为什么容易错？ ▸

Γ(6) = 5! = 120，不是 720。因为定义式里的指数是 x^(a−1)，导致「错位一」——历史遗留的定义习惯。

Q3. 「平均每 5 分钟来一个人，等第 4 个人」的均值、方差、众数各是多少？ ▸

θ=5, k=4。均值 kθ=20 分钟；方差 kθ²=4×25=100（标准差 10）；众数 (k−1)θ=15 分钟。注意众数 < 中位数 < 均值。

Q4. 某软件要求填 rate，你只知道「平均间隔 8 分钟」，该填什么？ ▸

填 rate = 1/8 = 0.125（不是 8）。检查方式：算出的均值 k/λ 应该等于 8k 分钟，量级对了才放心。

Q5. χ²(10) 用 Gamma 怎么写？验算一下。 ▸

Gamma(k=5, θ=2)（自由度对半，尺度取二）。均值 kθ=10 ✔（=v），方差 kθ²=5×4=20 ✔（=2v）。

Q6. 为什么 k 越大，Gamma 越像正态、相对波动越小？ ▸

因为 Gamma(k,θ) 是 k 个独立指数之和：① 独立随机量求和 → 中心极限定理 → 趋近正态；② 均值随 k 线性增长（kθ），标准差只随 √k 增长（√k·θ），所以 CV=1/√k 逐渐变小。「加起来的东西，运气会互相抵消。」

Q7. 一句话说清泊松和 Gamma 的关系。 ▸

同一条时间轴的两种问法：泊松＝时间固定问次数（竖着数），Gamma＝次数固定问时间（横着量）；因此 P(T_k ≤ t) = P(N(t) ≥ k)。
