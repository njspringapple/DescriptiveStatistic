看得见的三兄弟

卡方 χ² · t · F——它们不是天上掉下来的公式，而是正态分布的三个亲儿子。

本页从你已经会的「高斯分布 + 标准化」出发，用可交互图形一步步搭出它们，最后用一家奶茶店把三个检验全用一遍。

0先想清楚：我们到底在干什么？

一句话：统计推断＝把「观察到的差异」和「纯随机能造出多大的差异」比一比。

你尝了两家奶茶：A 店平均甜度 7.8 分，B 店 7.0 分。差 0.8 分。

这 0.8 分是真差别，还是你只是恰好抽到几杯偏甜的？要回答它，你必须先知道一件事：

如果两家其实一样，纯靠运气，这个差值会长成什么样？
这个「运气长什么样」的图，就是抽样分布。χ²、t、F 就是三张最常用的「运气地图」。

而它们全都长成同一个套路——信号 ÷ 噪声：

统计量结构白话
Z差异 ÷ 已知的标准差尺子刻度是确定的
t差异 ÷ 估计的标准差尺子本身也在抖
χ²Σ (偏差)² 累加把很多处偏差平方后攒起来
F一个方差 ÷ 另一个方差两种波动比大小

1起点：标准化只是「换一把尺子」

你已经会这一步了，但请再看一眼这个动图——后面三个分布全是从右边那条曲线里长出来的。

Z = ( X − μ ) / σ   ⟹   Z ~ N(0, 1)

关键直觉：阴影面积（概率）在两张图里完全相同。标准化没有改变任何事实，只是把「厘米」换成了「几个标准差」。
于是全世界所有正态问题，都能翻译成同一条 N(0,1) 曲线上的问题。Z 就是统计学的通用货币。

2卡方分布 χ²：把 Z 平方后攒起来

动机：有时我们不关心「偏高还是偏低」，只关心「偏得多不多」——那就平方，然后把多处偏差加总。

χ²k = Z₁² + Z₂² + … + Zk²  （k 个独立标准正态）

k 叫自由度（有几个独立的 Z 被加进来）。下面这台「机器」帮你亲手造一个卡方分布：

↑ 每次抽 k 个标准正态（蓝点），平方后相加，得到一个 χ² 值（橙色柱子落点）。

理论 χ²k 密度 你的模拟直方图

为什么它长这个「右边拖尾」的样子？

  • 不可能为负：平方之后只剩非负数 → 图形从 0 开始，左边被墙挡住。
  • 右偏（长尾在右）：大多数 Z 都是小数字，平方后更小（0.5²=0.25），挤在左边；偶尔冒出一个 Z=3，平方变 9，把尾巴拉得很长。
  • k 越大越像正态：一堆独立随机数相加 → 中心极限定理生效。均值恰好 = k，方差 = 2k。
χ² 的两大真身（一定要记住第 2 个，它是 t 和 F 的零件）：
① 计数类偏差的累加：Σ (观察 − 期望)² / 期望 ≈ χ² —— 这就是拟合优度检验、独立性检验的统计量（形状上就是「平方偏差之和」）。
② 样本方差的分布：若数据来自 N(μ,σ²)，则 (n−1)s² / σ² ~ χ²n−1。
也就是说：χ² 就是「方差」的分布。凡是涉及方差/离散程度的推断，背后都有卡方。

3t 分布：当尺子自己也在抖

现实里 σ 我们不知道，只能用样本标准差 s 顶替。这一顶替，天就变了。

Z = (x̄ − μ)/(σ/√n)   →   t = (x̄ − μ)/(s/√n)

把它拆开看，就能看到 t 的出生证明：

tk = Z ⁄ √( χ²k / k )

分子是一个标准正态（信号），分母是由卡方做出来的、带随机性的尺子。σ 是固定的刻度，s 却是随机的： 有时候你抽到的几个数恰好挤在一起，s 偏小，分母偏小，t 就被放大成一个夸张的大值。 这就是 t 分布尾巴更肥的全部原因。

动手看：n=5 的小样本模拟

模拟出的 (x̄−μ)/(s/√n) N(0,1) t₄

看两侧：直方图明显超出蓝色正态曲线、贴着绿色 t 曲线。用 Z 的临界值 1.96 判小样本，会把太多噪声误判成「显著」。

自由度怎么影响形状

三句话记住 t：
① 矮、胖、肥尾——因为分母在抖，极端值更常见（“不确定性的税”）。
② df 越大越像正态——样本越多，s 越接近 σ，尺子越稳；df≈30 以后两条线肉眼几乎重合。
③ t 的临界值总比 1.96 大——小样本要求更“过分”的证据才敢说显著。

顺便彻底搞懂「自由度 n−1」

自由度 = 独立信息的条数 − 被你用掉的约束条数。
算 s 之前你先用数据算了 x̄，于是所有偏差之和必须为 0。
举例：3 个数的偏差是 +2, −1, ? —— 最后那个没得选，只能是 −1。
3 个数里只有 2 个偏差是自由的 ⟹ df = n − 1 = 2。不是玄学，是被约束绑住了一个。

4F 分布：两个卡方在比大小

既然 χ² 是「方差的分布」，那么两个方差之比的分布，自然就由两个 χ² 相除而来。

F(d₁, d₂) = ( χ²d₁ / d₁ ) ⁄ ( χ²d₂ / d₂ )

每个卡方都先除以自己的自由度，变成「平均每个自由度贡献多少」——也就是均方（MS）。所以 F 的白话版是：

F = 一种方差的估计 ⁄ 另一种方差的估计
F 的直觉：把它读成「信噪比」。
在方差分析（ANOVA）里：F = 组间均方 ⁄ 组内均方 = （组与组的差异）⁄（组内部本来的噪声）。
• 如果各组真的没差别 → 分子分母测的是同一个噪声 → F 应该在 1 附近。
• F 远大于 1 → 组间差异大得没法用噪声解释 → 有真差别。
• 所以 F 检验天生是单侧（只看右尾），因为只有“太大”才可疑。

两个漂亮的家族联系（记住等于省一半脑力）

  • t² = F(1, k)：两组均值比较，用 t 检验和用只有两组的 ANOVA，结论必然完全一致。（试试把上面 d₁ 设成 1）
  • d₂ → ∞ 时，d₁·F → χ²d₁：分母样本无限大 ⇒ 分母方差不再抖 ⇒ 退化成卡方。
  • d₁,d₂ 都很大时，F → 1：曲线越来越窄地挤在 1 上。

6四兄弟对照表（可以直接背这张）

分布怎么来的取值范围/形状参数核心用途一句话记忆
Z (X−μ)/σ (−∞,∞)，对称钟形无 σ 已知或大样本的均值/比例检验 标准尺子
χ² k 个 Z 的平方和 [0,∞)，右偏，k 大趋正态df = k ① 交叉表独立性 ② 拟合优度 ③ 方差的区间估计/检验 平方堆：只问偏多少，不问方向
t Z ÷ √(χ²/k) (−∞,∞)，对称但肥尾df ① 单样本/双样本/配对均值检验 ② 回归系数检验 ③ 均值置信区间 抖动的尺子：σ 未知的代价
F 两个 χ²/df 相除 [0,∞)，右偏，中心≈1df₁, df₂ ① ANOVA 多组均值 ② 回归整体显著性 ③ 两方差是否相等 比值裁判：信号 ÷ 噪声，看它离 1 多远
对比抓手（三个维度就够）：
• 能不能为负？ Z、t 能；χ²、F 不能（因为都是平方来的）。
• 对称吗？ Z、t 对称 → 双侧检验；χ²、F 右偏 → 常用右单侧。
• 问的是什么？ t 问「中心位置差多少」，χ²/F 问「波动/偏离有多大」。

8踩坑清单（考试和实战都爱考）

χ² 的坑

  • 必须用原始计数，不能拿百分比去算。用 50%（其实 n=4）算出来的卡方是假的。
  • 期望频数最好都 ≥5（至少不低于 1，且 <5 的格子不超过 20%）。否则用 Fisher 精确检验或合并类别。
  • n 越大越容易显著：卡方值随样本量线性放大。要看效应量（Cramér's V），别只看 p。
  • 显著只说明「有关联」，不代表因果，也不告诉你关联的方向和强弱。

t 的坑

  • 配对 ≠ 独立：同一批人前后测必须用配对 t（先求差值），用独立样本 t 会白白损失功效。
  • 两组方差差很多时，用 Welch t（不假设方差齐），自由度会变成小数——这很正常。
  • 不要拿 t 做多重两两比较：3 组两两比 3 次，α 从 0.05 涨到约 0.14。请先 ANOVA，再事后检验校正。
  • 小样本时对极端离群值非常敏感（s 被拉大或缩小）。先画图看数据。
  • df≥30 时 t 与 Z 几乎一样，但报告时仍写 t。

F 的坑

  • F 显著只说明「至少有两组不同」，不知道是谁和谁。必须做事后检验（Tukey 等）。
  • 用 F 去检验「方差齐性」时对非正态极不稳健，实务上更推荐 Levene / Brown-Forsythe。
  • 单侧右尾：习惯把大方差放分子；查表注意 df 顺序 (分子, 分母) 不能颠倒。
  • F 不能为负；若算出的 F 小于 1，通常意味着组间差异还不如噪声大，直接不显著。
三者共同的大前提：它们的精确分布都建立在「数据近似正态 + 观测相互独立」之上。
独立性被破坏（重复测量、聚类数据、时间序列）比轻微非正态严重得多——那时换分布也救不了，得换模型。

9怎样才不容易忘

① 一句顺口溜（背这个）

一个 Z 是尺；
Z 平方堆起来是卡方；
Z 被卡方拖着抖是 t；
卡方比卡方是 F。

顺着念一遍，四个分布的定义式就全出来了。

② 形状联想（看图记）

  • χ² 像一条滑梯：左边陡陡爬上去，右边长长滑下来（永不为负）。
  • t 像一顶被压扁的钟：头矮了，两边裙摆（尾巴）厚了。df 越大，钟越挺，最后变回正态。
  • F 像1 号站台旁的小山包：山峰蹲在 1 附近，右边拖尾。

③ 用途口诀

均值找 t，多组找 F，数格子找卡方，方差比也找 F。

④ 用「代价」串起来

正态 → t 的唯一变化是：σ 不知道，用 s 代替。
代价 = 尾巴变肥 = 临界值变大 = 不确定性要交税。
样本量越大，税越少（df→∞，t→Z）。这条因果链一旦记住，t 分布就永远不会忘。

⑤ 用「自由度」串起来

χ² 有 1 个 df，t 有 1 个 df，F 有 2 个 df——因为 F 是两个卡方的比，一人贡献一个。
df 的含义永远是：独立信息数 − 用掉的约束数。

10实战：一家奶茶店，三个检验全用上

场景：你在商场调研三家奶茶店 A / B / C，每家随机请 10 位顾客给「甜度满意度」打分（0–10），并记录顾客性别与最喜欢的店。

t 问题一：A 店比 B 店真的更受欢迎吗？（两组均值）

数据：nA=nB=10，x̄A=7.8，x̄B=7.0，合并标准差 sp=0.90。

t = (7.8 − 7.0) / [ 0.90 × √(1/10 + 1/10) ] = 0.80 / (0.90 × 0.447) = 0.80 / 0.402 ≈ 1.99 df = 10+10−2 = 18 双侧 5% 临界值 t₀.₀₂₅,₁₈ ≈ 2.101 → 1.99 < 2.101，不显著（p≈0.062）
落地解读：“看起来 A 更甜受欢迎，但以这点样本量，还不能排除运气。”
注意这里的教学点：如果你偷懒用 Z 的 1.96 去比，就会得出“显著！”——这正是小样本必须用 t 的现实后果。
下一步该做的不是改结论，而是加样本（比如每家 30 人）。

χ² 问题二：男女的店铺偏好有差异吗？（交叉表独立性）

ABC合计
男30201060
女20303080
合计505040140

期望频数 = 行合计 × 列合计 ÷ 总数（意思是“如果性别与偏好完全无关，应该长什么样”）。

期望：男A=60×50/140=21.4 男B=21.4 男C=17.1 女A=28.6 女B=28.6 女C=22.9 （全部 ≥5 ✔ 前提满足） χ² = (30−21.4)²/21.4 + (20−21.4)²/21.4 + (10−17.1)²/17.1 + (20−28.6)²/28.6 + (30−28.6)²/28.6 + (30−22.9)²/22.9 = 3.43 + 0.10 + 2.97 + 2.57 + 0.07 + 2.23 ≈ 11.37 df = (2−1)(3−1) = 2 临界值 χ²₀.₀₅,₂ = 5.99 → 11.37 > 5.99，显著（p≈0.003）
落地解读：性别与店铺偏好有关联。看每格贡献：男生扎堆在 A（+3.43）、明显避开 C（+2.97）；女生偏爱 C（+2.23）。
但请注意：卡方只说“有关系”，不说“男生更爱 A 是因为 A 更甜”。要因果，得做实验。

F 问题三：三家店的平均满意度整体有差别吗？（ANOVA）

三家店 10 人一组，x̄A=7.8、x̄B=7.0、x̄C=6.4。计算得：组间均方 MS组间=4.90，组内均方 MS组内=0.81。

F = MS组间 / MS组内 = 4.90 / 0.81 ≈ 6.05 df = (k−1, N−k) = (2, 27) 临界值 F₀.₀₅(2,27) ≈ 3.35 → 6.05 > 3.35，显著 读法：店与店之间的差异，是店内部随机噪声的 6 倍。若三家真的一样，F 应该在 1 附近晃。
落地解读 + 必须的下一步：F 显著只说明“三家不全一样”。到底是 A>C 还是 B>C？必须做事后检验（Tukey HSD）。
千万别改成 A-B、A-C、B-C 各做一次 t 检验就下结论——那样第一类错误会从 5% 膨胀到约 14%。

附赠：F 还能查“波动”

A 店评分方差 s²A = 1.20（口味不稳定？）， B 店 s²B = 0.50 F = 1.20 / 0.50 = 2.40 df = (9, 9) 双侧 α=0.05 → 上临界 F₀.₀₂₅(9,9) ≈ 4.03 2.40 < 4.03 → 不能说 A 店的出品稳定性更差（样本太小，看不出来）。 ※ 实务里方差齐性更推荐 Levene 检验，F 检验对非正态太敏感。
把这个奶茶店故事记牢，三个分布就都记牢了：
比两家（平均分）→ t  |   数人头/查关系（男女×店铺）→ χ²  |   比三家 / 比稳定性（方差之比）→ F

11三十秒自测（点击题目看答案）

Q1. 为什么 χ² 和 F 都不可能取负值，而 t 可以？ ▸

因为 χ² 是平方之和，F 是两个非负量之比，天生 ≥0；而 t 的分子是 Z（可正可负），所以 t 对称分布在 0 两侧。

Q2. 样本量从 10 增加到 1000，t 分布会怎么变？为什么？ ▸

df 变大 → s 越来越准地估计 σ → 分母不再抖 → 尾巴变薄，曲线趋向 N(0,1)，临界值从 2.26 降到约 1.96。“不确定性的税”变少了。

Q3. 有人把 3 组数据做了 3 次两两 t 检验，说“找到一组显著”。问题在哪？ ▸

多重比较膨胀了第一类错误（3 次各 5%，整体约 14%）。应先用 F 检验（ANOVA）做整体判断，再做校正的事后检验。

Q4. 一个 2×2 交叉表，每格样本从 (20,30,25,25) 全部乘 10，卡方值和 p 值会怎么变？ ▸

卡方值大约放大 10 倍，p 值急剧变小，但关联强度（比例结构）完全没变。这就是为什么必须同时看效应量，不能只看显著性。

Q5. ANOVA 里如果各组真的没有差别，F 大约应该等于多少？为什么？ ▸

约等于 1。因为此时分子（组间均方）和分母（组内均方）估计的是同一个误差方差，两个同量之比自然接近 1。

Q6. 只用一句话写出三者的关系。 ▸

χ² 是 Z 的平方和；t 是 Z 除以 √(χ²/df)；F 是两个 χ²/df 之比，且 t²=F(1,df)。
