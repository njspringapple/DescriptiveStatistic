📐 三步法：如何"借位"划分子网

第1步：看原始 CIDR（如 /16）→ 前16位是网络，其余是主机。
第2步：要划分成 N 个子网 → 需要借 k = ⌈log₂N⌉ 位。例如4个子网 → 2位；1024个子网 → 10位。新 CIDR = 原 + k。
第3步：这 k 位从主机部分的最高位开始拿。它们的所有组合 (00,01,10,11…) 就是各个子网编号，把它们放回原位就得到子网地址。

🔐 CRC 原理

生成多项式 G 用二进制表示：\(G = x^3 + 1\) → 系数 1001（4位）。
一个 \(r\) 阶多项式 → \(r+1\) 位；需在消息后补 r 个 0，用模2除法(XOR)相除，余数就是 CRC 校验和。

发送：消息 + 余数。接收端再除一遍，余数为 0 即正确。

📶 CSMA/CD 冲突检测核心公式

为了能可靠检测冲突，发送方必须在帧发完之前收到冲突信号，即信号往返时间 ≤ 帧传输时间：

2 · t_prop ≤ t_frame

t_frame = 帧长(bit) / 传输速率
t_prop  ≤ t_frame / 2
d_max   = t_prop · v (传播速度)

结论：速率↑ → t_frame↓ → 最大距离↓；速率↓ → 最大距离↑。

📏 汉明距离 (Hamming-Distanz)

定义：\(H(C) = \min\{H(x,y) \mid x \neq y,\; x,y \in C\}\)，即码字集合中任意两个不同码字的最小比特差异数。

检测 d 位错误需要：\(H(C) \ge d+1\)
纠正 d 位错误需要：\(H(C) \ge 2d+1\)
